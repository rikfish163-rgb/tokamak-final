# 按首报净收益学习炮内更新动作：冻结的全 TRAIN 实验

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run and independent validation
- Origin Date: 2026-11-06
- Verification Status: defined before the real action and cross-fit runs
- Version Label: patch_utility_selection_train_v1

前一轮已证明，在相邻时间片的低秩写入位置上存在等锚点分数
无法复制的离线纠错；简单 H25 梯度与逐点岭解都不会选对。
本轮用实际更新的完整首报差当教师，不改变合格源检查点或
固定报警阈值。只使用锁定的 J-TEXT TRAIN1353，排除 VAL、
TEST 和 EAST，未追加标签查询。全炮按留出划分，这不是
按历史时间前瞻的 EAST 在线结果。

## 一、共同的真实动作库

沿用第一层前的相邻 patch 变化算子和 .35 状态范数上限。
每个释放 m=63+32k 从零态提案；未来更新窗口完全不参与提案
（写入仅 m+1 至 m+32，尾端截短）。输入只有 m 及以前的
原始诊断。首报分数阈值全程固定。

六个候选轴都投影到已到达 m−16、m−8、m 的风险导数零空间：
三个由已到达 m−4、m−12、m−24 的风险导数的平均或相邻差产生；
三个来自三诊断家族的 H25 lag8 梯度，按家族对真实和反序两套
先各取单位梯度均值，再对称合并。对称性确保真实／反序
选择器的动作库存相同。每轴正反共用由实际前向检验的倍率，
三点双符号风险偏移 ≤.10 logit，保留 12 个可能的写入和不写
入；无支持方向不使用。每个可用动作都真实走原网络，不用
线性近似、最终分数替代或任何未来信息计算动作。

波形、动作、真实轨迹、同锚点偏移轨迹及纯前缀特征先封存。
封存完成后才从原 HDF5 读取 IsDisrupt 和 DownTime。原分集、
原规范 J-TEXT 正窗 max(25 ms, AdvancedTime) 及严格首报提前
量 >10 ms 不变。

## 二、同一个目标，三个信息量对照

在已结束的炮上，用单个写入块替换静态曲线后重算完整首报。
硬效用为是否改善真实及时报警或消除误报（+1）、相反（−1）
或不变（0）。软效用使用同一扰动阈值下的累计首次过阈；
在原首报、原规范正窗和安全炮各自作区别。拟合两者 .75/.25
加权的**相对不写入增益**，不用后续风险或 HDF5 结果作输入。

- 风险／时钟：冻结风险历史、绝对释放点、候选族与符号、
  候选范数、token 编辑量、已到达风险偏移和变化。
- 真实波形：同一风险与动作特征，再加已到达真实反馈的分段
  有符号变化、预测误差、与候选方向的梯度对齐。
- 反序波形：同一输入宽度，新增特征用已到达的反序观测；
  观测值集合、有效配对和共有动作均保持。

五折由 shot ID 的固定哈希生成。每一外折另保留下一折作校准，
其他三折拟合固定加权岭回归（alpha .03）。在有支持的样本中，
先平衡两类，再在每类内均衡到炮、释放块及可用动作。一个外折
的炮不能影响同折的特征标准化、训练或弃权阈值。依次报告
最大预测收益 >0 即写入的开放规则，以及用独立校准折在
{0,.001,.0025,.005,.01,.02,.05,∞} 中选保守弃权门槛的规则；
校准要求不新增误报且不丢原及时炮，先最大化新增及时数，再
最大化消除的误报，平手选更保守门槛。各块都单独决策，最终
结果按拼接后的整炮首报计算。对真实选择器的**同一动作索引**
另做等锚点分数回放，检验增益是否只是移动决策分数。

## 三、解释门槛

精确计算有限动作库的事后可达性，分清没有可用动作与有动作
却没选中。没有新增误报、没有丢原及时的前提下，保守真实
选择器须新增至少 1 个及时炮或移除至少 3 个原误报，并且存在
风险／时钟、反序和等分数都未复现的受益炮，才送入源 VAL
整炮验证。相同炮的多个候选、多个时间点不是独立样本。外折
结果只描述当前数据上的留炮诊断；晋级也不改 EAST 阈值、
既定炮序、标签预算或 FPR ≤20% 的要求。

参考 [带弃权的策略学习](https://proceedings.mlr.press/v300/sawarni26a.html)
与 [以基线为后备的策略改进](https://proceedings.mlr.press/v97/laroche19a.html)
的设计动机。这里是能回放所有模型动作的配对实验，并非这些
论文的有倾向评分模型或 MDP，不继承其性能保证。
