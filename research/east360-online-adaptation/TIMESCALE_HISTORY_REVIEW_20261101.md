## Minimal *new* contrast — proposed only

If the main investigation decides the hypothesis merits a test, start with **one fixed causal input-rate intervention**, not a learned controller: compare the exact current cold/no-temporary-state parent at `d=1` against the same parent at predeclared `d=2`. For each scored endpoint `t ≥ 254`, supply `x[t−254], x[t−252], …, x[t]`, with the corresponding availability masks, as the 128 ordered rows; for `t < 254` use the identical `d=1` window in both arms. Apply the existing frozen input map consistently, do not invent missing values, and retain actual HDF5 endpoint timestamps, original alarm threshold and strict physical-time lead rule. This uses only already-arrived observations. Include the same source-only first20 predictions/cost in both arms, preserve the current parent, order and suffix identity, and require the `d=1` full curve to reproduce the saved cold curve before interpreting `d=2`. Verify prefix truncation invariance, exact indices/masks, early fallback, and `d=1` identity; no event time or outcome may select `d`, a window, or an update.

Report full360 and suffix340 paired TP/FP, rescues/losses and earliest/very-early alarms, with score differences, channel support/missingness and early fixed-prefix limitations. A single fixed `d=2` is illustrative, not a data-derived optimum or an adaptation algorithm; if the ongoing main-agent statistics motivate a different **predeclared** direction, that must be decided before looking at this contrast's outcomes. Decimation simultaneously changes physical span, sample density and possible aliasing, so even a positive result would **not** by itself identify a time-scale mismatch. A later causal per-shot learned or relative-change-selected tempo would be a distinct, still-unverified experiment; it would need past-only scale estimation, zero/near-zero and missing-channel rules, shot-reset behavior, and an explicitly frozen selection rule. Do not equate a log-like auxiliary target with such alignment or infer a physical time constant from it.
