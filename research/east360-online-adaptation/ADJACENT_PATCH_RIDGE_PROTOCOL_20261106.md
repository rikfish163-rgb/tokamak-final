# 逐点反馈可见，是否足以在不看结局时选对方向？

- Origin Mode: run

- Version Label: adjacent_patch_ridge_train_v1

只使用上一项预先固定的 40 个 J-TEXT TRAIN 炮，完整跑每炮每块。
这批是带有迟报、原首报和匹配安全窗的开发诊断，不估计总体
TPR/FPR。保持源检查点、时钟、观测掩码、标签窗、第一报警阈值。

在相同起点预测 H25。取已到达的同诊断、相隔八点的变化量误差，
剪到 SmoothL1 的一阶影响范围 [−1,1]；每个诊断家族／时段
的每对乘以该项有效配对数的负二分之一次方。对相同已观测
坐标求预测雅可比 J。先从 J 移除与三个已到达风险导数同向的
分量，再用线性岭解 `(JᵀJ + .01σmax² I)⁻¹ Jᵀr` 得到方向；
这不使用未来风险梯度、在线标签或论文中的目标结局。
真实／反序和变化／水平共享配对、正则公式和时间。

与原九项汇总下降的四臂配对。方向范数均不超过 .35，八臂
在同一锚点匹配实际 token 编辑 RMS，再用同一网格检验三点
实际双符号风险保护，最大 .10 logit。无共同方向均不写。
另加真实变化的等锚点分数控制。模型仅用波形预测并全炮
封存后再揭示 HDF5 标签。报告所有臂的首报、迟报救回、误报
得失和共同活动覆盖；新方法的局部峰不作替代验收。

仅当真序逐点变化臂在无新增误报、无丢原及时的前提下产生
固定反馈、反序、水平与等分数无法复现的新及时炮，才考虑
更大不见结局的源验证。若没有，则知道预测头的可观察空间
虽然更大，拟合真实变化本身仍未给出有效的预警方向。没有
EAST 数据、源 VAL/TEST、新标签、重训或阈值扫描。
