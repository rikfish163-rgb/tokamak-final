# H25 的到达时机与逐点变化量：两个可证伪的后续探针

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run
- Origin Date: 2026-11-06
- Verification Status: protocol frozen before either follow-up run
- Version Label: h25_release_timing_v1 / h25_increment_mechanism_v1

前置结果：幅值 H25 的真实／反序方向在危险窗的中位余弦相似度
为 .9989。增加的三个方向使受历史约束的未来风险梯度覆盖增加，
但与同秩反序臂几乎一致；六炮有限求解没有新增及时首报。以下
两个问题单独检验，不改变已封存结果、父模型、风险阈值或标签。

## A. 时机：同一个梯度早七点释放

只用原六个 J-TEXT TRAIN 迟报／漏报炮做快速否证。固定每个起点
`o=31+32k` 和同一个 H25 一次性预报；实测第 25 点到达后，
真／反序梯度计算一次，分别在 `o+25` 和 `o+32` 释放。两臂
都只修改释放以后、下一次释放前的 32 点，末尾按实际采样截短，
不回写过去；查询为零，窗口内不使用结局。

对签名家族平均下降方向，从 128 维中去除三个已到达时刻
`r−16,r−8,r` 的风险雅可比行空间，再用共同的正负两方向网格
验实 .10 logit 限制及 .35 参数范数。注意这是**全环境空间**
投影，不是把三个家族方向强制局限在原三维空间再同时施加三条
等式，后者通常没有自由度。两种释放时钟使用同一投影规则。
分别报告可作用的规范正窗端点、特别是本块额外七点、各臂
及时首报和最高实际风险。若没有早释放真实臂独有的及时救回，
本次有限规则不支持把速度单独当作主要解法；不是穷尽上限。

## B. 目标：只对已到达的有符号变化量训练

保持 `m=o+32`、相同 H25 头和起点、第一层 norm1 仿射写入
位置、三诊断家族、规范正窗／首报保护／匹配安全三个角色。
候选以**已经归一化**的轨迹为输入，固定比较相隔 8 个采样点
的变化量：取 `预测[t+8]−预测[t]` 与 `实测[t+8]−实测[t]`
之间的 SmoothL1，且两端都观测到才纳入。它消除了单通道的
常量水平，仍可保留上升／下降方向。不是扫描步距，也不是
引入物理标签。反序保持单通道值集合、缺测位置和有效配对，
仅改变已观测值的先后。幅值损失来自原封存梯度。

每个种子从同一旧方向基底，分别加入幅值真／反序、变化量
真／反序方向；每窗四臂用相同增加秩和相同精确双符号限幅
网格。因果动作只用已到达的梯度、旧方向和三个已到达风险
雅可比；规范窗目标及未来风险只作评分。比较危险峰、保护窗
越阈丢失、安全窗新越阈、真实／反序梯度余弦及一阶风险方向
覆盖率。危险峰先按炮内平均、种子平均，再做配对炮级重抽样；
不把同炮窗口或相同基模下的种子当独立实验样本。

进入下一轮训练的开发闸门：至少 70% 原危险窗四臂有共同
支持；危险窗变化量真／反序梯度的中位余弦较幅值下降至少
.15；真实变化量的危险峰相对冻结平均为正、相对反序至少
+.005 logit，后者炮级重抽样的 2.5% 分位高于 0；相对反序
及真实幅值均不增加两类窗口伤害。低余弦或几何容量变大
单独不算进展到下一阶段。任何一臂都不在此使用 EAST 或
J-TEXT VAL/TEST，也不拿局部峰结果当完整炮流成绩。

参考的是任务梯度需一致与反馈须在到达后使用这两个原则：
[Sun 等的测试时训练](https://proceedings.mlr.press/v119/sun20b.html)、
[DSOF 的在线预报时序合同](https://proceedings.iclr.cc/paper_files/paper/2025/hash/46e624c244cff669223d488defd4e835-Abstract-Conference.html)。
两篇不提供托卡马克或本数据上的实证。
