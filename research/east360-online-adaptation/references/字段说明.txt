J-TEXT event 标注说明
导出日期：2026-10-18
主文件：JTEXT_event_labels.csv

一、标注范围
采用论文参考运行 single_ap（seed 42）的冻结 K=6 事件词表及最终合并事件。
包含当前 training_pool 全部 1,634 炮和 sanity 全部 182 炮，共 1,816 炮。
仅导出 event 的类别、开始和结束时间；不包含 MIL 训练过程中的原始 onset 点。
炮号、队列、破裂标签、事件序号和标注状态用于识别记录与解释缺失值。

二、字段
shot_no：原始炮号。
cohort：training_pool 或 sanity。
disruption_label：原有炮级结局标签；1 为破裂，0 为非破裂；与 event_class 不同。
event_index：该炮最终事件按时间排列的序号，从 1 开始。
event_class：冻结词表中的 A、B、C、D、E、F 类，沿用论文命名。
event_start_s：事件开始时间，单位秒，原始诊断时钟。
event_end_s：事件结束时间，单位秒，原始诊断时钟。
annotation_status：见下方状态说明。

三、时间定义
事件区间采用左闭右开 [event_start_s, event_end_s)。
时间不是“距破裂还有多少秒”，也不是“从输入记录起点算起的秒数”。
本批记录输入从原始诊断时钟 0.15 s 开始；每个 token 为 5 ms。
换算公式：时间（秒）= 0.15 + token 边界索引 × 0.005。
event_end_s 对应结束边界，不减去一个 token。事件时长为 end − start。
同一类别若中间存在空隙，保留为两个事件；不同轮次的重叠候选按冻结主链合并规则处理。

四、状态与空值
event：一行对应一个最终事件，类别及起止时间均有效。
no_event_detected：该炮已处理，但未保留最终事件；用一行保留炮号，事件字段为空。
excluded_short_record：记录不足 50 ms（10 tokens），未进行该模型的事件标注；事件字段为空。
只读取事件区间时，筛选 annotation_status == event。
空值不能解释为类别 A、起点 0 s 或零时长事件。
未检测到事件不等于整炮物理状态正常；短记录排除也不等于没有事件。

六、A–F 各类的信号特征与可能物理含义

阅读口径：
以下沿用论文参考运行的 h_mean_own12 / KMeans / K=6 词表，不与其他聚类方案中的同名字母混用。
“升高／降低”指事件窗口的工程特征均值相对同炮完整记录中位值的偏差，再按类内每炮等权汇总；不是相对事件开始前一刻的变化，也不表示每个样本都具备全部特征。
这些特征用于解释已生成的类别，并非人工设置的类别判定阈值。特征处于已有存储变换后的坐标，不能把变化量直接当作米、安培或特斯拉。
模型归因（SHAP）说明哪些输入影响局部破裂分类分数，与信号本身升降、物理因果作用是不同概念。

A — 位移偏离型
  主要信号：垂直位移 dy 与水平位移 dx 均偏高；局部分类分数对 dy、等离子体电流 ip 和环向磁场 bt 的归因较突出。
  可能含义：与等离子体位置或平衡状态偏离相关的候选状态，也可能包含 ip／bt 运行工况差异；可作为位移相关状态标签理解。
  解释边界：ip、bt 的模型归因突出不等于电流或磁场发生突变；不能仅凭 A 确认垂直位移事件（VDE）或位置控制失稳。

B — 模数／频率变化型
  主要信号：极向模数估计量 mode_number_m 与频率特征 frequency_m 偏高；dx 有小幅正偏移倾向，但其类均值区间跨零。局部分类对 qa_proxy 的归因突出。
  可能含义：与磁扰动的模结构或频率变化、平衡运行状态差异相关的候选状态。
  解释边界：qa_proxy 是边缘安全因子的代理特征，其归因不能解释为 q_a 必然升高；也不能据此确认具体 m/n 模式或某个有理面穿越。

C — 水平位移伴随较低磁扰动幅值型
  主要信号：dx 偏高，同时 Mirnov 幅值 FFTMir_abs 和极向模数估计量 mode_number_m 偏低。模型归因中 dx 与 Mirnov 主频 FFTMir_fre 较突出。
  可能含义：位置偏移与较弱磁扰动特征共同出现的候选状态；与 D 的磁扰动增强状态可作区分。
  解释边界：幅值偏低是相对同炮中位状态，不证明磁扰动已被抑制、系统已经恢复，或随后一定转为 D。

D — 磁扰动增强型
  主要信号：Mirnov 幅值 FFTMir_abs 偏高，并伴随极向／环向模数估计量 mode_number_m、mode_number_n 的变化；本批类均值均为正偏差。模型主要依赖 dx、Mirnov 幅值与主频。
  可能含义：与磁流体不稳定性（MHD）活动增强或磁模结构变化相关的候选状态。
  解释边界：D 尚未被确认为撕裂模或锁模；类别本身不提供经物理验证的 m/n 数值，也不表示必然破裂。

E — 垂直剖面与碳杂质发光变化型
  主要信号：CIII 垂直弦阵列的剖面方差特征 Z_profile_var 明显偏高，即弦间信号差异较大；同时 mode_number_n 与 CIII 信号偏高。模型归因中 Z_profile_var、qa_proxy 较突出。
  可能含义：与 CIII 垂直弦阵列发光分布变化、碳杂质发光增强共同出现的候选状态，可用于识别这类剖面／辐射组合特征。
  解释边界：CIII 增强本身不能确定杂质浓度、杂质来源或因果作用；Z_profile_var 也不能单独证明 VDE。

F — 软 X 射线与辐射剖面变化型
  主要信号：软 X 射线中心弦强度 SXR_core、软 X 射线剖面方差 sxr_profile_var 及 AXUV 阵列方差 axuv_array_var 均偏高；后两项表示同一时刻的弦间信号差异较大。模型归因以 sxr_profile_var 较突出。
  可能含义：与中心视线软 X 射线信号增强、辐射剖面形态变化相关的候选状态。
  解释边界：不能仅由这些信号确定电子温度、杂质浓度或能量损失的变化，更不能直接命名为辐射塌缩或热猝灭。

常用信号缩写：
dx / dy：水平／垂直位移；正负方向沿用原诊断约定。
ip / bt：等离子体电流／环向磁场。
FFTMir_abs / FFTMir_fre：Mirnov 磁扰动的频谱幅值／主频工程特征。
mode_number_m / mode_number_n：由磁探针相位差得到的极向／环向模数估计量，可以为连续值；估计量变化不等于已确认特定本征模。
frequency_m：极向模数估计算法选取的互谱峰频率特征，不与 FFTMir_fre 混为同一个字段。
qa_proxy：边缘安全因子代理特征。
CIII：C III 碳离子谱线发光信号。
SXR：软 X 射线诊断；AXUV：极紫外辐射探测阵列。
Z_profile_var / sxr_profile_var / axuv_array_var：分别为 CIII 垂直弦阵列、SXR 阵列和 AXUV 阵列的跨通道方差，在同一时刻对不同通道取方差，不是沿时间取方差；方差增大不等于时间振荡增强。

字母与风险的关系：
A–F 的命名顺序依据开发池破裂事件的中位提前量，不是风险等级，也不要求每炮按 A→B→C→D→E→F 演化。
出现某类、类间转移或字母顺序回退，都不能单独解释为必然破裂、物理因果链或恢复。

依据：论文 v3 的候选家族表（tab:families）和“Representation and local explanation”附录；同一 K6 词表的 naming.json、candidate_validation/h_mean_own12_k6/profiles.json。通道定义参考项目特征对照表 idp_pgfe_feature_crosswalk_r4.md；跨通道方差定义核对 Feature_extraction.py 的 factors_profile。仅引用该旧对照表的通道定义，不采用其旧类别解释。上述物理含义是对已观测信号组合的候选解释，不是新增物理验证结果。

七、标签含义与文件格式
A–F 是模型发现的候选事件类别，不是人工确认的物理模态标签。
这些区间来自完整记录的离线分析；起点不是在线检测器的事件确认时刻。
CSV 使用 UTF-8 BOM、逗号分隔、小数点为英文句点，可直接用 Excel 或 Python 读取。
Python 示例：
  import pandas as pd
  labels = pd.read_csv('JTEXT_event_labels.csv', encoding='utf-8-sig')
  events = labels.loc[labels['annotation_status'].eq('event')].copy()
