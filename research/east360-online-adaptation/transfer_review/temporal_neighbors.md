# 原360的邻炮相似性，支持局部参照但不证明物理工况或风险学习

目标是检验原360按整数炮号到达时，第一前驱是否比同90炮块内其他过去炮更相似，以及这种相似性能否支持划分 regime。这里把 regime 限定为有可观测定义的相似运行工况，不把相同结局或相同报警分类当作工况。

**结论。** 这份已暴露的历史流有局部连续性。第一前驱的首点电流和诊断可用掩码明显更相似。正常炮的封存 logit 峰值总体更近，但第二块反向，原始电流最大跌幅的证据对工况分层敏感。二元结局有较弱的邻近关联，完整报警分类的证据更弱。可以登记诊断覆盖片段，或研究按当时已见工况选历史参照。不能把相邻炮、每90炮块或相似性连通链直接命名为稳定物理工况，也不能据此声称学会了风险。

## 数据范围和时间口径

只读 [paired_forensics.json](paired_forensics.json) 的360行，以及 [current_drop_check.json](current_drop_check.json) 对应的360个原成员。没有读取其他炮，没有读 HDF5、模型、缓存或权重，没有训练、GPU、调参或新报警回放。以下计数和检验均由 [temporal_neighbors.py](temporal_neighbors.py) 生成。

- 封存字段含 `rank`、`shot`、`block`、首点 `ip`、`mask0`、`kind`、`down`、正常峰值。字段生成和结局读取见 [paired_forensics.py 的收集过程](paired_forensics.py#L49-L69)。结局继承该封存的原 HDF5 判定，本次没有再次读取原字段独立认证。
- 固定成员为54157至96375号，按整数炮号严格递增，共360个不同炮号。四块各90炮，块号、排名、原序列 SHA256 均通过断言。父分类仍为135及时、23晚报、22未报、31误报、149正确不报，破裂和未破裂各180炮。
- `shot` 的差值是整数炮号差，不是小时。用户确认较小炮号先放电，本次按这个先后关系回放；`start`、`end`、`DownTime` 是炮内录波时钟，没有给出绝对采集日期或两炮间等待时间。历史另有按电流选准备段的协议，不能借用其排序或成绩。[历史协议](../README.md#预测炮内更新炮间更新怎样分开)。
- 工况代理只用首点 `abs(Ip)` 和23位 `mask0`。首点是记录首点，不保证是放电初始或稳定平顶。它不等于 PCS 指令、加热配置或已认证运行场景。
- `eligible_peak_z` 在正常炮上是全记录 logit 最大值，`timely_peak_margin` 是全记录 `z−报警线` 最大值。正常炮的 `eligible_n==n` 已核对。源权重冻结不等于输入对齐状态、报警倍率和分数分布冻结。[峰值定义](paired_forensics.py#L60-L67)
- 原始跌幅使用正常炮的 `full_peak`，即已有核验中的128点窗 `(Ip_first−Ip_last)/abs(Ip_first)` 全记录最大值。它不用模型分数，但受记录长度和采样机会影响。[原始跌幅定义](current_drop_check.py#L39-L49)

## 第一前驱与一名其他过去炮作等预算比较

对同一目标炮，第一前驱臂只取一名供体。对照臂从同块、更早、排除第一前驱的炮中均匀抽一名。表中对照值是这个单抽的精确期望，不是把所有历史炮合成一个预测器。每个目标炮一票，不因历史池更大而增加目标权重。未使用未来供体或跨块供体。

四类全流指标每块88个目标，共352个。每块第一炮无前驱，第二炮无额外过去供体，所以两炮不作这个统计对照。它们仍保留在360成员和父评分中，没有删除准备段或错例。

正常峰值主对照取“最近已结束正常炮”对同块其他更早正常炮。当前炮是否正常只在炮后用于评价，不用于当炮选择。每块头两个正常炮缺少等预算对照，共172个目标。该供体不必是原流紧邻炮，其中104个的供体正好是第一前驱，其他68个跨过了破裂炮。排名差分布为1炮104次、2炮30次、3炮13次、4炮9次、5炮7次、6炮4次、7炮2次、8炮1次、9炮1次、12炮1次。

损失越小越相似。`advantage=对照期望损失−前驱损失`，正值支持邻近性。

## 同工况供体与保留依赖的置换

第一项条件对照把供体资格限定为 `mask0` 完全相同且首点电流比值不超过1.25。该资格只用当时已见首点，不用目标结局或峰值。

- 二元结局和 `kind` 仍要求真实第一前驱满足资格，且有至少一名其他同资格过去炮。各块73、65、66、58，共262个目标。结局不同率为0.354962对0.454516，优势0.099554。`kind` 不同率0.564885对0.620488，优势0.055602，但第二块反向。
- 正常峰值取最近的同资格已结束正常炮，对其他同资格过去正常炮。各块52、27、33、42，共154个目标。logit 差2.539834对3.063732，裕量差2.409589对2.629730，原始跌幅差0.006108对0.006729。第二块三项均反向，第四块裕量仍反向。这是不同的合格供体池，不能与172目标主对照当作完全相同样本的消融。

置换使用固定种子20261127，每项1999次。报告单侧 `p=(1+null优势不小于实测的次数)/2000`。它们是封存序列的探索性关联检验，不是随机新炮试验的显著性或未来性能保证。

1. **同块整行置换。** 每个90炮块独立重排行，首点工况、结局、`kind` 和各峰值一起移动。保留每块组成及工况与结局、峰值的经验联合关系，只打破块内序列邻近。正常目标数不变，正常位置随整行移动。
2. **同工况二元结局与 `kind` 置换。** 固定原顺序和首点工况。在同块、同掩码、同首点电流带内置换 `kind`，二元结局随 `kind` 一起变化。不是全流独立抛硬币。电流带为按最近中心取整的50、100或200 kA宽度，只是原A数值的分组，不是认证工作点。
3. **同工况且同已解决正常分类的峰值置换。** 固定真实正常位置和完整 `kind` 序列，正常峰值三元组只在同块、同掩码、同电流带、同TN或FP内一起置换。它保留结局串、误报分类串以及它们与粗工况和峰值的依赖，检验是否仍有额外的正常峰值邻近关联。

| 指标 | 同块整行 p | 同工况50 kA p | 同工况100 kA p | 同工况200 kA p |
|---|---:|---:|---:|---:|
| 首点电流 | 0.0005 | 不适用 | 不适用 | 不适用 |
| 掩码 | 0.0005 | 不适用 | 不适用 | 不适用 |
| 二元结局 | 0.0100 | 0.0140 | 0.0255 | 0.0295 |
| 完整 `kind` | 0.0305 | 0.1090 | 0.0795 | 0.0595 |
| 正常 logit 峰值 | 0.0050 | 0.0135 | 0.0040 | 0.0035 |
| 正常裕量峰值 | 0.0470 | 0.0170 | 0.0135 | 0.0275 |
| 正常原始跌幅峰值 | 0.0470 | 0.1900 | 0.0110 | 0.0335 |

50、100、200 kA条件层分别有39、27、20个组，其中6、2、1个单例组。含两种结局的组覆盖340、339、352行。可移动的正常峰值行分别170、172、173个，不是大量单例导致置换几乎无效。固定种子的Monte Carlo标准误由脚本输出，条件检验最大约0.0088，最小可报 p 为0.0005，不能写成 p=0。

同块整行零分布的95%分位区间，首点电流优势为−0.017375至0.018626，掩码为−0.047014至0.052894，正常 logit 为−0.358936至0.378788。实测分别0.084808、0.231021、0.491214。100 kA条件峰值零分布的logit优势为−0.188507至0.352897，裕量为−0.098559至0.253847，原始跌幅为−0.000320至0.001080。这些是置换参考区间，不是总体效应置信区间。

多项检验必须保留在结论中。同块七项做Holm校正后，电流、掩码、正常 logit、二元结局的 p 分别0.0035、0.0035、0.025、0.040，`kind` 为0.0915，裕量和原始跌幅均0.094。全部15项条件检验一起作Holm校正时，没有一项低于0.05，最小校正值0.0525。因此条件结果支持继续研究局部参照，不作为已确认独立机制的证据。尤其不能挑100 kA下跌幅的0.011，忽略50 kA下的0.190。

## 可以登记覆盖片段，不能把相似性链当物理 regime

360行只有四种首点掩码，其变化只涉及第0和第1位，其余21位在该数据中不变。按原序列出现五个连续覆盖片段。

| 排名 | 炮号范围 | 炮数 | `mask0[:2]` |
|---|---|---:|---|
| 1至68 | 54157至64697 | 68 | True, True |
| 69至75 | 64835至65067 | 7 | True, False |
| 76至137 | 65944至71415 | 62 | False, False |
| 138至188 | 72419至75657 | 51 | False, True |
| 189至360 | 76861至96375 | 172 | True, True |

这是诊断可用覆盖的登记，不是已认证仪器升级或运行场景切换。首末片段掩码相同，不能仅因间隔远就定义为不同物理工况。

在四块内，用相邻 `mask0` 相同且电流比值不超过1.25串成局部相似链，共89条，31条只有一个炮。最长各块为27、13、18、21炮。271/356个同块相邻对满足该工况代理，但12条链的全链电流最大最小比已超过1.25，最大1.4253。例如64258至64562的六炮链，每一对都合格，全链却跨42.5%的电流比例跨度。局部相似不具传递性。链内还允许混合结局，结局不能替代工况认证。

若以后需要工况归类，应先定义当时可观测的固定参考或全组包络，并保留不匹配供体时的回退。不能用未来结局选类，不能仅把最近一炮设成健康模板。本次没有实现或验证这种在线归类。

## 充分证据与不充分证据

- **足够支持这360炮中有可观测局部连续性。** 首点电流在四块均更近，掩码在前三块更近、第四块恒定。相邻小炮号差的首点电流更近。该主张不需要把结局当工况。
- **足够支持封存正常 logit 峰值的总体描述性邻近优势。** 主对照及同工况供体对照都较近，固定结局和TN/FP串的条件置换仍有局部迹象。但第二块反向，多重检验和既有开发暴露限制了机制主张。
- **不足以证明稳定物理 regime。** 缺少绝对采集时间、PCS工况、配置版本及稳定段认证。90炮块是评价块，五个掩码片段是覆盖片段，89条链也不是89个物理工况。
- **不足以把结局聚集解释为学到了风险。** 二元结局一致优势约6.19个百分点，完整 `kind` 较弱，均是已解决结局的事后关联。正常峰值又含随历史变化的对齐和报警状态，原始跌幅峰值还受观察机会影响。没有证明新的前兆方向、校准收益或同预算及时检出收益。
- **不足以选择“上一炮正常峰值就是下一炮阈值”。** 第二块正常分数峰值反向，原始跌幅细分工况后不稳。整炮最大值的可预测性也不等于能给后续正常炮FPR保证。

从代码仓库根目录运行。只需要现有CPU Python和NumPy，输出JSON到临时文件，不改输入。[已保留的机器可读结果](temporal_neighbors.json)。

```bash
CUDA_VISIBLE_DEVICES='' OPENBLAS_NUM_THREADS=1 python -I \
  research/east360-online-adaptation/transfer_review/temporal_neighbors.py \
  --repeats 1999 --seed 20261127 > /tmp/temporal-neighbors.json
```

脚本不导入项目模型模块、不访问HDF5或网络。它断言原顺序、360成员、四块、结局与 `kind` 一致性、360个父首报与跌幅账本一致、正常峰值窗口覆盖全记录及所有使用数值有限。字段单位、真实结局和时间元数据的外部认证不在这些断言中。
