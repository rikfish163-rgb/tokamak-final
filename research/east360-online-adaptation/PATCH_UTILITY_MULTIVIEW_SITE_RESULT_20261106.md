**决定：不晋级至 J-TEXT VAL 或 EAST。** 缺诊断对照把单写入有益

## 1. 新增教学实例有没有帮助？

沿用[事前方案](PATCH_UTILITY_MULTIVIEW_POLICY_PROTOCOL_20261106.md)：
三个已封存的 J-TEXT TRAIN1353 视图，同一炮的各视图始终
在同一折。五次轮转，每次三折拟合、一折校准、一折留出。
每类先对独立炮等权，再分给有支持的视图、块和动作；其他
视图不作当前炮运行时输入。三训练方案使用相同既有特征、
硬标签三分类、L2 .03 与每炮至多一次因果写入。共同门槛
在校准折要求三个视图各自没有新增误报或丢失及时。
这不能保证未参与校准的炮也安全。

| 训练条件 | 前缀信息 | 原生：及时／误报 | 缺 MNM | 缺 MNM 和 CIII |
|---|---|---:|---:|---:|
| 冻结 | 不写入 | 182 / 117 | 178 / 113 | 179 / 200 |
| 只用原生 | 风险与时钟 | 182 / 117 | 178 / 110 | 179 / 200 |
| 只用原生 | 真实 | 182 / 116 | 178 / 113 | 179 / 200 |
| 只用原生 | 倒序 | 182 / 117 | 178 / 113 | 179 / 200 |
| 各视图单独 | 风险与时钟 | 182 / 117 | 178 / 113 | 179 / 200 |
| 各视图单独 | 真实 | 182 / 118 | 178 / 115 | 179 / 202 |
| 各视图单独 | 倒序 | 182 / 116 | 178 / 113 | 179 / 201 |
| 三视图合并 | 风险与时钟 | 182 / 117 | 178 / 113 | 179 / 200 |
| 三视图合并 | 真实 | 182 / 116 | 178 / 113 | 179 / 200 |
| 三视图合并 | 倒序 | 182 / 117 | 178 / 113 | 179 / 200 |

所有保守臂和所有开放臂都没有改变及时炮数，也没有及时炮互换。
合并真实臂在原生去掉 1053001，**仅原生训练也去掉同一炮**；
双缺失消去 1055272 但新增 1056655，净数 200 不能解释为
“无新增误报”。同动作恒偏移在这三个视图均回到冻结计数。
风险／时钟单用原生在缺 MNM 减少三个误报，原生则一增一减；
这是动作范围内的对照，不能记为真实诊断时序的贡献。

**为什么没有及时收益：** 对全部六个可救“视图—炮”组合
（五个原炮），真实前缀的三种训练方案在可写窗口里均**从未把
有益动作排第一**，即使事后提供应写的时刻也没用。只有单视图
倒序对照在双缺失的 1055239 的一个窗口排对，实际策略并未
救回。合并真实在三个视图分别可将 3／2／7 个安全炮的有益
动作排首位，说明评分函数非恒定，但可见信息及现有模型的
结合没有学出迟报需要的方向。不能以此断言原始诊断信号中
绝无可用信息。结论是**扩大这批硬标签的覆盖不足以修复现有
选择器**，不再扫它的弃权门槛。

## 2. 改到另一层能扩大可救范围吗？

按[等动作层位方案](PATCH_UTILITY_SITE_PROTOCOL_20261106.md)，每个
视图纳入全部静态迟报，以及原输入动作存在有益或有害单写入
的安全炮。两个位置复用逐值相同的数据 token 残差，不写
CLS；同一正负方向共享尺度并同时满足相同三个历史点的
实际 logit 偏移 ≤.10。没有重新训练选择器。适配位置值得
单独检验的设计背景可参考 [AdaptFormer（NeurIPS 2022）](https://proceedings.neurips.cc/paper_files/paper/2022/hash/69e2f49ab0837b71b0e0cb7c555990f8-Abstract-Conference.html)；
该视觉任务不验证本实验，也没有复现其适配器。

| 视图 | 迟报／安全病例 | 输入端：可救迟报／可消误报／可新增误报 | 两层之间：同三项 |
|---|---:|---:|---:|
| 原生 | 6 / 36 | 2 / 8 / 28 | 0 / 2 / 4 |
| 缺 MNM | 10 / 44 | 1 / 9 / 35 | 0 / 1 / 4 |
| 缺 MNM 和 CIII | 9 / 71 | 3 / 19 / 52 | 0 / 6 / 9 |

表中均为**单次写入存在性**，同一炮可以有有利和有害候选，
没有可部署的选择，更不是整套数据的 FPR。比较范围为同一
输入方向族，不排除针对中层重新生成的方向另有作用。
两位置共有 19,584 个可用非零动作；全部同锚点恒偏移都
没有救回迟报。中层相对输入端的未来风险变化 RMS，按视图
分别取有效炮—视图中位数，为 **0.161、0.158、0.151**；
相同激活幅度没有等同于相同未来 logit 效力。它与潜在误报
及迟报恢复同时减少一致，但不是证明所有中层适配都较弱。

原网络独立复跑的例子：缺 MNM 的 1053940，同一动作在
输入端首报提前 107.56 ms，在两层之间仍为 6.56 ms；
另三个安全病例每视图一例，在中间层也能真实消除误报，
说明不是中层路径没生效。其余见逐炮记录。
