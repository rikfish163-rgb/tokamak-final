# 匹配危险与安全轨迹：有限内部动作容量实验

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run
- Origin Date: 2026-11-06
- Verification Status: predeclared before paired data collection or effects
- Version Label: peak_contrast_capacity_v1

本轮使用 [整块实验](WHOLE_BLOCK_UPDATE_RESULT_20261106.md) 之后提出的
假设。目的：在较可比的危险、安全窗口上区分全块分数平移和选择性形状
变化，并比较写入位置。不是模型上线、全炮成绩或物理因果识别。

## 匹配与作用时钟

只读原 J-TEXT TRAIN1353 的原始 HDF5；冻结基模、原归一化、三种子
差分头、双 32 点成熟时钟、原风险阈值、原标签均不改。每个结束的破裂
炮用 HDF5 结局及 `10 < lead ≤ max(25, AdvancedTime)` 定义后续
正窗；即使原模型早已报警，也保留这些教学样本。安全炮只纳入
完整的下一 32 点块。所有候选在成熟时至少两个诊断组可用。

同一破裂炮／安全炮分别只匹配一次。边必须同时满足：成熟时的已到达
时间差 ≤64 ms、冻结分数差 ≤0.25 logit、前后块终点的分数变化
差 ≤0.35 logit、两块同通道的 11 位有效掩码差 ≤3、三个诊断组
的有无模式相同。用最大配对数后最小归一化平方距离选配对。另独立
构造双方成熟风险概率均 ≥ 原阈值−.15 的高风险配对；两个样本集
可能重叠，不并为一组。匹配不看后续模型效应。
方法上的最优匹配先例见 [Rosenbaum](https://www.tandfonline.com/doi/abs/10.1080/01621459.1989.10478868)；
这里不将可测协变量平衡视为消除混杂或证明物理因果。

## 真实前向与对照

两个位置都临时改第一层注意力之前的仿射。原位置覆盖全部有效 token
含 CLS；新位置只覆盖末四个数据 patch 的有效项，不直接改 CLS。
两个位置都从同一冻结差分头取三族有符号及三族绝对值辅助梯度，
按成熟风险雅可比分解切向与法向。试探六族单方向、一个法向、两个
族和方向，每种的正与负，均以参数范数 .35 匹配。切/法向是零点
导数分解，有限步结果仍使用真实前向。任一位置或匹配一侧该向量
范数太低（≤1e−6），两个位置两侧该动作共同停用；原四对照的非零
共同支持也必须在三种子两侧满足。比较的是相同参数半径，不声称
token 数不同的两位置具有相同激活扰动。所有固定方向仅由已到达
信号产生，在下一块生效，不将任何动作累积到别炮。新位置也不访问
采样后的结局、段标签或信号。

对每个动作，保存实际未来曲线以及同一动作在成熟点的反事实改变量。
从未来曲线减去这个常数，只作**分析**，不接入报警器。危险峰和
配对安全峰比较相同相对时间点；另检查完整安全块和原及时首报前缀。
可用动作定义：危险的扣平移峰增 ≥.05 logit，同时间安全扣平移峰
不增超过 1e−6，没有实际新增安全越线，且原及时首报所在块不被
推迟或取消。报告固定方向和其反向的全部结果，不挑最好方向来
宣传成绩。配对允许后验试探可用动作，仅作为有限容量；单列真正
迟/漏报的正窗候选越阈，已及时炮不算救回。按炮对重采样，种子
先在炮对内汇总；没有独立泛化结论。

## 下一阶段准入

配对预检至少 40 个独立炮对、至少 12 个独立高风险对，且某位置在
至少 5 个高风险对上有两个或更多种子存在上述动作，才进入基于该
动作集的源训练。否则，优先辨别支持、动作可达性和已到达信息三者
中卡住哪一项；不能把小样本事后可行看作在线收益。源验证仍必须
完整盲封存并优于等分数、不增加误报；最终验收仍是固定 EAST 两流
及其提前量/FPR 限制，当前不触碰 VAL、TEST 或 EAST 的信号和结局。
