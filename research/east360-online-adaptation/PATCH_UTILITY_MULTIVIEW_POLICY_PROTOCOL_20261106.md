# 下一步：成对观测视图能否帮助学到因果更新选择

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: plan for next execution
- Origin Date: 2026-11-06
- Verification Status: proposed after the capacity audit; no policy run
- Version Label: patch_utility_multiview_policy_v1

原生 10 个与三视图合并 39 个单动作有益炮，是两个可比较的
监督条件，不是 39 个在线收益。问题是：**增加真实配对实例，
能否改善有害／有益动作的排序和实际首报，而不靠报警门槛？**

1. 使用三个已封存动作库和同一个 J-TEXT TRAIN1353。保留原
   五折，按 shot ID 放置全部视图；外折全部视图不影响拟合、
   归一化或校准。采用原三拟合、一校准、一留出。比较
   native-only、view-only、pooled-view 训练；共同输出仍为
   当前块有益、有害或无硬变化的排序，不改报警阈值。
2. 先延续单写入三分类模型，隔离监督支持这个变量，不加
   新神经网络。权重按硬类、原炮、该炮在此类有支持的
   观测视图、该视图有支持的块、块内动作逐级均衡，
   同一炮多个视图不会增加它的类内总权。固定 L2 .03，
   单次写入和独立校准延用稀有事件方案。动作分仍惩罚
   害处，训练可用标记只有当前观测状况、到达波形和静态
   风险上下文；真实结局和其他掩码视图不进入运行时输入。
3. 风险／时钟、真实、反序三类特征同维；真实臂同一动作索引
   另回放恒定锚点偏移。主比较在两个缺失视图各自固定静态
   参照上完成，同时报告原生的退化情况。公共选择门槛在
   校准折上从固定分位数网格求取；保护必须在每个参与视图
   分别满足，不能由一视图增益抵消另一视图新增误报。
   每次选择只在当前块确定，最多首次接受一次，不回看整炮选时刻。
4. 报告每视图的新增／丢失及时、消除／新增误报、写入炮，
   以及固定序列中的排名能力和真正实现率；同一物理炮的
   多个获益视图同时列出但去重。要进入源 VAL，真实 pooled
   必须每视图无新增误报、无损失原及时，在新视图至少救回
   一个迟报且风险／时钟、倒序、等分数都不能复现。同样
   给出与 native-only、view-only 的净比较，避免借掩码
   难度或只更换拟合样本冒充机制增益。

实施细则（任何拟合与留出打分前固定）：沿用单视图实验完全
相同的前缀特征，不追加视图 ID、其他视图的预测或参数维度。
视图内当期可用性只通过原因果特征和动作可用掩码反映。
每个方案的校准网格在校准折合并三个视图的可写块最高分计算，
含 .50/.80/.90/.95/.975/.99/.995 分位与 ±∞；先检查三个
视图均无损害，再最大化去重救回炮、去重消除误报、较高门槛。
另报 −∞ 开放臂，仅为首可写位置的对照。独有收益在原炮
ID 层认定：对照若在任一缺失视图也救回该炮，则不算独有。

若这个阶段仍失败，结论只能是“在更丰富的受限动作教学下，
当前到达特征仍不能稳定选对”，停止重复同一选择器；改为
比较**不同内部位置或不同物理变化反馈的真实可纠错范围**。
即使通过，也只锁定一条候选再进源 VAL。EAST 仍需从既定
冷启动验证炮内独立、炮间独立、联合及同预算对照，固定
FPR≤.20 主要求与 .10/.15 补充，不能用这里的反事实代替。
