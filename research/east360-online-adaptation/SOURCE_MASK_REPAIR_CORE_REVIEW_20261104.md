# Source mask-repair core: CPU implementation review

## Scope and interface

Implemented only the small internal embedding repair and CPU/synthetic tests. No fitting, optimizer, raw shots, GPU execution, or change to shared source, data, train or evaluation code. This is not signal recovery or evidence of alarm efficacy. The plan is `SOURCE_MASK_REPAIR_PLAN_20261104.md` (SHA256 `c1e2562e8c5c0cec12ca57bede1512bf463a2c0e67045bdfd42e0713e4677c8c`).

`TokenRepair()` owns only `LayerNorm(66) → Linear(66,16) → SiLU → Linear(16,64)` (2,292 parameters), with a zero final layer. `forward(base, repair, x, a, enabled=True)` returns `logit`, `forecast`, `embedding_before`, `embedding_after`, `embedding_delta`, `missing_fraction` and `repair_tokens`. It checks native source configuration, eval/frozen flags, tensor shapes, dtype/device, observed-value and repair finiteness, and source/repair parameter storage separation. Runtime checks do **not** authenticate in-memory source weights; the caller must load the qualified checkpoint securely.

For each eight-frame patch, the denominator is the number of frames with any available channel, excluding padding. CIII/MNM availability fractions, in that order, join the original 64-vector as network input. `missing_fraction` is the corresponding B×16×2 missing proportion, defined as zero for an all-padding patch. `repair_tokens` is the B×16 eligible mask when enabled, otherwise all false; zero-initialized eligible tokens can still have zero deltas. Only eligible patch embeddings change, without modifying values or availability. If no token is eligible or repair is disabled, the hook returns the original embedding object without a differentiable zero addition. The hook is removed even on error. Use one synchronous forward at a time per shared base: hooks are temporarily attached to that base.

Each correction is RMS-clipped to 0.25, with a relative safety margin of four dtype machine epsilons when clipping and float64 scaling before casting. The margin handles floating-point roundoff, including extreme finite float32 corrections. No physical units or recovered observations are implied.

## Verification

TDD: the new tests first failed because the module did not exist. Additional strict-RMS tests exposed ordinary rounding and subnormal-scale-factor overshoot in intermediate implementations; both were corrected and retained as regressions. Final CPU result: **36 passed in 1.78s**; `ruff check --no-cache` passed. Tests used synthetic inputs and the existing qualified checkpoint, whose SHA256 is `c7270c1ea3652db2e30e972d4ca9a4a2d33220a68e4a3765c8b7f5bcceeaeb02`.

Tests cover architecture/zero initialization; complete, partially missing, mixed, all-padding and disabled cases; valid-frame fraction denominators; exact no-op path and unchanged inputs/source state/flags/gradients; nonzero manually set repairs and strict RMS for 768 varied capped tokens plus extreme finite values; finite gradients only into repair at zero and in the clipped branch; hook cleanup on repair and source exceptions; and invalid source, shape, finiteness, dtype, device and storage aliasing. Zero initialization is bitwise equal to native inference in `no_grad` with CPU MHA fastpath both enabled and disabled, and in gradient-enabled comparisons when both models take the same attention path.

**Attention-path limitation:** in a CPU synthetic comparison with grad mode enabled, frozen inputs and CPU MHA fastpath enabled, the native frozen baseline and differentiable repair path can select different MHA kernels. At zero repair, one observed logit maximum difference was `0.0` and forecast maximum difference was `8.344650268554688e-7`; this is an example, not a general error bound. With fastpath disabled, or both paths made differentiable, that example was bitwise equal. Future gradient-enabled baseline comparisons should explicitly use the same MHA path (for example, caller-managed fastpath disablement); the core does not change global backend settings. Fully observed/disabled no-op paths remain exact without changing backend settings.
