# 稀有首报翻转监督与每炮一次写入：源域探索协议

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run and independent validation
- Origin Date: 2026-11-06
- Verification Status: frozen before running this exploratory follow-up
- Version Label: patch_utility_sparse_train_v1

此协议在看过原始岭选择器的结果后提出，仍然使用同一完整 J-TEXT
TRAIN1353 训练集作源域诊断，**不是新的独立确认**。原动作库、父模型、
动作保护、报警阈值、炮号和 HDF5 口径不改。无需再运行 GPU 或打开新的
波形和标签。原选择器已在实际限幅动作库上失败：只有 30 个单写入的
有利硬标签，开放选择器几乎每块都写，校准保护后全不写。问两个具体问题：
去掉纯风险峰软代理、平衡罕见翻转，能否学对有用方向？把策略改成每炮
最多一次写入，能否让训练标签与执行效用一致？

1. 同一选择时钟 m=63+32k。如果冻结风险到 m 已经越阈，或该炮已执行过
   一次非零写入，则不再写；否则当前块选择最高分的可用非零动作，只有
   严格超过门槛才接受。这个状态机不需要结局，不回选整炮最高分。
2. 沿原 ID 五折，训练三折、校准一折、评分另一折。对训练折且尚未
   越阈的可用非零动作，用单写入硬标签 {-1,0,+1} 拟合三分类线性
   softmax。类别等权；每类内每炮等权、炮内每块等权、块内各动作
   等权。加权标准化，L2 系数 .03，确定性 LBFGS。动作分取
   logit(+1) − log(exp(logit(0)) + 2 exp(logit(-1)))。
   这是少数类重加权后的排序分，不报告为真实概率。
3. 对风险／时钟、真实、反序三视图应用同一规则；在这三视图上也
   复用原拟合的岭分数，给予完全相同的单写入与校准流程作对照。
   真实视图的实际写入另用同锚点恒偏移作配对回放。
4. 校准折的可写块各取最高可用动作分；门槛候选为 −∞，这组块
   最大值的 .50/.80/.90/.95/.975/.99/.995 分位，以及 +∞。
   原有无新增误报且不丢原及时的保护条件不变；按净新增及时、
   消除误报、门槛从高到低的重要性排序，平手选择更高门槛。
   另报第一可写块即执行的 −∞ 开放对照。
5. 把失败分为排名和时机：报告留出折中，在某个可写块排名第一
   的真实有利单动作覆盖哪些炮。这一步事后知道应该等待哪一块，
   **不是**策略成绩。实际只报顺序执行的完整首报，以及写入
   后的逐炮真实单动作效用；同一炮的候选不视为独立证据。

若真实保守规则无新增误报、无损失及时，且新增 ≥1 个及时或消除 ≥3
个误报，且存在三个信息／标量对照不能复现的炮，才值得事先锁定
新的源 VAL 验证。本探索不会直接进入 EAST，也不修改 EAST 方法、
标签预算或 FPR 上限。
