## 问题与不变条件

上一轮发现70868及时区间风险在经验密度映射后下降。仅比较不训练的源模型不能判断此映射是否也损害后续少量监督适应。因此本轮重新训练四种准备条件，分离输入映射与表示统计损失。不是新模型有效性的预先结论。

沿用20个历史TRAIN炮的四折划分，每折3破裂12安全准备、1破裂4安全留出。每折从原始J-TEXT源归档重新初始化。所有归一化、训练及预测头拟合只用源TRAIN及该折15炮，留出炮信号只在因果预测阶段访问，结局只在所有预测封存后用于评价。

这20炮已参与开发，分折不使它们成为独立未来验证。按结局元数据分层划分，非严格时间投运模拟。禁止用本轮TPR与TEST360直接相减。

## 四组与共同训练预算

| ID | EAST经验ne_nG映射 | 表示统计损失 |
|---|---|---|
| raw_bce | 不施加；必要输入处理保持 | 无 |
| raw_moments | 不施加；必要输入处理保持 | 按已知点标签匹配均值与协方差 |
| mapped_bce | 该折15炮估计的中位数比例 | 无 |
| mapped_moments | 同上 | 同上；复现上一轮准备条件 |

每组均用512步Adam、学习率1e-4、梯度范数裁剪1；每步源/目标各32个平衡窗口。

\[
L=\tfrac12(L_{\mathrm{source}}+L_{\mathrm{EAST}})+c L_{\mathrm{moments}},\qquad c\in\{0,1\}.
\]

两个监督项均为原风险头的点标签交叉熵。所有组在每折必须具有逐条相同的炮号、端点和标签抽样；无统计项仍记录其数值但不使其参与梯度。仅更新输入投影、位置/CLS和第一Transformer块。原风险头、第二块及阈值0.7258946895599365保持不变，不重新训练J-TEXT归档。

随后每组256步、学习率3e-4，仅拟合同一个25点诊断预测头，源目标各32自然窗口；抽样身份逐条匹配。临时炮内更新完全沿用原到达信号预测反馈，学习率1e-3、裁剪1、间隔128点，首次256点后更新，每炮重置；不加检索模块、输出修正、报警调参或炮间写回。

四组各有static与intra两臂，共8条结果线。先保存所有曲线，再获取留出结局。评价严格lead>30 ms，另列>3000 ms报警。完整报告4破裂16安全，不以逐时间点数量当作独立样本。

## 比较、反例与边界

主要问题是映射与统计损失各自对TP/FP及炮内增量的影响，报告全部四种条件，不仅报告最佳组。同步检查63226、70868及时区间峰值以及全部误报翻转身份，但不依据这两炮修改本轮训练。

mapped_moments应逐值复现上一轮四折准备参数与static/forecast预测。若不一致，先解释实现差异，不使用未核实结果替换旧证据。

这轮不运行TEST360，不进行阈值或学习率扫描。只有出现满足FPR≤0.20、及时TP不减且净增益为正的炮内候选，才具备后续继续验证的理由；4破裂炮不足以证明稳定收益。所有条件均失败时，应转向检查标签时窗、训练采样与危害路径覆盖，不能继续添加分数抬升补丁。
