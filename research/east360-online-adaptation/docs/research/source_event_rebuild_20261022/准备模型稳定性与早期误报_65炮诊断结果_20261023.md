## 1. 本轮最重要的结论

当前不能把“少量EAST准备已经解决，只差炮内损失”当作前提。在同一批65炮上，四份15炮准备模型的静态误报数为5—31，及时检出数为0—4。此前20炮交叉验证的低误报率，不能直接推广到其他历史工况。

炮内更新也不是简单的“完全不动”：一份联合准备模型救回了75604，但同时新增10个安全炮误报；另一份没有增加及时检出，却新增5个误报。原始信号拟合误差下降与预警收益没有形成可靠对应。

还有一个明确的时间边界：第2折联合准备模型在第一次临时更新生效前已经误报13个安全炮，13/61=0.2131。只改之后的更新，不可能让这一组的首次报警FPR降到0.20以下。**这不是学习率大小的问题，而是当前方法已来不及改变这些判定。**

本轮没有新训练J-TEXT、没有新训练EAST准备模型、没有炮间更新；是对既有固定检查点的扩大诊断。没有实现新的达标系统，研究目标仍未完成。

## 3. 完整结果

下表每格为“及时检出/4，误报/61”。同一行static→intra才是炮内贡献；A→B还包含既有准备过程变化。

| 原准备折 | A静态 | A炮内 | B静态 | B炮内 |
|---|---|---|---|---|
| 0 | 4，31 | 4，30 | 4，26 | 4，26 |
| 1 | 0，5 | 0，5 | 1，6 | 1，11 |
| 2 | 4，27 | 4，26 | 4，29 | 4，29 |
| 3 | 2，21 | 2，21 | 3，22 | 4，32 |

四折等权平均只是描述性汇总，不是四个独立seed的均值置信区间：

| 方法 | TPR>30ms | FPR | J |
|---|---:|---:|---:|
| A静态 | 0.6250 | 0.3443 | 0.2807 |
| A炮内 | 0.6250 | 0.3361 | 0.2889 |
| B静态 | 0.7500 | 0.3402 | 0.4098 |
| B炮内 | 0.8125 | 0.4016 | 0.4109 |

B炮内虽然平均TPR和J略有提高，FPR却从0.3402升到0.4016，不能满足FPR≤0.20的要求。不能只展示TPR=0.8125或正的ΔJ。

秒级过早报警数量按折0/1/2/3分别为：A静态与A炮内均2/0/0/0；B静态与B炮内均1/1/0/0。其中第1折B唯一及时炮75604提前3003ms报警，必须连同这个事实报告，不能当作已经准确识别临近破裂的证据。

## 4. 哪些炮被救回，哪些被改坏

### 4.1 原准备模型A

四折均没有及时检出翻转。第0折消除62557误报，第2折消除85330误报，其余折总计数不变。及时风险峰值对安全炮峰值的排序AUC在四折均未改变，因此这两个减少误报的现象不能解释为广泛提升了危险区分能力。

### 4.2 联合准备模型B

- 第0折：消除61059误报，同时新增79479误报，净FP不变。
- 第1折：新增77460、77639、83690、83954、87581五个误报，没有增加及时检出。
- 第2折：及时检出和误报身份都不变。
- 第3折：75604由未报警变为提前433ms报警，但新增62557、67499、72792、77161、77270、77460、80087、80557、80920、83954十个误报。

第3折75604的及时区间最高概率从0.574558升到0.775691，确实跨过固定门槛。这是实际神经更新产生的局部成功；伴随十个误报，不能认定整体方案成功。对应安全炮的升分不应被忽略。

准备过程本身也不是处处损害TPR：B相对A，第1折增加75604的及时判定，第3折增加77412的及时判定。此前63226在准备阶段被改坏的证据仍成立，但不能扩大成“准备只会统一压低所有炮风险”。

## 5. 不是单纯更换阈值就能解决

这是**主实验完成后追加的诊断**。对破裂炮取提前量>30ms区间的风险峰值，对安全炮取有效记录全程峰值，用这65炮真实结局计算排序及最佳单阈值上限。

它使用了被评价炮的答案，只回答“现有曲线有没有可能靠一个阈值同时满足要求”，**不能作为校准后的留出成绩，也不能将该阈值用于部署**。

下表三个数依次是在FPR≤0.10、≤0.15、≤0.20约束下最多及时检出的炮数，分母均为4。A炮内与A静态的三个计数相同。

| 折 | A静态上限 | B静态上限 | B炮内上限 |
|---|---|---|---|
| 0 | 0 / 2 / 2 | 0 / 1 / 2 | 0 / 1 / 2 |
| 1 | 1 / 1 / 1 | 1 / 1 / 1 | 0 / 0 / 1 |
| 2 | 0 / 2 / 3 | 0 / 1 / 2 | 0 / 0 / 1 |
| 3 | 0 / 0 / 0 | 0 / 0 / 1 | 1 / 1 / 1 |

当前16条模型/折/模式组合，没有一条能在FPR≤0.20下同时检出全部4个破裂炮，即使事后知道答案也不行。这里证明的是**这些固定分数与单阈值的局限**，不是对所有架构或未来方法的上限。

及时峰值排序AUC按折0/1/2/3为：

- A静态、A炮内：0.790984 / 0.741803 / 0.803279 / 0.663934。
- B静态：0.758197 / 0.668033 / 0.782787 / 0.696721。
- B炮内：0.762295 / 0.639344 / 0.762295 / 0.647541。

这是按炮及时峰值的排序诊断，不是所有时间点AUC。B炮内在第3折增加一个及时炮，但排序AUC下降，符合新增大量安全炮高风险的观察。没有单凭AUC变化解释物理因果。

## 6. 首次更新前的误报：后续微调无法撤销的下限

第一份临时更新只影响索引256及之后的预测，之前的报警已经发生。按当前“首次报警”规则，有：

\[
\mathrm{FPR}_{\text{整炮}}\;\geq\;
\frac{\text{首次更新生效前已报警的安全炮数}}{\text{安全炮总数}}.
\]

| 折 | A更新前误报 | A对应FPR下限 | B更新前误报 | B对应FPR下限 |
|---|---:|---:|---:|---:|
| 0 | 10/61 | 0.1639 | 9/61 | 0.1475 |
| 1 | 1/61 | 0.0164 | 3/61 | 0.0492 |
| 2 | 11/61 | 0.1803 | 13/61 | **0.2131** |
| 3 | 6/61 | 0.0984 | 7/61 | 0.1148 |

这一下限以保持当前父模型、更新前预测及首次报警规则为条件。第2折B即便让其余所有安全炮都不再误报，仍达不到0.20。应改善进入本炮时的模型或研究更早的有效反馈，而不是期望炮末更新抹掉此前错误。

**记录前256点不是物理放电的前256ms。**例如历史记录可能从绝对时间3s开始，已经处在其他运行阶段。本轮不据此判定电流爬升、装置启动或安全阶段，也没有删掉前256点报警。

已有研究记录中曾发现其他父模型的早期误报；本轮不是把这一概念当新方法，而是在当前固定四折模型及另外65炮上量化实际下限。已有反馈时钟实验保持首次更新在256点；不能把简单重复缩短后续间隔当成新的解决方案。

## 7. 下一步研究重点

1. **先重新建立准备模型的稳定性检查。**把不同历史工况的安全炮和破裂炮同时纳入检查；同一20炮小集合上的好结果不再作为唯一通过依据。准备身份与训练采样的贡献需要另外做匹配实验，不能从本轮折差异直接选“最好的一折”。
2. **检验风险相关的表示变化，而非仅要求信号拟合变好。**A、B各9496次炮内更新的已到达目标误差都下降，但B仍新增误报。该数值检查涉及原实现的梯度/无梯度执行上下文，不把极小差异单独解释成实质拟合改善；预警变化由完整曲线另行确认。
3. **把反馈可用时点纳入设计。**需要区分何时已经有一个可用的真实未来目标、何时算法才开始更新、哪些误报此前已发生。更早反馈是否有用仍须对照，不能预先承诺。
4. 保留纯炮内与炮内＋炮间的独立比较目标；报警政策继续单列。当前候选不晋升，不改合格J-TEXT归档，不把开发结果宣称为独立验证或新物理规律。

方法背景核读：[Zhao等，On Pitfalls of Test-Time Adaptation，ICML 2023](https://proceedings.mlr.press/v202/zhao23d/zhao23d.pdf)，本轮阅读摘要、§4.2部分、§5相关段落及§6相关段落。该文展示适应收益依赖起始模型与分布变化，不能从一种场景推广到所有场景。它不证明本项目具体通道的失效原因，也不能为当前过高FPR开脱。本轮未声称全文精读或完成100篇全文调研。
