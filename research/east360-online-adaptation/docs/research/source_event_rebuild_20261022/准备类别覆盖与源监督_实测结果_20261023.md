# 准备集类别覆盖与源监督：四组实测结果

## 结论

历史85炮四折留出中，已知类别选取4破裂＋16安全，静态及时检出从1/8提高到3/8，误报从8/77变为9/77。
但炮内更新没有增加及时检出，反而新增1个误报；去掉源分类监督也没有恢复破裂识别。
**准备数据的选择影响静态结果，但当前炮内方法仍未达到目标，四组均不晋升。**

这是历史TRAIN85的开发诊断，不是TEST360结果。只有8个破裂身份，单个翻转改变TPR 0.125；
四折是不同准备模型，不是四次独立实验。未做显著性或稳定泛化声称。

## 实验条件和信息使用

沿用[事前约定](准备类别覆盖与源监督_四组事前约定_20261023.md)。每折用候选63/64炮选20炮，
留出身份分别为3D19S、3D18S、1D20S、1D20S，每个身份只评价一次。
无标签选样四折训练集的破裂数为1、3、5、3；已知类别选样每折均4D16S。
已知类别方法使用候选池的shotlist类别，不能称为只访问20个标签，也不是公平盲查询比较。
四折选中身份的并集：无标签组44炮，已知类别组39炮；20是每个模型梯度训练的EAST身份数。

四组从同一J-TEXT原模型开始，平坦23列；未使用经验密度倍率。
更新输入投影、位置、CLS与第一Transformer块，风险头和第二块冻结。
风险准备512步，预测头256步；有/无源监督严格共用采样序列，目标损失系数始终0.5。
新增12个模型共9216步离线优化，9201次炮内临时更新，主运行215.76秒。
炮内直接预测后25点、已到达后才计算反馈；每炮清除临时参数，没有炮间或报警参数更新。

## 逐炮解释

1. 已知类别＋混合监督相对无标签选样，恢复74412、77412两个破裂的及时报警；
   同时消除6个旧误报、新增7个误报。类别组成和具体身份同时变化，不能把差异只归因于破裂数量。
2. 无标签组去掉源监督，消除60155、61327、64894、72415、75501、85188六个误报，
   但及时检出仍只有1/8。炮内随后又使72415误报。
3. 已知类别组去掉源监督，丢失63824的及时报警，消除3个误报又新增68933误报。
   因此“去掉源分类监督即可解决问题”不成立。
4. 已知类别＋混合监督的炮内新增77203误报，没有救回破裂。
   仅目标监督组炮内TP/FP不变，但77412提前量1167.3→1059.3 ms，不能说风险轨迹完全不变。

## 梯度冲突和阈值诊断的边界

每64步记录一次源/目标分类梯度。无标签仅目标、已知类别混合、已知类别仅目标三组分别有20/32、22/32、19/32次负夹角，
余弦中位数分别−0.1797、−0.1144、−0.2122。说明采样状态存在优化方向冲突，
不证明某个物理通道或25/125 ms标签差别是根本原因；移除源监督的配对结果并未全面改善。

允许用全部评价标签事后挑单一阈值时，FPR≤0.20的最高TP：原模型5/8、
无标签混合静态/炮内均3/8、无标签仅目标均1/8、已知类别两组静态/炮内均3/8。
这是事后诊断上限，不是可部署校准成绩，不能把相应阈值写成已验证部署参数。
