# 两个炮内纠正是否依赖真实信号变化

## Material Passport

- Origin Skill: academic-research-suite / experiment-agent / tdd-workflow / results-analysis
- Origin Mode: controlled ablation + CUDA run
- Origin Date: 2026-10-23
- Verification Status: UNVERIFIED
- Version Label: persistence_control_plan_v1

这是一项顺序追加的开发实验：在独立于参数拟合的10炮校准后，mapped_fixed在相同门槛下
由132TP37FP变为133TP36FP。不能把它立刻解释成学到了有效动力学，需排除一般性漂移或收缩也能造成相同变化。

固定mapped_head_factor20_test360_20261023的mapped_fixed模型与输入映射。
主门槛使用heldout_threshold30_test360_20261023中只由10炮安全峰值确定的alpha=.20门槛，
不重新拟合；原源门槛作为附加对照。TEST360已开发暴露，无新独立验证。
20炮准备＋10炮校准总预算不变，不新增标签或炮间学习。

三臂：static；原真实已到达目标的intra；新persistence_sham。
新臂在每次原定反馈时点保持输入窗口、更新时点、目标可用掩码、损失形式、步长和参数范围不变，
仅把每段后续25点真实值替换为该段预测起点的最后观测值，重复25次。
这个虚构目标并非物理真值，也不是候选部署方法；它故意删除已到达目标中的演化信息。
所有替换均限于已到达片段，不读未来结局；静态风险曲线必须逐值复现原静态。

这是相同步数/步长的对照，不是相同梯度或参数位移的对照。
目标掩码仍继承真实已到达观测，故并未删除全部反馈信息；原预测头与输入也仍包含时序结构。
若sham同样或更好，只能否定“这两次改善必须依赖真实后续数值”的解释，不能断言全部时序信息无效。
若真实目标更好，也只能支持本设置下使用已到达数值的作用，不能直接推断物理规律。

完整360炮全部运行，不只检查两个改善炮。逐炮列出救回/改坏，另报提前>3000ms数量。
先对目标替换做TDD，再用本机rl_env CUDA执行，timeout1800秒。
核查static原样、前256点不变、每炮临时状态重置、源档不变、完整首次报警重计。
预定62765、87537两炮重放新控制；这是根据前一轮结果指定，不称盲选择。
