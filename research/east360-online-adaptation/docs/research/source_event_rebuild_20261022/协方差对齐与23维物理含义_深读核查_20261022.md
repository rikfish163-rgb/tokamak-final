# 协方差对齐、23维物理含义与下一步实验

日期：2026-10-22。范围：保留合格 J-TEXT 源模型，解决 EAST 输入与表示适配。本文区分论文方法、代码事实、实际实验和待验证想法；不是论文复现完成报告，也不宣称已经识别新的破裂物理规律。

## 1. 核心判断

此前仅做逐列均值／尺度处理，不足以回答“跨通道关系是否错位”。但换成协方差矩阵也不自动解决问题。必须依次分清：

1. **是不是同一个物理量？** 阵列视野、探针几何、派生公式不一致，不能只靠归一化解决。
2. **数值坐标是不是一致？** 单位、增益、偏置和缺失编码可以导致同一现象被网络看成不同状态。
3. **通道间的联合关系是否错位？** 这是 CORAL 比逐列缩放多处理的一层。
4. **相同信号组合是否仍对应同样的危险性？** 装置运行区域、破裂原因和类别构成不同，需要任务相关学习，不能仅靠无标签边缘分布匹配。

当前失败不能用“零炮就是很难”搪塞。另一方面，不能把论文的 AUC、另一种特征提取方法或有标签 S-CORAL 成绩直接当作当前冻结 Transformer 的固定阈值成绩。

## 3. 23个字段到底是什么

以下“论文定义”不等于本地提取代码已经认证。现有 HDF5 是处理后的23列；用户确认没有原始密度或提取脚本。本次只读核查的40份记录中，通道属性只有采样率／起点，没有单位与算法版本属性。

| 字段 | 物理含义或论文中的对应量 | 对齐时应保留什么／不能怎么解释 |
|---|---|---|
| Bt | 环向磁场 | 运行水平本身有意义，不能见到装置均值不同就全部消除；本地数值单位还需来源认证 |
| CIII | 碳线辐射 | 受壁材料与诊断响应影响，不等于总杂质浓度；本地 −10 缺失哨兵与真实零值分开 |
| MNM | 极向模数估计 | PGFE-U 针对 EAST 非圆截面使用 SVD；本地原始列存在，但读取器屏蔽，来源待认证 |

| sxr_var | SXR 阵列幅值方差 | 单位是诊断幅值单位的平方；增益和剖面都能改变它 |

### 能从物理约束推出什么

若同一阵列仅发生共同的正增益和偏置变化，`新信号 = g×原信号+b`，则均值变成 `g×均值+b`，方差变成 `g²×方差`，偏度和超额峰度不变。共同乘法增益还会在内外均值比中抵消；加性偏置、区域增益不同则不会抵消。

这是统计定义的代数结果，**不证明本地诊断只发生了这种变化**。但它给出了有物理解释的适配约束：不应让“修正方差”的自由度与“修正均值增益”完全无关，也不应任意旋转偏度、峰度来宣称仪器校准。

## 4. 协方差多处理了什么

以两项信号为例：

\[
C=\begin{bmatrix}\operatorname{Var}(x_1)&\operatorname{Cov}(x_1,x_2)\\
\operatorname{Cov}(x_1,x_2)&\operatorname{Var}(x_2)\end{bmatrix}.
\]

对角线描述每项信号变化幅度；非对角线描述它们是否一起变化。逐列缩放不能改变标准化后的相关系数。CORAL 通过线性组合处理这些相关关系，但相关不等于因果，零时滞协方差也不保留完整时间顺序。

对行向量输入，理想满秩情况下，目标到源的映射为：

\[
x'=(x-\mu_E)C_E^{-1/2}C_J^{1/2}+\mu_J.
\]

其中 `μ` 是均值，`C` 是协方差，`J/E` 分别是 J-TEXT/EAST。先抵消目标域协方差，再施加源域协方差。原 CORAL 常用相反方向处理源样本，再训练分类器；**训练过程不同，不能因公式可逆就声称两个系统相同**。

本轮在源模型既定 asinh 坐标内，先按每个域的标准差标准化，再对相关矩阵加单位阵；固定 ridge=1。它是稳定数值计算的约定，不是根据 TEST 指标选出的最优参数，也不是 Ledoit–Wolf 最优收缩。

## 5. 为什么必须区分工况变化与危险演化

假设短窗里信号是 `x(t)=a+b t+噪声`。即使减掉均值，协方差里仍有 `b bᵀ Var(t)`。如果 `b` 正是多通道持续恶化的方向，强制白化会缩小这一方向。这是具体风险，不是说所有协方差方法都无效。

另一个混淆来自炮级混合：

\[
C_{全部}=\operatorname{平均}_{炮}(C_{炮内})+
\operatorname{Cov}_{炮}(\mu_{炮}).
\]

第一项包含炮内动态，第二项包含不同炮运行水平的差异。两者都可能同时携带诊断变化与真实物理状态，不能自动把第一项叫“危险”、第二项叫“噪声”。因此本轮把总协方差和平均炮内协方差单独比较。

TTT++ 与 Deep CORAL 提醒的另一个问题是辅助任务偏移：信号重建更准不代表风险分类更准。当前线性风险头下，表示改动带来的 logit 变化为 `wᵀ(h新−h旧)`；冻结头并不能阻止这个变化。今后的炮内实验必须检查已到达信号产生的梯度是否有助于后续风险判断。

## 7. 已纠正的问题与仍未解决的问题

已纠正：旧 `robust_all` 的零IQR分支把稀疏活动误写成“常量”。新回归测试构造127个零和1个非零，确认IQR虽为零、方差仍大于零。现在日志区分 `zero_iqr_unidentifiable_identity`；映射数值仍是原先的单位映射，既有预测与成绩没有变化。

同时更正“模数是离散类别”的描述和历史数据字典的电阻、密度、位移、阵列统计等明显错误。没有顺手更改旧模型的输入掩码，也没有重新解释旧实验成绩。

旧实验的代码快照与报告保留；当前源码有更正，因此旧审计器若要求“当前代码SHA等于旧运行SHA”会报告差异。这是版本变化，不应通过改写旧SHA消除。复现旧运行应使用其封存快照，新实验使用新的协议与代码SHA。

未解决：`ne_nG` 的提取单位／公式来源、`MNM` 的具体提取版本、阵列视野一致性；更没有证据证明全局无标签对齐已能区分“新工况”与“新危险”。

2. 20炮总协方差相对于20炮对角尺度，减少4个FP（81017、85632、86930、93641），损失1个及时TP（61629）；ΔJ=3/180≈0.0167。这隔离了相关性修正的增量，但不能掩盖系统仍有95个误报。
3. 相对于20炮密度基线，在共同340炮中，总协方差救回35个TP，却新增68个FP；平均炮内协方差救回33个TP，却新增64个FP。没有以“TPR提高”单独包装成功。
4. 只平移辐射均值就已产生大部分敏感性变化；本轮不支持“主要缺失仅是通道间相关性”这一解释。也不能据此否定真正的 source→target 重训 CORAL 或深层条件适配，因为本轮没有实现它们。

### 是否只是原阈值不再合适？

另对同一共同340炮做事后工作点扫描，**允许此诊断查看全部340炮结局，因此绝不是可部署的在线成绩**。没有把扫描出的阈值写回模型。及时峰值排序AUC与普通所有端点AUC不同：破裂炮只取提前量>30ms的风险峰值，安全炮取整炮峰值。

| 对照 | 及时峰值排序AUC | FPR≤0.10事后TPR | FPR≤0.15事后TPR | FPR≤0.20事后TPR |
|---|---:|---:|---:|---:|
| 原始静态 | 0.7360 | 0.5225 | 0.5843 | 0.5955 |
| 20炮密度倍率 | 0.8005 | 0.6124 | 0.6573 | 0.6966 |
| 20炮＋辐射对角尺度 | 0.8025 | 0.6461 | 0.6798 | 0.7303 |
| 20炮＋辐射总协方差 | 0.8034 | 0.6461 | 0.6910 | 0.7247 |
| 20炮＋辐射炮内协方差 | 0.7939 | 0.5730 | 0.6910 | 0.7191 |

因此原阈值失配确实影响固定工作点；不能只看FPR约0.5就说排序完全没用。但即便允许不公平的事后阈值选择，协方差20炮对照在FPR≤0.20时TPR也只有0.7247，且并不优于同范围对角尺度的0.7303。**调整阈值不足以达到目标，新增协方差也未显示一致优势。** 10炮版本、所有工作点及代码哈希见 [事后诊断](../../../experiments/risk_aligned_online/runs/covariance_radiation_test360_20261022/operating_diagnostic.json)。

### 数值稳定不等于物理正确

20炮总协方差对照中，SXR/XUV正则化相关矩阵的条件数为3.145／2.941；正则化协方差等式残差约9.1×10^-16／1.45×10^-15。逐炮留一的映射相对变化最大约6.84%／11.36%。没有证据把此次失败主要归因于矩阵求逆爆炸。

但逆映射后的XUV方差字段，在总协方差20炮臂的1,420,436个完整观测点中有30,353个为负；平均炮内协方差臂有36,361个为负。原始对应值没有负数。20炮均值平移还使SXR／XUV分别出现777,308／721,846个负方差点。它们是**不受物理约束的数值对照**，不能部署为物理校准。没有把负值裁剪后另挑一个成绩。

此外，前20炮辐射总协方差的迹中，炮间均值项占SXR约85.0%、XUV约82.1%；源TRAIN约93.0%、91.1%。这说明把几千个时间点合成一个“域矩阵”时，放电之间的状态组成有很大影响；不能仅凭矩阵估计稳定就称其为装置响应矩阵。

## 9. 下一步的先后顺序

1. 先根据本轮配对结果，判断协方差项是否相对对角尺度带来净收益，尤其是否丢失及时预警；不以矩阵距离下降单独验收。
2. 单独检验原始 `MNM` 的保留／屏蔽，不把字段存在当作跨装置提取等价的证明。
3. 若需要复现文献优势，另设“源数据映射到目标后重新训练”的真实 CORAL 对照。S-CORAL 仅可使用已结束炮的标签；当前未结束炮不能按真实类别选择变换。
4. 炮内适配仍以内部时序表示为对象，使用已经到达的后续窗口检验此前直接输出的多步信号预测。不要把当前危险窗口的均值／协方差持续拉回“正常平均值”。适配规则需要源训练或过去结束炮上的任务相关证据，不能仅靠辅助损失下降。
5. 在相同输入与阈值条件下，再分别跑 static、intra-only、inter-only、intra+inter。必须先证明纯炮内的独立收益；报警参数控制单列。FPR≤0.20为主限制，严格 lead>30ms；不改评价集来制造增益。

上述后续步骤是方案，不是已完成结果。当前数据已参与开发，仍需未参与选择的未来炮流验证。
