# 已到达后段表示能否提供有用的炮内梯度

## 问题与既有证据

变化条件局部拟合已失败：信号预测改善不等于预警改善。本轮停止增加局部风险修正分支，检验真实神经参数更新的一个不同监督来源：后续信号已经到达后，用冻结模型对后段的内部表示，教临时编码器处理稍早片段。它不要求新预测头先准确预测未来信号，也不把当前炮结局作为训练目标。

不是首次发明未来到过去蒸馏。代码库 direct_latent_gate 已实现恒等预测器的一步控制，但当时新线性预测器未通过辅助预测门槛，实际梯度阶段未执行。本轮将这一未执行问题独立检验，另加时间反向和原信号预测的匹配控制；不把改名或未运行代码写成创新成果。

参考 Streaming Egocentric Action Anticipation（https://arxiv.org/html/2306.16682 ，实际核读§2.4、§3、§4.1–4.2）：作者以较后视频指导较早视频，并明确运行延迟影响提前判断。本轮不是其原算法复现：没有视频空间对应、标签训练或新师生网络；当前时刻之后的信息不可使用。参考 TTT（https://proceedings.mlr.press/v119/sun20b.html ，本轮核读摘要）仅支持测试时从无标签样本进行参数适应的范式，不提供托卡马克有效性保证。

## 固定范围

- 共同父模型为 matched_preparation20_test360_20261023/conditional_moments.pt，源存档和风险头不改。
- 同20个准备身份（4破裂16安全），无新增标签身份；不读取TEST信号或结局进行本轮初筛。
- 准备炮已参与父模型训练，因此初筛是乐观的训练内可行性检查，绝不是留出泛化成绩。
- 临时更新原输入投影、位置/CLS和第一Transformer块，与已有H25范围相同；学习率0.001、梯度总范数上限1；各个探针从父模型重新开始。
- 没有额外离线优化，没有新增模型参数、风险分数分支、报警器或炮间更新。

## 三种更新和一个不更新对照

在已看到 count 个点后，构造最多四对长度128的窗口；较后端点 b=count−1−25j，较早端点 a=b−25，仅保留 a≥127 的对。两窗所有信号均已到达。只有两窗各至少有一项有效观测，且(a,b]有新观测才参与。

1. **advance**：临时编码器在较早窗口的64维风险头输入，拟合冻结父模型在较后窗口的64维表示。
2. **reverse**：交换前后窗口，检验一般平滑/回拉是否与所谓提前学习相同。
3. **forecast**：已有H25一次输出25点真实信号目标，完全复用原梯度算子；相同0.001学习率与裁剪。
4. **static**：不更新。

表示损失为平均平方误差。目标是模型表示，不是物理状态真值；不能声称发现破裂原因。危险演化可能在教师中识别太晚、或被错误表示，本实验可以失败。

各探针在 q=count+24 处评价，即更新后第25个端点。只在准备数据中按已知标签构造可行性评价：每个安全炮32个均匀有效q；每个破裂炮16个严格30ms<lead≤125ms的q及16个较早负端点。短集合允许重复并明确记录，不当独立样本。要求q≥177、q在有效范围。没有相应端点即报错，不静默换炮。

本轮同时测量每种更新梯度与未来q的真实分类梯度的内积/余弦以及实际更新前后BCE。未来标签只进入只读诊断计算，禁止进入候选更新、模型参数、窗口输入或阈值。其作用是解释更新方向，不是部署策略。

## 决策门槛

按炮等权分别汇总安全炮负端点、破裂炮及时正端点的BCE；破裂炮较早负端点另外报告。advance必须同时满足：正端点及安全负端点均不变差，二者均值严格降低，且至少3/4破裂炮正端点BCE降低，才允许进入新目录的完整TEST360连续回放。不以reverse或forecast更好而偷换该假设，也不在此次筛查后扫描学习率。

这个门槛只用于节省无效全流计算，不是最终验收。若通过，后续仍要固定阈值、严格lead>30ms、完整180+180、同父模型关闭更新对照，并处理连续累积状态与运行时成本；若未通过，保留真实梯度证据并停止该候选。

## 核验

先写测试：时点索引、未来后缀不可影响更新、无标签输入合同、缺失观测不造目标、同窗教师应零更新、临时参数确实改变且父模型不变。核验梯度内积与有限步实际风险变化；代码和父模型哈希归档；主进程独立重计、抽样CUDA复放。仅本机rl_env CUDA。
