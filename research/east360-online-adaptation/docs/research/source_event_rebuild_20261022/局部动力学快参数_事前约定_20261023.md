# 局部诊断变化快参数：事前约定

这是新的开发候选，不是已确认收益。保持合格源归档和matched20 conditional父模型全部参数、输入映射、风险头及阈值不变。当前失败证据要求避免再次用整段raw水平预测误差无差别推动第一编码器；旧25点时钟、差分反馈、偏置扣除均已有实验，不能改名作创新。

## 结构与因果边界

过去128点分成16个8点片段。每列先使用父模型原有asinh坐标，再取片内有效均值；只有一整片8点有效，才作为该通道的变化监督。相邻片段均值之差为23列诊断变化，不称为真实物理状态或破裂原因。

可学习key投影将“上一片23维均值＋23维完整性”映射到8维tanh特征，再附加常数，得到9维k。慢参数W0为9×23的线性变化预测器。前14个已到达片段转移（片0→1至13→14）拟合本窗口快参数：

    Wc = W0c + (K' Mc K / nc + 0.1 I)^−1 K' Mc (Δc − K W0c) / nc

每列按各自有效转移数nc取均值；nc=0时没有本列监督，快参数保持W0c，不构造零值真标签。岭项使系统正定，不使用求逆或失败后默认替代。

最后一个转移（片14→15）不参与快参数拟合。使用k14 W预测最后一片变化，与已到达真值比较，得到23维预测误差；其tanh经无偏置23→64线性投影，加到最后一个patch embedding，再进入原Transformer及风险头。投影初值为零，初始模型严格等于父模型。不是在风险分数上叠加一个头。

快参数每个滑动窗口重新拟合，窗口长度128点；不保存到下一炮，也不宣称整炮长期记忆。全部监督来自当前已经到达的真实诊断，不回喂预测值，不读当前炮结局。局部变化并不一定是正常变化，预测误差也不等于危险，必须经实验检验。

## 慢参数训练与对照

只训练新增key、W0、内部投影，共2055参数。使用原J-TEXT TRAIN1353及相同20炮准备标签，固定512步Adam、lr0.001、clip1。每步源32／目标32，各16正16负，seed131/2131。每个候选同样样本与优化步数，不新增EAST标签身份。

- static_trained：不解局部快参数，使用W0。目标为BCE＋0.1×最后转移SmoothL1误差。
- adaptive_trained：同一批次中W0与局部拟合各计算一次，上述两项损失分别取两模式平均。既学如何使用个性化拟合，也保留未拟合行为。静态臂重复相同两次前向以匹配主要调用次数；局部求解的额外计算仍另报，不能声称严格等FLOPs。

不根据TEST挑epoch、超参数或臂，均使用第512步。完整TEST360六条曲线：父模型复用；static_trained不拟合／局部拟合；adaptive_trained不拟合／局部拟合／打乱转移目标拟合。打乱仅将前14个转移目标与掩码倒序，保留取值集合和当前观察，不是物理可实施干预。比较同一已训练模型的fit与prior，另与static_trained容量对照比较；不能把额外准备训练收益全归给炮内适应。

EAST固定125ms训练标签、严格lead>30ms测试规则、180D180S、阈值0.7258946895599365。全曲线封存后再读TEST结局。不做炮间组合、报警参数调整或独立未来确认宣称。

## 文献动机及非复现边界

[TTT层原文§2.1–2.3](https://arxiv.org/html/2407.04620v1)将测试序列内模型拟合纳入可学习前向过程；[可微闭式求解器原文](https://arxiv.org/pdf/1805.08136)支持通过岭回归解传播外层任务梯度。本候选把内层目标固定为实际诊断变化，而不是学习任意隐变量目标；任务、骨干、窗口和训练均不同，不称上述模型复现或算法首创。[MedTS-TTT预印本§2.2](https://arxiv.org/html/2606.21329v1)提供分类驱动内部快参数的近期实例，但其生理信号结果不是托卡马克有效性的证据。

验收需实际炮级收益、FPR≤0.20，且同模型fit优于prior、不能仅靠容量解释。记录拟合次数、参数变化、末转移误差、概率变化、逐炮救回/改坏、计算时间。测试须覆盖闭式解正常方程、缺失不填零监督、末片未参与拟合、零投影父模型一致、慢参数冻结、窗口未来不变性和可微求解梯度。
