# 近期TTT方法与本项目的差别

本次补读用于限定方案，不是“已经复现论文”或“已完成100篇系统综述”。只列主控实际核读的原文部分。

## 1. GradNorm：控制梯度尺度，不是确保物理正确

Chen等，ICML2018：[原文§3](https://proceedings.mlr.press/v80/chen18a/chen18a.pdf)。方法利用任务梯度范数和相对训练速度学习损失权重。它支持检查不同损失的梯度是否失衡，但并不证明某个损失适合破裂预测。

当前二因素实验仅给风险梯度设置不超过信号梯度的上限，没有学习GradNorm的权重或相对训练速度，因此不称GradNorm复现。最终是否减少误报，仍由整炮计分决定；Adam之后也没有信号损失单调下降保证。

## 2. MedTS-TTT：单片段内部适应，不等于提前预警

Chen等，MICCAI2026：[原文§2.1—2.3、§3.1](https://papers.miccai.org/miccai-2026/paper/5029_paper.pdf)。原文从多通道时序生成Q/K/V，用学习到的V−K构造自监督目标；单步更新层内快参数，再做片段分类。训练阶段通过分类任务学习慢参数，测试阶段保留快参数更新。

对本项目的启示（推断）：可研究只用当前已到达窗口构造内部适应目标，减少等待未来信号的延迟。但其完整片段、跨受试者分类实验，不能直接证明托卡马克严格提前30ms的逐炮预警收益。Q/K/V是学到的表示，不能仅因它们来自诊断信号就解释为密度、MHD或新的物理规律。直接插入冻结基模也不是论文的端到端训练设置。

## 3. LaCT：临时记忆和因果时序必须分开核查

Zhang等，ICLR2026，Test-Time Training Done Right：[原文§4.1—4.3、图3及因果语言模型说明](https://proceedings.iclr.cc/paper_files/paper/2026/file/ffbfff81fb78e4bb558273b91e12e318-Paper-Conference.pdf)。原文将历史token写入快权重，用局部窗口注意力处理块内结构；更新与应用的先后顺序决定信息依赖，因果任务采用相应的移位块结构。

对本项目的启示（推断）：临时快权重是一种内部记忆，不自动等于危险性适应。大块更新的吞吐量优势也不能替代预警时效约束。若借鉴，必须先明确“哪个信号已经到达、哪次预测会受更新影响”，不能先用整块更新后再把块内更早预测当在线成绩。本轮仍用旧因果算子，不因这篇论文临时改变实验。

## 4. 再读paper131后应保持的比较边界

本地[博士论文§4.3.1、§4.5.1—4.5.2](../../literature/paper_131.txt:2327)：J-TEXT、EAST分别采用超过10ms、超过30ms的及时预测口径；常规跨装置实验先PGFE，并分别用装置统计量标准化；EFD零炮模型仍用10个已知EAST破裂炮估计统计量，但不以其训练分类器。

这支持“先处理特征语义和数值坐标”的必要性，但不能把其零炮结果当作完全没见过EAST信号的成绩。本轮也没有复现PGFE-U＋FLS＋EFD全链路。论文提到安全炮平顶期负样本；当前HDF是否已经裁剪至对应区间，需要依实际时间轴核查，不能再自动删去误报时段来抬高指标。

## 5. 一个具体的时间轴核查

历史准备安全炮58717的HDF从绝对时间3.0s开始，先前静态风险峰在第103点，即3.103s。前256点电流中位数约250.38kA，范围245.85—253.83kA。这说明“输入记录开始后不久”不应直接称为“装置刚启动”；也不能仅据此断定该时段不是平顶期。

当前256点后才开始更新，是算法对已提供记录的等待成本，不一定是物理放电启动成本。这个例子不决定全部早期误报的原因，但要求今后的报告区分采样记录起点、物理放电起点和模型适应起点。
