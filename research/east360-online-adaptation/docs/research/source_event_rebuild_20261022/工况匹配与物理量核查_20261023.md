# 对齐之前：哪些量可以比较，哪些差异不应消掉

本轮核读原始方法和本地数据，随后完成信号与表示诊断。它不是“已获得炮内增益”的报告，也不是100篇文献的系统综述。

## 一、文献给出的具体约束

| 原始研究 | 方法中实际使用的信息 | 对本工程的约束 |
|---|---|---|
| [Shen：Cross-tokamak disruption prediction，§2.2、§4.2](https://arxiv.org/pdf/2309.05361) | S-CORAL对历史破裂／非破裂样本分别变换，再训练DART；所用目标数据为110炮、10破裂 | 不能把带标签的分类别对齐说成无标签方法；本轮20炮也不是其数据条件或算法的原样复现 |
| [Zhu：Scenario adaptive，§2、Table1](https://arxiv.org/pdf/2109.08956) | 用平顶期平均的q95、βp及加热功率区分工况 | 23列缺少其中若干变量，qa_proxy不能直接替代q95；完整平顶统计也不能当作当前端点实时可见的信息 |
| [OPS-DANN，§3.5、§4.5、Table3](https://arxiv.org/html/2302.01704) | 按运行阶段分别对齐，实验使用整个目标域的无标签数据 | 支持检查“工况混合比例”，不证明因果在线更新有效；M→L任务中hard/soft的RMSE为2.66/2.72，源模型2.63，并非每个任务都提高 |
| [Deep CORAL，§3.1–3.2](https://arxiv.org/pdf/1607.01719) | 源分类损失加深层协方差差异 | 单独降低协方差损失可退化到所有表示相同，不能替代分类验收 |
| [TTT++，§3.1–3.3](https://papers.nips.cc/paper/2021/file/b618c3210e934362ac261db280128c22-Paper.pdf) | 辅助自监督任务、均值／协方差约束、动态队列 | 自监督损失降低可能损害主任务；多个相关时间窗口也不能直接视作大量独立放电 |

这些研究并不互相矛盾：有的依赖已知类别，有的依赖完整目标分布，有的有真实工况变量。我们不能只保留“协方差”三个字，把其余条件删去。对本研究最有用的区分是**计量／提取差异、运行工况差异、破裂前兆差异**，后三者不能统一当作应消除的域偏移。

| 描述量 | J-TEXT | EAST前20炮 |
|---|---:|---:|

要求电流与磁场同时在目标值的±5%、±10%或±20%内，都没有源窗口匹配。这里只说明这组数值坐标不支持该匹配法，**不说明两装置完全没有可迁移物理**，也没有认证HDF5全部通道的单位。

## 四、qa_proxy提供了更具体的线索

定义数据核对量：

\[
k=\frac{\mathrm{qa\_proxy}\,|I_p|}{|B_t|}.
\]

窗口中位数结果为：J-TEXT `0.3740008124`，EAST `0.6877391339`。本地`paper_131.txt`给出名义尺寸J-TEXT a=0.25m、R=1.05m，EAST a=0.45m、R=1.85m。代入：

\[
\frac{2\pi a^2}{R}=0.3739991254\quad\text{与}\quad0.6877540674.
\]

逐点检查现有列是否接近 `2πa²Bt/(R Ip)`：1353个源炮中，最差一炮的中位相对误差为0.010004%；20个目标炮中为0.049752%。所有检查点的最大误差分别约0.5662%和0.8342%。这些是实际数值关系，不是补写提取代码。

在圆截面、大纵横比近似中，`Bp(a)=μ0 Ip/(2πa)` 与 `q(a)≈a Bt/(R Bp)` 联立给出：

\[
q_{\rm cyl}\approx\frac{2\pi a^2 B_t}{\mu_0 R I_p}.
\]

因此，在现有电流和磁场坐标正确的条件下，存储列**数值上接近μ0乘圆柱安全因子近似**。这是候选解释，不是提取来源认证，更不是EAST非圆截面平衡重构的q95。不能直接把存储值约`4e-6`称为安全因子本身，也不应因为两台装置的电流不同就把这个几何相关量再次全局标准化到同一分布。

此处圆截面近似的边界可核对[Maris等的跨装置密度极限研究，§2.2](https://arxiv.org/html/2406.18442v2#S2.SS2)：其圆柱近似另含伸长比因子`(1+κ²)/2`，且明确将q95与q_cyl区分，用前者表达近似式未涵盖的形状效应。现有23列没有逐炮κ，因此不能把上面的数值核对提升为完整平衡安全因子认证。该论文的边缘密度、温度、碰撞率结果也不能直接移植到缺少这些测量的当前数据。

进一步仅按存储qa_proxy的相对数值匹配，在±5%内覆盖前20炮抽样窗口的93.28%；再要求相对电流变化差≤0.01，覆盖82.66%。这里的相对电流变化是本窗口末32点与前32点电流幅值中位数之差，除以整个窗口电流幅值中位数；不是设定值、不是安全标签，也不是精确导数。

后一匹配中最近邻来自89个不同源炮，但按重复使用权重计算的有效源炮数仅约29.79。**有匹配不等于代表性充足，也不等于危险轨迹已对齐。** 该结果只支持把几何相关代理列列为后续待验证条件，不支持立即上线。

## 五、协方差为什么可能对错对象

本轮在原模型64维风险表示上验证：

\[
\operatorname{Cov}(h)
=\mathbb E_{\rm shot}[\operatorname{Cov}(h\mid\rm shot)]
+\operatorname{Cov}_{\rm shot}(\mathbb E[h\mid\rm shot]).
\]

总体方差迹中，炮间均值差异占J-TEXT的87.29%、EAST前20炮的83.77%。这证明总体协方差很大一部分与不同炮的表示均值有关，**尚不能证明其成因就是运行工况，更不能说这些差异应该全部消除**。按已观测电流升降分组仅解释8.95%和0.57%，不能代替完整工况描述。

还存在一个直接的数学限制：把所有表示加同一个向量不会改变协方差，但固定风险头 `z=wᵀh+b` 的分数可能整体上移。因此只对齐协方差既不能保证风险水平正确，也不能保证FPR受控。单元测试覆盖这一反例。

## 六、对下一步的影响

1. 不采用绝对Ip/Bt最近邻强制匹配；当前数据已否定这一具体选择。
2. 在用户允许少量EAST标签后，先比较监督微调、全局均值／协方差和按标签均值／协方差；物理qa匹配另作后续因素，避免一次更改多个环节。
3. 源存档不变；不修改最终分数或阈值来冒充神经适应。
4. 后续需要区分标签语义：整炮结局、正样本时间窗口、具体事件标记不是同一个目标。未标事件不能自动当作无事件。

## 验证和未完成事项

8个诊断测试通过，包括时间可见性、单位倍乘／极性不变的相对变化、缺测、拒绝远邻、加权协方差恒等式、零方差和几何代数关系。独立审查发现的零方差分数问题已修复并添加回归测试；原v2实际表示非零方差，故该问题未影响其统计。

此诊断没有训练新模型、没有新TPR/FPR结果、没有证明物理机制学习。部分物理量缺少原始提取脚本和单位属性，名义尺寸也不等于逐炮实际平衡形状。已运行的20炮有标签对照见独立事前约定，最终结果另行核对。
