## 1. 辅助轨迹预测应服务于主任务，而不是替代主任务

Xue、Du等，Learning to Select the Best Forecasting Tasks for Clinical Outcome Prediction，NeurIPS2020。[会议原文](https://proceedings.neurips.cc/paper/2020/file/abc99d6b9938aa86d1f30f8ee0fd169f-Paper.pdf)。本次读取摘要、引言、任务定义、§3.1–3.2及一阶算法起始部分，未完整核读实验附录。

论文用临床结局任务的表现来学习辅助预测任务的选择。关键启发是，所有信号都预测得更准不保证所学表示更适合判断结局。它是临床数据上的任务选择与迁移，不是托卡马克实时炮内更新；本轮梯度隔离也不是复现其算法，更不借用其指标作为本项目证据。

## 2. 监督时间范围、模型输出与报警期限不是同一概念

Koshizuka、Yaguchi，Horizon-Aware Early Event Prediction for Tokamak Disruption Alarms，2026预印本。[arXiv原文](https://arxiv.org/html/2609.24443v1)。本次复核摘要、§2、§3.1–3.5及评价定义片段；已有项目记录此前也读过该文，不能称新发现。

其比较将因果编码器与预测目标分开，区分训练预测期限和操作报警期限。原文采用40ms评价，不是本项目严格30ms；实验也不是从J-TEXT零样本转到EAST后逐炮适应。它支持检查目标与评价是否一致，但不支持直接扩大本项目125ms标签窗口，或用测试标签选阈值。

## 3. 沈呈硕的事件链工作：与在线适应有关，但不能直接等同

Chengshuo Shen等，Autonomous Discovery of Disruption Precursor Event Chains in Tokamak Plasmas via Progressive Multiple Instance Learning，IAEA第四届破裂与缓解技术会议，2026-09-29。[会议记录](https://conferences.iaea.org/event/451/contributions/42899/)。本次获得官方检索返回的会议摘要；直接打开页面返回403，未获得其完整PPT。因此仅作为会议摘要级线索，不写成完整论文复现。

摘要介绍用炮级标签发现前兆序列，含局部与全局注意力分离、逐轮遮盖已发现窗口及一致性检查。对本项目最重要的限制是：离线完整放电中可辨认的事件阶段，不一定能由当前时刻的历史前缀辨认。把离线事件类别直接当成当前炮的真标签，会混淆事后解释与在线可用信息。是否能以前缀模型识别这些阶段，需要另行验证。

## 4. 这轮据此做了什么、没有做什么

做了：检查准备阶段的信号预测梯度与风险监督方向；固定旧训练日程，对直接辅助梯度做一次隔离实验，分开报告静态及炮内结果。

没有做：更改125ms点标签、重新训练或覆盖J-TEXT源归档、增加最终风险修正模块、依据留出标签选择炮内更新、宣称已学习破裂机理、宣称已完成100篇全文调研。

文献提出的是研究问题和方法参照。方案是否可用，仍由固定父模型、固定阈值、相同数据边界下的完整炮级比较决定。
