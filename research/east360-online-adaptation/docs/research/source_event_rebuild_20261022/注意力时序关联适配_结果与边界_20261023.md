# 限制炮内更新位置：保住已有报警，但尚未产生额外收益

## 结论

本轮完成了一个有等步长对照的结构实验：只更新第一层注意力的Q/K矩阵，或只更新V矩阵，都保住了静态模型原有的3个及时检出；更新原可训练范围的全部参数，即使将每一步的参数变化长度缩小到相同水平，仍丢失1个及时检出。

这支持一个有限结论：**在这组数据和更新规则下，改动哪些参数会影响损伤程度，不能只用学习率大小解释。** 但Q/K和V两种局部更新都没有超过静态模型，原有漏报没有救回。因此没有证明炮内增益，也没有证明Q/K是优于V的特殊机制。

以下结果来自历史20炮的开发交叉验证，只有4破裂、16安全，**不是TEST360的新成绩，也不是独立未来验证**。按事前约定，不扩大这个未过门槛的候选，不通过降低报警阈值包装收益。

## 1. 少量有标签EAST准备，和本轮检查分别用了哪些数据

沿用用户允许的少量EAST准备方案，20炮分为四折；每折15炮准备，另5炮留出。准备集含3破裂、12安全，留出集含1破裂、4安全。四折留出身份不重复，汇总评价20炮。每炮由未用该炮拟合的分类器和辅助预测头预测。

本轮直接使用上一轮已封存的四折变化量预测模型，不增加准备炮，不重新训练预测头，不改变输入处理或分类器。该起点使用必要输入处理和风险监督准备，没有增加经验密度倍率或统计对齐损失。J-TEXT源归档保持不变，在线更新只发生在EAST。

这不是严格按原历史时间投运的验证：准备炮不保证都早于对应留出炮；这些数据也已经参与方法开发。整个项目接触过的EAST标签不止20炮：新旧准备集合并集为34炮，选择时还检查过TRAIN88元数据。不能把本轮样本数写成全项目累计标签预算。

此前完整TEST360的对齐结果及误报代价，见[20炮准备结果](邻近时期20炮对齐_结果与数据问题_20261023.md)。本轮没有再次访问TEST360，不能将这里1/16的误报直接解释为完整在线流的FPR已经解决。

## 2. 为什么检验Q/K和V

注意力的一步计算可写为：

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}(QK^{\mathsf T}/\sqrt{d})V.
\]

Q和K共同决定当前表示从哪些历史片段取信息，V是被取出的特征值，d是每个注意力头的宽度。它们不是三组独立的物理诊断信号，而是同一输入表示的三种线性变换。

工程假设是：只改变“哪些时刻互相参考”，可能比同时改变输入映射和特征变换更少破坏原有预警能力。需要特别注意，冻结V只保证**同一输入的第一层V不变**；改变Q/K仍会改变注意力输出及后续表示，并不保证最终风险不变或物理含义被保留。

[Tang等的Domain-Conditioned Transformer，ACM MM 2024](https://arxiv.org/html/2410.10442v1)把注意力关联作为测试时适应对象，提供了检验这个方向的依据。但该文通过Q/K/V条件向量、生成器及归一化参数实现适应，采用不同的优化目标。本轮直接限制矩阵梯度，并非该文复现；图像领域结果不能作为托卡马克预警收益的证据。

## 3. 五个对照条件

| 条件 | 炮内实际允许更新的部分 | 用途 |
|---|---|---|
| static | 无 | 同一准备分类器的静态起点 |
| full | 原16个编码器参数张量 | 上轮变化量预测更新；核验哈希后复用曲线 |
| qk | 第一层Q/K矩阵权重，共8192个坐标 | 主候选 |
| value_matched | 第一层V矩阵权重，共4096个坐标 | 同步长的不同位置对照 |
| full_matched | 原16个张量，共58240个坐标 | 同步长的原更新范围对照 |

Q/K和V条件都冻结偏置、输入投影、CLS参数、位置参数、归一化、前馈层、注意力输出投影、第二层编码器及风险头。冻结的是参数，不是所有中间激活值。

各条件使用各自当前状态下的信号预测梯度。Q/K条件按学习率0.001、所选梯度范数上限1产生更新长度；另外两个新条件把自己的梯度缩放到同一个提议长度。它们只读取Q/K的无标签步长，不读取其正确与否；属于归因对照，不是独立部署策略。

**相同参数欧氏步长不等于相同风险变化，也不等于相同功能空间距离。** 浮点运算还会使实际长度略有差异；本轮实际值与提议值的最大差约为1.96×10⁻⁸，均记录在日志中。

三个新条件都使用已有变化量预测头：根据过去128点，一次输出未来25点、23通道的变化量；不将预测值递归输入。更新只读取已经到达的四段25点目标，有效性由观测掩码确定。首256点后开始，每128点检查一次；更新影响更晚端点，炮末丢弃临时参数。没有炮间更新，也没有额外风险修正头。

全部预测封存后才读取留出炮结局用于评价。EAST正样本窗口仍为破裂前125ms，及时报警严格要求提前量>30ms；恰好30ms不计及时。所有条件阈值固定为0.7258946895599365。

各条件提前超过3000ms的报警均为0。静态及时检出为63226、63824和64677；Q/K与V均保留这三炮。两个原范围更新条件都丢失63226。70868在所有条件下都未及时检出，唯一误报均为64481。

事前验收同时要求TP不减、J增加且FPR≤0.20；若要归因于Q/K位置，还须优于同步长原范围更新。Q/K满足后一个比较，却没有超过静态，最终验收失败。这里只做描述性筛查，不将4个破裂炮或相关窗口当作足够的显著性证据。

## 5. 两个代表性反例

### 63226：少改坏了，不等于学会了新错误

| 条件 | 提前>30ms区间最高风险 | 是否及时报警 |
|---|---:|---|
| 静态 | 0.744595 | 是，提前258ms |
| 原范围更新 | 0.577888 | 否 |
| 只更新Q/K | 0.740296 | 是，提前255ms |
| 只更新V，同步长 | 0.739407 | 是，提前255ms |
| 原范围更新，同步长 | 0.714693 | 否 |

报警阈值约0.725895。同步长的原范围更新仍把该炮压到门槛下；两种局部更新保住了报警。这说明仅控制参数变化长度不足以避免这个反例，但不能把保住原静态正确判断称为新增检出。

### 70868：限制损伤还不足以纠正原有漏报

静态及时区间最高风险仅0.00764272，Q/K、V以及同步长原范围更新均约为0.0076427，远低于固定阈值。局部适应几乎没有改变这条错误轨迹。当前方案尚未形成“利用已到达信号纠正此类漏报”的有效方向。

这两个例子共同指出：**减少更新损伤和产生有益纠错，是两个不同问题。** 当前只在前者上获得有限证据，后者尚未解决。不能由此声称Q/K对应某种破裂机制，或断言任何无标签适应都不可能有效。

## 6. 确实更新了什么

三个新条件各发生693次非零神经参数更新，共2079次。逐次坐标检查确认更新没有越过指定掩码。

| 条件 | 第一层注意力发生变化的更新次数 | 第一层V发生变化的更新次数 | 最大实际单步参数长度 |
|---|---:|---:|---:|
| Q/K | 693 | 0 | 1.12608×10⁻⁵ |
| V，同步长 | 0 | 693 | 1.12618×10⁻⁵ |
| 原范围，同步长 | 693 | 693 | 1.12629×10⁻⁵ |

这里前后比较使用同一个已观测输入，探针只用于记录，不参与更新决策。其注意力计算与PyTorch的MultiheadAttention做了对应测试。

日志中的拟合损失下降次数分别为422、429和491，而非全部693次。它们来自float32前后计算；微小差值没有另做双精度独立验证，不能用来建立物理机制或每一步有效性的结论。本轮也没有新增随后未见片段的预测评分；上一轮的未来误差不能移用为这三个新条件的结果。
