# 隔离信号预测的直接梯度，仍没有恢复炮内预警收益

## 结论

本轮实际训练、留出预测及复算已经完成。**仅让信号预测损失直接训练预测头，不再直接修改初始编码器，未改变及时检出和误报计数。** 两种新准备方法各自的静态、炮内均为2TP/1FP，仍低于原静态的3TP/1FP。该候选不替换主线，也不扩大到TEST360。

这里的分母只有4个破裂炮和16个安全炮。它是历史20炮上的四折开发检查，不是360炮结果，更不是独立未来测试。FPR=6.25%不能证明完整在线流的高误报问题已经解决；少检出一炮就会使这组TPR下降25个百分点。

## 1. 为什么做这一轮

上一轮补回J-TEXT训练样本后，源训练分类损失改善，新增误报减少，但63226仍丢失原有报警。因此，不能把失败仅归因于源域遗忘。

本轮检查一个更窄的问题：准备阶段，同时要求编码器做好风险判断和信号预测，会不会使两类训练方向互相牵制？先在固定准备批次上计算梯度，再用真实训练检验移除其中一条梯度路径是否有帮助。没有按诊断结果扫描权重、学习率或阈值。

## 2. 到底改了什么

为避免字母代替解释，先说明三个目标：

- **更新前风险损失**：用尚未执行本炮临时更新的模型，判断后续一个观测块中的风险。
- **更新后风险损失**：从相同模型出发，模拟此前所有已到达信号所触发的炮内更新，再判断同一个后续块。
- **信号预测损失**：用历史窗口一次预测后续25点；只对已经实际到达的目标计算误差。

普通联合准备使用“更新前风险损失＋0.20×信号预测损失＋源样本分类损失”；适应感知准备使用“更新前后风险损失的平均值＋0.20×信号预测损失＋源样本分类损失”。这些目标数值及其系数均未改变。

本轮只改变最后一条求导路径：**计算准备阶段的信号预测损失时，编码器参数停止求导；预测头仍正常求导。** 风险损失和源样本分类损失仍训练编码器。适应感知训练仍完整追溯炮内更新，使“更新后的风险判断”能够影响编码器初值和预测头。

实际留出炮上的更新没有关闭：仍由已到达信号的预测误差更新临时编码器，预测头固定，每炮重置临时状态。因此，这不是只训练一个输出校正器，也不是把整个编码器冻结。

输入处理、冻结风险头、报警阈值0.7258946895599365、严格提前量>30ms、125ms正标签窗口、128点更新节奏、炮内SGD学习率0.001均不变。准备阶段仍为相同64步、相同EAST片段、相同每步32个J-TEXT TRAIN窗口；编码器/预测头学习率分别为1e-5和1e-4。重算支路增加了计算，不能声称相同FLOPs。

## 3. 梯度诊断说了什么，不能说明什么

在每折固定前8组训练批次上检查，共32组；分别检查原准备起点和上一轮适应感知训练后的模型。仅使用本折准备炮及J-TEXT TRAIN，不使用留出标签计算训练梯度，不更新任何模型参数。

| 检查位置 | 信号项与总风险监督梯度反向的批次数 | 信号项/总风险梯度范数比的中位数 |
|---|---:|---:|
| 原准备起点 | 21/32 | 0.0144% |
| 上一轮准备完成后 | 19/32 | 0.4103% |

“反向”指两向量内积为负，不等于某一炮必然被改坏。信号项的范数明显更小，也不能直接据此认定它没有作用：Adam按参数坐标缩放梯度，实际参数改变量不是原始梯度范数的简单比例。因此仍做了下面这一轮隔离对照。

诊断是固定批次的局部欧氏方向分析，不是Adam更新归因，更不是物理因果分析。它没有经过独立第二实现的完整梯度重算；梯度关系函数、求导隔离和数值导数有单元测试。

## 4. 实际结果

每折15炮准备、5炮留出；准备集为3破裂/12安全，留出集为1破裂/4安全。四折留出身份合计4破裂/16安全。它不是连续炮间学习，本轮没有调整报警参数。

| 方法 | 静态TP/FP | 炮内TP/FP | 炮内相对自身静态的ΔJ |
|---|---:|---:|---:|
| 原准备起点 | 3/1 | 2/1 | −0.2500 |
| 上一轮普通联合＋源回放 | 2/1 | 2/1 | 0 |
| 上一轮适应感知＋源回放 | 2/1 | 2/1 | 0 |
| 本轮普通联合，隔离直接信号梯度 | 2/1 | 2/1 | 0 |
| 本轮适应感知，隔离直接信号梯度 | 2/1 | 2/1 | 0 |

原静态TPR=0.75、FPR=0.0625、J=0.6875。两条新候选各自静态与炮内均为TPR=0.50、FPR=0.0625、J=0.4375；超过3000ms的报警均为0。风险轨迹和提前量并非逐值不变，只是检出、误报计数没有改善。

### 63226：准备阶段的损伤仍在

原静态提前258ms报警，及时区间峰值为0.744595。本轮普通联合准备后的峰值为0.157968，炮内为0.288089；适应感知准备后为0.180041，炮内为0.321514。与上一轮对应值相比有小幅变化，但仍远低于固定门槛，没有报警。

这些数值是各自曲线的区间峰值，不保证发生在同一个端点。不能由峰值上升推断每一次更新都正确，更不能把未越过门槛的上升叫作及时检出收益。

### 63645：没有新增误报，不等于获得炮内收益

安全炮63645在原静态中已判断正确。本轮普通准备的最高风险0.672107、炮内0.654425；适应感知准备0.609064、炮内0.557303，均低于门槛。因此这不是救回一次原有误报，而是没有重新引入此前某些候选的错误。

### 70868：困难轨迹仍未识别

原静态及时区间峰值0.007643，本轮适应感知炮内为0.009033，仍未报警。63824和64677保持及时检出。本轮没有证据表明模型获得了对新破裂路径的识别能力。

## 5. 方法裁决

1. 不继续扫描辅助梯度隔离比例或回放权重。当前一次配对不支持把“辅助信号目标直接改动编码器”作为主要失败解释；不能据此排除它在其他配置中的作用。
2. 保留合格J-TEXT归档和较好的EAST静态起点。没有改动源归档、没有新增J-TEXT在线分支，也没有用风险分数叠加或报警参数调整补成绩。
3. 后续先追溯准备阶段风险下降来自哪些监督样本：分别检查源样本、EAST安全片段、EAST破裂片段对既有报警的影响。该检查属于事后错误分析，不能把留出结局变成在线更新规则。此项尚未完成，不列为本轮成果。
4. 用户允许少量EAST标签准备，不意味着可以把已有所有EAST标签提前用于模型。当前单折准备15炮；项目以前还使用过其他历史EAST身份，不能把整个项目的总标注消耗写成15或20炮。真实连续流和独立炮内收益仍是未完成目标。
