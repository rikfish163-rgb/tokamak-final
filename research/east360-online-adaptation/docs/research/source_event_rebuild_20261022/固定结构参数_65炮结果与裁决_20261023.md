# 固定位置编码与CLS参数：完整配对结果

## 结论

**没有解决FPR，也没有获得满足要求的独立炮内收益，候选不晋升。**
固定位置编码与CLS初始标记，能减轻部分误报，但也损伤正确预警。
不能把“错误轨迹变稳”当作“学到了正确的破裂特征”，也不能把比失败的在线基线更好，
说成已经优于同父模型的静态预测。

最关键的反例是prepared第3折：原炮内4个及时检出/32个误报，固定结构参数后变为3/26。
与静态3/22相比，虽然及时检出总数同为3，但实际救回75604、又丢掉原本检出的77412，
并新增4个误报。只展示总TP会掩盖这种交换。

## 1. 这次实际使用了多少数据

- 现有历史20炮开发池（4破裂16安全），沿用四折；每个模型只用对应15炮（3破裂12安全）准备。
- 对照评价用另外65个历史TRAIN炮，4破裂61安全，与这20炮不重叠；不是TEST360。
- warm和prepared是两类既有准备模型。本轮没有新增离线训练或标签，没有源模型重训、炮间学习。
- 四折使用同一65炮，不能说有260个独立测试炮，更不能说这是独立未来流。
- 历史项目已查看更多标签和开发结果，不能将“每个模型15炮准备”写成全项目只见过15个标签。

用户允许少量EAST标签准备，但准备身份、模型状态和评分数据仍须分开。
本轮仅控制更新范围，不把20炮准备收益与炮内收益混在一起。

## 2. 控制了什么

风险阈值固定0.7258946895599365；及时报警严格要求提前量>30ms；超过3000ms另列。
所有端点保留，包括首次无标签更新之前的端点。没有删去初始误报，没有改报警状态机。
使用128点因果输入，一次预测25点未来信号。目标全部到达后才更新：首次256点，此后每128点。
更新影响后续预测，不能撤销已发出的首次报警；每炮结束丢弃临时参数。

四列分别为：

1. 静态：不做炮内更新，复用原封存曲线；
2. 原炮内：更新输入投影、第一Transformer块、位置编码和CLS，复用原封存曲线；
3. 固定结构参数：只更新输入投影和第一Transformer块，不动位置编码及CLS初始标记；
4. 等步长全参数：仍沿原全部参数梯度，但每一步的请求欧氏步长与第3列一致。

第4列用于区分更新位置与仅减小更新幅度，依赖并行第3列状态，不能当作独立部署算法。
同样的请求步长不意味着浮点更新逐位相等；实测两臂实际步长最大差1.33e−8。
固定CLS参数不等于固定最终CLS表示，编码器仍执行真实神经反向传播并改变风险表示。

## 4. 逐炮变化，不能只看平均值

固定结构参数相对原炮内：

- warm第2折：85330重新误报，原有减少1个FP的收益丢失；
- prepared第1折：消除87581误报，77639仍误报；
- prepared第3折：消除62557、77161、77270、80087、80920、83954六个误报，但漏掉77412；
- 其余折及时检出与误报身份不变。

prepared第3折相对静态：救回75604、漏掉77412，新增67499、72792、77460、80557四个误报。
这说明同一参数范围既可能帮助检出，也可能制造误报；简单冻结不是对两种作用的分离。
这仍是模型行为证据，不能据此声称已找到真实破裂机制。

## 5. 77639改善了什么，又没有改善什么

本轮固定的是原first256、四段目标规则，不是前一轮early1/late1时钟比较；两轮时间不混用。

| 第1折prepared在77639上的方法 | 全炮最高风险 | 首次误报时刻/s |
|---|---:|---:|
| 静态 | 0.680058 | 未报警 |
| 原炮内 | 0.990815 | 5.837 |
| 固定结构参数 | 0.775538 | 6.599 |
| 等步长全参数 | 0.975860 | 5.899 |

固定结构使最高风险下降、误报延后762ms，但仍越过原阈值，因此在炮级FPR里仍算误报。
前一轮的风险差反例得到了机制层面的部分解释，却没有变成成功的纠错策略。

## 6. 方法裁决与下一步边界

1. 不把此候选合入主线，不继续扫描冻结比例、位置参数学习率或更新时钟。
2. 目前有两个问题：准备模型在第一次更新前已发生误判；后续辅助信号更新又会改变正常/危险的判别。
   只修第二个问题不足以达到FPR要求。
3. 下一项检查应回到少量标签准备的目标覆盖：当前联合准备的EAST块风险任务从第256点起构造，
   与从第1点起评估的整炮首次报警存在覆盖差异。须先核查准备时实际抽样与前256点误判，
   再设计配对修正；不能通过不评分前256点来掩盖差异。
4. 任何新准备仍使用明确的少量历史身份；先验证静态EAST判别不被损伤，再独立报告炮内相对同起点的收益。
   源J-TEXT归档保持不变，炮间收益不能替代炮内验收。

这一轮按实验规划和结果分析流程，报告负结果及全部对照；不以信号拟合误差下降、单炮曲线更平稳
或某折TPR较高来替代主任务验收。现阶段仍不能宣称已学到新物理规律或独立未来泛化。
