# 针对已观察小收益的机制对照

本方案在第一轮6臂TEST结果已知后制定，属于明确的事后开发诊断，不是独立验证。
静态训练模型由prior到fit：131TP/37FP→130TP/32FP。但内部修正量显著缩小，不能排除只是限制新增模块扰动。

固定同一个`static_trained.pt`、20炮准备身份、风险阈值和TEST360，新增两臂，不重新训练模型：

1. **倒序配对**：使用现有`shuffled`模式，仅倒序14个拟合目标及其掩码，输入key次序保持不变。改变的是配对及缺失模式，不单独代表纯时间顺序干预。
2. **固定缩小**：仅在原20炮准备数据上，每炮有效且>=127的端点均匀取32个（不足时显式重复），计算同一窗口prior与fit的64维内部修正u、v。用最小二乘系数a=clip(sum(u·v)/sum(u²),0,1)匹配两者；分母为零时明确报错。之后固定a，复制静态模型并把内部readout权重乘a，测试时只使用prior，不解任何本炮快参数。这是内部容量/幅度对照，不是风险分数或报警修正。

拟合a只读20炮已授权历史标签来界定有效信号时段，不读TEST标签；TEST身份及第一轮结果此前已经被开发者查看。两新曲线完整封存后再读取TEST结局评分。原曲线和原参数不覆盖。固定缩小系数不得根据TEST重新选择。

若真实fit与倒序近似相同、或固定缩小同样好，则只能保留有限的预测改善事实，不能宣称学习到本炮特有动态或物理机制。若真实fit更好，也仍需要多seed、独立未来数据及物理证据。不会仅凭该开发诊断晋升主线。
