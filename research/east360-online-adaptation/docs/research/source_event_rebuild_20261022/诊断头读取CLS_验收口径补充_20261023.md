# 验收口径补充

本补充在结构实验运行期间、读取该次最终结果前制定，不改代码、预测、阈值或原始事前约定；原约定及其哈希保留。

原约定要求TP不减、FP不增、J提高且FPR≤0.20，是比用户目标更严格的双指标筛查。用户明确接受在FPR上限内提高TPR，因此不能用该更严格筛查否定例如TP从3/4增至4/4、FP从1/16增至2/16的方案。

结果中同时列出：

1. 原严格筛查：TP不减、FP不增、J提高、FPR≤0.20。
2. 用户目标筛查：TP不减、J提高、FPR≤0.20；允许FP在上限内增加。

无论哪一项，恢复到相同静态计数不算炮内增益。即使通过，20炮开发检查也不是最终验收，仍需完整测试和更广的可靠性检查。此补充只纠正验收解释，不授权选择性隐藏不利结果。
