# 变化条件局部适配：固定表征对照

上轮局部key在128点内变化很小，完整拟合和均值控制仅相差一个FP。当前假设：绝对水平主导key，限制局部拟合学习状态相关变化。本轮测试变化条件，不继续调整报警阈值、时间滞后或ridge强度。

保持合格源归档、同20炮准备、原分标签对齐父模型、原风险网络、同TEST360及>30ms评价。新增内部模块与上一轮相同2055可训练参数，源风险网络冻结。训练两个候选：level_key、change_key，同初始化同512步同训练窗口及Adam(.001)，均取prior与fit损失平均：BCE+0.1 SmoothL1。新增离线准备预算明确披露，不作为炮内收益。

过去128点划为16个8点片段，均值m0..m15、差分d0=m1-m0到d14=m15-m14。仅完整观测片段有效。变化尺度在前32个训练批次的源TRAIN1353和固定EAST20上按通道RMS估计，抽样种子/顺序与正式512批一致；不读TEST，保存端点清单。无有效变化列尺度取1并记录，其他尺度至少1e-3（源asinh坐标的数值下限，非物理阈值）。固定后不随测试窗口归一化，保留局部变化幅度。

两候选的训练目标相同：v_j=asinh(d_j/scale)。level_key输入m1..m14，change_key输入v0..v13，各拼相应差分有效性23列，经46→8 tanh并加常数1。拟合13对(k0,v1)..(k12,v13)，查询k13预测v14；最后8点不参与快参数拟合。输出有效性要求连续三个片段完整。风险网络仍读取原始源坐标128点，未对风险输入去均值、去趋势或分组。

每个候选运行prior、fit、shuffled、mean四臂：同一慢检查点，关闭拟合；正确配对ridge(.1)；仅反转13个目标及其mask的配对控制；上一轮常量key等价的平均残差修正。共八条新曲线＋父模型参照，全部预测封存后才能读取TEST结局。每窗口临时系数重置，不跨炮保存。无炮间持久更新、无报警变更。第一24点之前没有三个完整片段，输出须与父模型一致。

本轮仍是内部诊断预测器的闭式快系数适配，离线训练会通过求解器反向传播；部署不对Transformer执行反向传播。它检验设计依据，不替代用户最终要求的神经炮内微调验收。若改变key不能带来稳定、正确配对独有的收益，不用事后选择某炮或阈值宣布成功；下一步需更换学习目标或更新范围。

验收证据：未来前缀不变、heldout末片段不影响fast、完整缺失有界、风险梯度到key/prior/readout、源基座逐值未变、训练清单一致、同父静态-适配配对、打乱/均值控制、独立计数、抽样CUDA重放。全量360单种子开发探索，不作独立或物理机制证明。
