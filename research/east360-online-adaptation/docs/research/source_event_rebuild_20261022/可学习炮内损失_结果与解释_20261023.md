# 可学习炮内损失：真实实验、对照与结论

2026-10-23。代码分支：`codex/risk-aligned-intra-shot-online`。

## 1. 结论先说清楚

本轮已经实现并运行“用历史结局训练炮内更新损失”，不是仅写设计。它在不使用当前炮结局的条件下，对第一Transformer编码块执行真实梯度更新。

但它仍没有通过事前验收：破裂前及时端点的平均交叉熵下降，安全炮的平均交叉熵上升。增加一个可学习损失网络，并未自动解决误报风险。简单熵最小化对照在这批端点上反而更好，值得另做完整炮流核查；它不是本文提出的新物理方法。

**这里没有新的TEST360 TPR/FPR。** 当前只完成20炮历史准备集上的单步探针；不能把端点交叉熵、改善的端点数或3/4破裂炮的局部损失下降写成炮级检出率提高。

## 2. 与现有主线的关系

源归档仍为已达标J-TEXT模型，没有重新训练或覆盖。EAST仍使用同一个20炮准备父模型、同一个输入映射、同一个风险头与阈值。

| 对象 | 本轮是否改变 |
|---|---|
| J-TEXT源归档 | 不改变 |
| EAST已有20炮准备父模型 | 不改变持久参数 |
| 输入归一化与必要的经验尺度处理 | 不重新拟合 |
| 输出风险头、报警阈值 | 不改变 |
| 新增损失网络 | 使用历史15炮拟合，每折独立 |
| 当前探针的第一编码器副本 | 使用已到达信号更新一次，随后丢弃 |
| 炮间学习、报警参数反馈 | 本轮不启用 |

因此本轮没有把离线准备收益、阈值收益或炮间收益冒充炮内收益。准备20炮来自历史TRAIN，不是按真实炮序的最初20炮；旧准备与新准备身份的累计开发使用也不能抹去。本轮没有增加标签身份。

## 3. 损失究竟怎么学

### 3.1 更新时能看到什么

在已经收到第`t`个采样点时，取截至该点的128点输入窗口。原有Transformer给出内部状态`h`，实际64维，仍由原风险头产生分数和概率。

另从已到达信号计算上下文`c`：

1. 最近25点中每个诊断量的均值：当前处于什么水平；
2. 最近25点均值减去之前25点均值：最近发生了怎样的变化；
3. 最近25点的有效观测比例：哪些信号确实可用。

这只是23列信号的三种摘要，共69维，**不是恢复17+8分组**。均值在既有源asinh坐标中计算，不是原始物理单位下的密度或能量；未解决单位来源的列也不能因此称为完成物理标定。缺失信号不作为真零目标，两段均有有效值才计算变化。

### 3.2 内层：当前炮如何更新

小网络输出一个非负标量：

\[
L_\phi(h,c)=\operatorname{softplus}\{W_2\tanh[W_1(h,c)+b_1]+b_2\}.
\]

`φ`是该小网络的参数；结构为133→32→1，共4321参数。它**不输出另一个破裂概率**，也不直接加到最终分数上。

对临时编码器参数`θ`计算这个标量的梯度：

\[
g=\nabla_\theta L_\phi,
\qquad
\theta'=\theta-0.001\,\frac{g}{\max(1,\|g\|_2)}.
\]

更新的仍是输入嵌入、位置、CLS和第一Transformer块。第二块及原风险头不动。更新以后，后续窗口仍经过原有预测路径。没有把`Lφ`当风险分数使用。

最后线性层零初始化，因此开始时不产生编码器改动；但“改变损失网络会怎样改变内层梯度”的外层导数不为零。回归测试和有限差分均核查了这点。

### 3.3 外层：什么叫一个好的更新方向

历史TRAIN炮已经有真实结局。在历史窗口上模拟上述更新，随后用25点之后的窗口判断破裂风险，将其交叉熵作为训练损失网络的目标：

\[
R(\phi)=\operatorname{BCE}\bigl(f_{\theta'}(x_{\leq t+25}),y_{t+25}\bigr).
\]

这里`f`仍是原风险网络；`y`只在离线外层训练或事后评分中使用，**没有传入炮内更新函数**。实际样本时间戳核查，25点对应25ms。

直白说：不是奖励“诊断预测误差变小”，而是奖励“按这个损失更新后，后面一小段的破裂判断更正确”。这个目的更直接，但是否能跨炮成立，仍要靠留出实验，不能从公式推断必然有效。

## 4. 训练与留出没有混成一回事

准备集是4破裂、16安全，共20炮。分4折，每折留1破裂+4安全，只用其余15炮训练损失网络。所有方法同初始化、同192次Adam更新、学习率0.003、每次均匀抽1安全炮端点和1及时破裂端点；不选择最佳epoch。

**限制：父模型和输入映射已经使用过这20炮。** 所以这只能检验“新增损失网络是否能迁移到未参与其拟合的炮”，不能称为整个模型的独立测试。

共640个端点：安全炮每炮32个，破裂炮每炮16个`30<lead≤125ms`端点，另16个较早负端点。后者仅用于诊断，不参与外层优化。较早破裂端点的训练标签虽为0，但其告警仍可能满足炮级提前量要求，不能称为安全炮误报。

每个端点从同一父模型独立进行一次更新。**这还不是一炮内多次更新累积的在线回放**，也没有测完整报警轨迹。先做此小实验，是为了避免在错误更新方向上继续扩大计算。

## 5. 完整对照结果

下表先对每炮端点平均，再对炮平均；两类平均为安全与及时破裂两组的等权平均。均为BCE，越小越好，不是TPR/FPR。

| 方法 | 安全炮BCE | 及时破裂端点BCE | 两类平均 | 及时端点改善的破裂炮 |
|---|---:|---:|---:|---:|
| 不更新 | 0.033040 | 0.069717 | 0.051379 | — |
| 学习损失：内部状态+信号上下文 | 0.035925 | 0.061637 | 0.048781 | 3/4 |
| 学习损失：去掉69维信号上下文 | 0.035843 | 0.064374 | 0.050109 | 2/4 |
| 学习损失：一半步骤交换监督配对 | 0.034270 | 0.089948 | 0.062109 | 1/4 |
| 固定损失：熵最小化 | 0.031407 | 0.061530 | 0.046468 | 3/4 |
| 固定损失：原H25信号预测 | 0.035020 | 0.083232 | 0.059126 | 1/4 |

事前要求：安全、及时破裂两组均不变差，两类平均严格改善，并至少3/4破裂炮改善。主候选未达到安全项，因此**不晋升主线，不进入其完整360炮测试**。

去上下文对照仍保留当前64维内部状态，并不是完全不看信号。交换监督对照每次仍有1正1负、总192步中恰好96步交换，同一训练计划；它是破坏历史输入—标签关系的对照，不是省略一半训练。

正确监督优于打乱监督，说明学习过程确实利用了历史对应关系；但安全项变差、且未优于简单熵损失，不能宣称已经学到更可靠的物理纠错方向。训练内结果也不是完美：4折中1折的安全BCE在训练炮上就变差，不能把失败完全归咎于留出分布差异。

## 6. 哪些炮在拖累，说明什么

### 安全炮64481仍是主要反例

其32端点平均BCE：

- 不更新：0.155925；
- 可学习损失：0.219678；
- 熵最小化：0.155009。

可学习损失使该炮误差增加0.063753。16炮等权时，这一炮对安全组平均差值贡献约+0.003985，而全部安全组净差值仅+0.002885；说明其他炮的改善没有抵消它的损害。并非所有安全炮都恶化，不能从平均数作这样的推断。

3/4破裂炮的及时端点得到改善；63824例外，BCE从0.129743到0.134202。熵对照在它上面也变差，到0.135295。说明这个反例不能只归因于新增上下文网络。

### 为什么简单熵损失不等于已经解决问题

二分类分数为`z`、概率为`p=sigmoid(z)`时，熵为：

\[
H(p)=\operatorname{softplus}(z)-zp,
\qquad
\frac{dH}{dz}=-zp(1-p).
\]

它倾向于让已有判断更坚定：当前分数为正就倾向继续推高，为负则倾向继续降低。当前判断正确时可能有利，当前判断错误时可能强化错误。共享编码器更新后对其他窗口的影响还取决于参数梯度关系，并不是每个未来分数都按上述符号简单移动。

本轮安全端点大多原本就低风险，降低这些端点的BCE，不能证明少数危险的误报尖峰也被消除。因此即使简单对照通过小门槛，仍要在固定阈值下检查完整安全炮的首次越阈值，以及破裂炮的>30ms及时告警。**均值改善不替代炮级FPR验收。**

## 7. 文献如何影响本轮设计

MT3将无标签内层适配与监督外层目标结合，说明可以训练“更新后的任务效果”，但原作处理图像、自监督任务和元模型参数，本轮只借鉴双层训练思路，不声称复现其方案。[Bartler等，AISTATS2022](https://proceedings.mlr.press/v151/bartler22a/bartler22a.pdf)

Goyal等通过元学习探索适配损失，发现某些设置下所学损失接近缩放后的熵；原文并不把任意MLP损失推荐为通用方案。本轮因此必须保留熵对照，实际结果也表明复杂网络未必更好。[Goyal等，NeurIPS2022](https://papers.neurips.cc/paper_files/paper/2022/file/28e9eff897f98372409b40ae1ed3ea4c-Paper-Conference.pdf)

上述不是托卡马克物理证据。未使用EAST事件类型真值，也未证明某一诊断变化就是破裂原因。本轮“物理上下文”的准确称呼应为“已观测诊断量的水平与变化”，而非“新物理规律”。

## 8. 已完成核验

- 主运行100.53秒，使用本机rl_env CUDA；并非实时部署时延。
- 4折×3学习臂，共4608次内层训练更新；另3200次留出探针更新和5760次训练内诊断更新。
- 全部12个损失网络从相同随机起点重新训练，参数和训练记录逐值一致。
- 全部3200条留出探针在CUDA完整重放，结果及更新回执一致。
- 全部8960条诊断用独立NumPy公式重算BCE；按炮汇总和门槛重算一致。
- 35项相关测试通过，包括未来信号不可影响当前更新、标签不可进入更新接口、父模型不变、留出身份隔离、真实外层梯度及有限差分。
- 有限差分测试最初使用±0.1扰动，越过梯度裁剪拐点，不能近似局部导数；改用±0.001并显式检查未触发裁剪后，数值导数0.073314与解析0.073306一致。没有改变已运行算法或放宽测试容差。
- 本轮未打开TEST360信号/结局，没有修改源归档或风险阈值；单种子、仅4破裂炮，不作显著性或独立确认声明。

## 9. 接下来的明确决定

1. 停止扩展本轮可学习损失，不用报警参数或炮间更新掩盖其安全项退化。
2. 熵对照可作为另立方案的**探索性基线**，检查单次局部更新与炮内累积更新是否导致错误强化；不能因为它在此表最好就称为预先选定的方法。
3. 下一完整流仍需固定同一父模型、输入映射、阈值、炮序，报告TPR、FPR、提前量和所有有利/不利翻转。若炮级结果失败，保留负结果，重新检查安全误报峰与危险演化的区分目标。
4. 当前并未完成用户要求的有效炮内+炮间系统，目标保持进行中。
