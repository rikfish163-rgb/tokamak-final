# 时间变化与水平依赖：完整360炮诊断约定

这是读取既有负结果后设计的事后模型诊断，不是独立验证，也不是新的在线策略。

沿用已完成的 `labeled_alignment20_test360_20261023` 作为参考，固定源模型、输入映射、阈值及TEST360。20炮准备集、其类别元数据预算和时间顺序限制不改变；不新增训练，不调阈值，不引入专家或风险修正头。

新问题：密度经验映射降低FPR时丢失的29个及时命中，原先主要依赖数值水平还是窗口内时间变化？此前已有不同30炮映射的密度插值敏感性实验，本轮不是重复搜索插值系数，而是检查当前20炮父模型的时间依赖，且纳入所有360炮。

分别在原始输入和已映射输入上执行三种前向：

1. 原始128点因果窗口，逐点核对已封存风险轨迹；
2. 仅将密度列的已观测值替换为该窗口中位数；
3. 将全部23列分别替换为各自窗口中位数。

三种情况都保留观测/缺失掩码，填充与缺失不参与中位数计算，不用整炮统计，不改模型参数。先封存六臂完整曲线，再读取结局计分。中位水平本身仍随窗口移动而变化；因此压平窗口不等于删除整个炮的长期演化，也不能说模型完全没有时间信息。

报告完整360炮的TP/FP及29丢失及时炮、67消除误报炮的成对响应。诊断产生的人工窗口可能偏离真实信号分布，不能把TP提高当作已实现的在线收益，更不能把敏感性解释成物理因果。

方法依据：WinIT指出时序归因应考虑窗口中的依赖及滞后，而不是只看单点。本轮只是固定中位数扰动对照，不是WinIT复现或生成式条件反事实。原文：https://roseyu.com/time-series-workshop/submissions/2021/TSW-ICML2021_paper_26.pdf 。

Windsor等跨装置研究强调无量纲参数的物理定义，同时说明某些归一化会改变接近破裂时的变化。其JET/AUG参数与本项目存储代理不同，不能将本项目的ne_nG经验乘法当作已验证物理标定。原文：https://colin-windsor.github.io/HomePage/05disr/index.htm 。

验收：完整曲线复算、原始两臂参考相等、源及持久参数不变、窗口与缺失值测试通过。不得把这次诊断标记为炮内训练验收通过。
