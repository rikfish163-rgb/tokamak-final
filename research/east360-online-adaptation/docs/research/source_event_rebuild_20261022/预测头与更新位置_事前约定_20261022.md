# 预测头与更新位置：受控对照

2026-10-22，运行前固定。仅 EAST 在线，原始合格 J-TEXT 模型不训练、不改写。

## 目的与已知事实

原预测头曾在128维 token 临时参数坐标下接受梯度方向训练。上一轮又使用普通预测损失拟合预测头，且将在线更新范围扩大到输入投影和第一 Transformer 块。两项变化需拆开，不应据原训练名称就认为新更新仍然风险对齐。

已有2026-10-05审计记录指出，合格存档的旧 aligned 训练实际未包含更新后风险损失，虽然协议曾记录 meta_risk_weight=0.5。本轮再次核对原512步日志，不能把后来代码的修复追认到旧存档。这不改变该存档的静态达标事实。

## 五臂

1. 静态：前20炮结束后只使用既有密度尺度映射。
2. 原预测头＋编码器临时更新。
3. 普通预测校准头＋编码器临时更新，复用上一轮完全一致的已封存轨迹，不称为独立重复。
4. 原预测头＋128维 token 临时更新。
5. 普通预测校准头＋128维 token 临时更新。

同一更新算子内只改变预测头，因此能够归因预测头校准的增量。两个算子之间的参数坐标、步长及限制方式均不同，不能把其差值解释成仅改变参数数量。

## 固定合同

- 源模型SHA `c7270c1ea3652db2e30e972d4ca9a4a2d33220a68e4a3765c8b7f5bcceeaeb02`，阈值0.7258946895599365不变。
- TEST360，180破裂180安全，严格lead>30ms；前20炮纳入评分。另报共同340炮。
- 前20炮使用共同原预测；其封存后才启用密度映射和已用同一前缀训练的校准头。核对继承实验的前缀ID、静态轨迹、准备检查点与哈希。
- 不额外训练任何参数；不恢复MNM、不新增CORAL、不调整报警器。
- 两算子共用每128点一次、最近四段已到达H25的反馈窗口。暂不改变频率，避免把预测头差异和更新时点混在一起。
- 编码器算子：输入投影/位置/CLS/第一块，SGD一步1e-3、梯度范数上限1，沿用上一轮。
- token算子：64维增益和64维偏置，作用于进入Transformer前的patch表示，不直接修正风险分数；归一化步长0.05，距初始参数半径≤1，使用原训练的参数坐标和步长规则。
- token算子的H25×4反馈与128点频率不同于原历史单窗口26点部署。因此只称为“恢复原更新坐标和步长”，不称为完整历史复现。
- 临时状态每炮重置，标签只在完整预测结束后用于评分。静态风险头、诊断预测头及持久网络权重均冻结。
