# 20炮有标签EAST对齐：结果、失败原因与下一步

## 结论

本轮已完成本机 `rl_env` CUDA 实验和独立复核。**少量目标标签可以改变内部风险表示，但当前实现没有同时达到低误报与有效炮内适应的要求，不能作为成功主线。**

仅用20炮估计密度列的经验尺度，原始裸迁移的误报由94/180降至27/180，但及时命中也从145/180降至117/180。进一步监督微调、全局或按标签均值／协方差对齐，及时命中恢复了一部分，误报却升至41—43/180。炮内更新继续增加命中，也增加误报；固定阈值下没有净J增益。

源模型存档没有改动；本轮没有训练J-TEXT在线分支，没有添加最终风险分数修正，也没有更改报警阈值。

## 1. 这20炮究竟怎么使用

用户允许少量有标签EAST放电用于前置对齐，本轮从现有 `train88` 角色中选择4破裂、16安全。选择规则在实验前固定：每类按炮号从小到大取足数量。

- 安全：54314、54941、57264、58717、59215、59643、60155、60476、60479、61059、61327、62440、62557、62583、62630、62945。
- 破裂：63226、63824、64677、70868。
- 68928、71316、71393的shotlist与HDF5结局冲突，明确排除，不静默修订。
- 选择前核查88炮结局元数据；实际进入信号统计和梯度拟合的是20炮。因此这是**20炮模型拟合预算**，不是只访问20个标签的盲查询实验。
- 所选20炮与VAL22、TEST360不重叠。既有角色划分并非全局时间划分，部分拟合炮晚于早期测试炮；本轮是**回顾性少样本迁移实验**，不是严格历史先后的投运模拟。

测试保持同一360炮、180破裂和180安全，不以结果好坏挑炮。全部预测封存后才读取测试结局。及时命中要求**提前量严格大于30ms**，阈值始终为源存档值 `0.7258946895599365`。测试集已参与开发，不能称为独立未来确认。

## 2. 比较的是什么

### 输入处理

保持23列、缺失规则及源域asinh预处理。仅由所选20炮估计 `ne_nG` 的正增益：`0.00036155007389467784`。其余列不做任意混合或旋转。

这个数是经验分布增益，不是经原始提取脚本认证的单位换算。当前没有原始密度信号和单位属性，不能宣布密度物理定义已完全对齐。

### 三个神经准备分支

1. **监督微调**：源、目标分类损失各占一半。
2. **全局矩匹配**：在监督微调上增加风险表示的均值、协方差差异。
3. **标签条件矩匹配**：分别计算正类、负类的均值及协方差差异，再取平均。

三个分支使用同一初始化、同一采样清单和512步优化。每步源、目标各32窗口，均为16正、16负。这是类别平衡后的分布，不是自然在线类别比例。

更新的是输入投影、位置／CLS参数与第一个Transformer块，共16个参数张量；第二块、最后归一化和风险头冻结。**冻结风险头仍允许前面的神经表示通过反向传播改变。**源、目标都经过适配副本，不是把源表示固定为教师；源BCE约束并不保证适配副本仍保持原源域测试性能。

现有64维风险表示记为h，其矩匹配损失为：

\[
D(H_s,H_t)=\frac{\|\mu_s-\mu_t\|_2^2}{64}
+\frac{\|C_s-C_t\|_F^2}{4\times64^2}.
\]

均值项约束整体位置，协方差项约束各表示方向的共同变化。它们不直接约束整炮误报，也不等于物理机制一致。源正类为 `max(25ms, AdvancedTime)` 窗口，目标正类固定125ms；按0/1分组不代表相同前兆阶段已经对应。

方法借鉴[Shen等S-CORAL的分类别对齐](https://arxiv.org/pdf/2309.05361)、[Deep CORAL的可微协方差](https://arxiv.org/pdf/1607.01719)及[TTT++的一、二阶统计约束](https://papers.nips.cc/paper/2021/file/b618c3210e934362ac261db280128c22-Paper.pdf)。不是原S-CORAL输入变换+DART的原样复现，不能直接继承其性能结论。

### 炮内成对开关

每个准备模型另以相同预算拟合原有25点直接信号预测头，256步；该步骤不改变静态风险输出。之后每个模型都比较关闭／开启炮内更新。

开启时，先封存当前预测，再用已经完整到达的25点真实信号计算预测误差；至少观察256点后，每128点执行一次临时编码器SGD更新，学习率1e-3、梯度范数上限1。只影响后续端点，每炮重置。**本轮没有炮间持久监督更新**，避免把炮间收益算入炮内收益。

## 4. 已查明的现象与尚未证明的原因

**不是没有更新。**四个炮内分支各有11,301步真实梯度更新，参数改变量均非零；监督分支11,294步辅助预测损失下降，其余三分支11,301步均下降。辅助损失降低没有转化成合格的预警收益。

**风险上升不只发生在危险窗口。**排除每炮最初256点后，按炮先求概率变化均值：标签条件臂180个安全炮中138炮的平均风险上升，安全炮均值变化的中位数约+0.00492；破裂前30—125ms的对应中位数约+0.00444。这与新增误报相符，但不能仅凭此证明具体哪个物理通道是原因。

**不能把训练窗口拟合好等同于整炮安全。**监督损失按平衡时间窗口计算，评价则是安全炮任一点越过门槛即误报。当前目标没有直接控制“整炮内出现一次错误高风险”的概率。这是明确的目标差异；其贡献大小仍需对照验证。

**少样本条件协方差确实受限制。**目标正类8,192次抽样仅涉及4炮、498个不同端点，约93.92%的抽样次数是重复端点。每类每批16行、64维协方差秩至多15。这里不求逆，因此不是矩阵求逆故障；问题在于有限轨迹下的统计代表性。不能据此断言所有协方差对齐无效。

**仅改阈值不足以恢复理想识别能力。**另行进行了明确标注的后验排序诊断：利用全部测试结局为每组寻找FPR≤0.20的最优阈值，九组最高及时TPR仍只有0.7278（标签条件＋炮内）。这一数值是使用测试标签选阈值的诊断上界，**不是可部署结果，也没有写回模型**。它说明本批预测不能只靠重设报警门槛变成TPR约0.8—0.9、FPR≤0.20的系统。

## 5. 补充事件标签实际能做什么

既有补充CSV有1,816个J-TEXT身份、732个事件区间；本地TRAIN1353对应327个有事件炮、401个区间。与本轮EAST20炮交集为0。它可以用于源域辅助表示或解释研究，**不能当作EAST已经有的真实事件标签**。

这些A—F是离线发现的候选事件家族，不是人工认证的破裂原因。未检出事件、未标区间不能自动当作正常。本轮为隔离对齐因素，没有新增事件损失；此前事件相关实验的结果也不能混入本表。

## 6. 下一步应改的环节

不再把“加大均值／协方差权重”作为主要推进路线。下一轮优先检验以下具体假设，不能预先宣称有效：

1. **用少量EAST标签训练更新方向，而不仅训练静态分类。**准备阶段将同一炮拆成先前可见窗口和后续监督窗口：内层只用已到达信号更新，外层检查更新是否改善之后的危险识别、是否增加安全高风险。部署时仍不给炮内过程真实结局。
2. **区分窗口误差和整炮误报。**源模型与风险头保留，拟合更新目标时同时约束安全炮的高风险片段，不能只奖励短期信号预测变准。必须与相同步数、相同初始化的现有H25更新成对比较。
3. **按独立炮检验方向。**20炮采用按炮隔离的准备／检查，不能把同炮相邻窗口随机拆成独立验证样本；只有4个破裂炮时需要明确不确定性。预算10/20的变化应保持名单嵌套，不另挑容易的炮。
4. **物理条件只使用有依据的量。**当前绝对Ip/Bt窗口在两装置间没有近邻重叠；qa_proxy数值与名义几何、电流磁场关系相符，但不是已认证q95。下一轮若引入条件选择，应单列对照，不能强行消除真实工况或危险轨迹的差异。

这些是基于本轮失败提出的实验方向，尚未在本轮实现或证明。尤其不能用后续炮间监督收益补写成炮内收益。
