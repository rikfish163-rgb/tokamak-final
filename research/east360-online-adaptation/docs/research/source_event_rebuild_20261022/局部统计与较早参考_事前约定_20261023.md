# 局部统计与较早参考：固定二因素对照

上一轮正确/倒序配对均130TP/32FP，未证明状态与变化配对有独立价值。本轮不加模块、不重训，只拆解同一static_trained检查点的无标签临时适配，仍是已开发TEST上的探索。原归档、20炮准备模型及其新增模块全部冻结，固定阈值及TEST360身份。

因素一：状态相关岭拟合（ridge） vs 只估计近期平均预测偏差（mean）。
因素二：当前128点窗口（recent） vs 截至当前点之前128点的那个128点窗口（lagged）。
四臂均在索引256后才启用；之前完全使用同一prior。另保留prior、以及上一轮从最早可用片段开始的reference_fit，避免把等待时点变化误归因于参考窗口。

每个参考窗口仍只用前14个转移作拟合，当前窗口最后转移仍作为预测误差的检验对象。lagged不使用更晚数据，也不意味着较早片段必然正常；固定128点是现有窗口长度，不是按TEST或真实破裂时刻选取的事件边界。不扫描延迟。

mean保留原先验预测，逐列求有效转移的平均残差r；计算同一有效集合的平均key q，并令偏差修正b=r×(||q||²/(||q||²+0.1))。无有效转移时b=0。它没有学习key与目标的相关关系；系数使常量key情形与原ridge及同一0.1惩罚完全一致，避免仅用不同正则强度解释差异。当前查询的预测为k_query W0+b。原始风险网络输入不做去均值。

新计算recent_mean、lagged_ridge、lagged_mean三条完整曲线。recent_ridge可由原reference_fit在前256点替换成prior精确构造，因为快参数每窗口独立；抽样必须重算证明。六条曲线全封存后才计分；输入代码不得读取TEST结局。记录每炮风险变化、末转移误差、平均修正幅度、最近和较早窗口的实际时间差。不得把本轮写成Transformer主干反向传播。

先在同一20炮准备集各32个端点诊断key饱和、窗口内key变化及相关拟合与平均偏差的区别；这些端点沿用上一轮scale_fit清单，不新增标签身份，不以本轮TEST选择方法。

评价：同一等待合同下比较ridge/mean和recent/lagged主效应及交互，保留全部负结果，不因某一个报警临界点改参数。若均值对照解释大部分收益，则减少模型复杂度；若较早参考保护预警，则下一步需要可因果验证的参考选择依据，不把固定较早当成物理正常真值。
