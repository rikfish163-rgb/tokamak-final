# 历史保护与当前炮收益不是同一问题

本轮针对原文方法段核读，不声称新增精读100篇。它补充当前整流实验的解释，不修改已锁定实验。

## 1. GEM：保护旧样本，不等于学好当前炮

[Lopez-Paz与Ranzato，NeurIPS2017，§3式7–11与算法1](https://arxiv.org/pdf/1706.08840)
在当前模型处重新计算历史任务梯度，通过半空间投影约束新更新。其一阶判据依赖局部线性近似。
因此上一轮固定起点梯度的实现不能直接继承该判据；本轮重算方向并另测实际损失。
即使历史窗口没有受损，也没有得到当前未标记危险轨迹的正确更新方向保证。

## 2. TTT：关键是当前主任务与辅助任务的梯度关系

[Sun等，ICML2020，§4定理1](https://proceedings.mlr.press/v119/sun20b/sun20b.pdf)
在光滑凸主损失、梯度有界和正相关等条件下给出单步改善的充分条件。
本项目Transformer不直接满足该理论框架；只能借鉴局部内积与实际损失变化的诊断。
尤其要区分：与20个历史窗口梯度不冲突，不意味着与当前炮后续预警梯度正相关。
后者在真实部署时没有标签可算，只能在已结束历史任务训练、或封存后的开发诊断中研究。

## 3. S4T：新的相关思路，但不能直接搬用成绩

[Jeong等，ICCV2025；arXiv作者版§3.2–3.3](https://arxiv.org/html/2507.07778v1#S3)
学习不同任务表示之间的关系，训练时用真实任务标签，测试时用完整表示的预测指导掩蔽表示。
额外分支服务于适应，而非最终预测。理论假设包括任务关系跨域保持、关系模块已充分训练。

本项目可借鉴“直接训练适应用的任务关系”，但不能把23个通道预测自动当作23个有可靠语义的主任务。
风险预测也可能给错教师目标；跨装置通道语义和密度尺度未完全认证，不能预设关系不变。
此外原文§4.2按目标任务平均最佳性能选择适应步数；本项目在线回放不能提前用测试结局挑步数。
故该论文是待验证设计的参考，不是当前已完成的复现或零标签安全保证。

## 4. 与已有负结果合并后的设计约束

仓库已经比较过预测头更换、25/128点反馈时钟、临时参数位置、变化预测、均值控制及可学习损失，
不能再把这些已有实验当作尚未尝试的新方向。分别见[更新位置](辅助损失与更新位置_梯度核查与五臂结果_20261022.md)、
[反馈时钟](反馈时钟与目标新鲜度_完整结果_20261023.md)和[可学习损失](可学习炮内损失_结果与解释_20261023.md)。

本轮当前梯度＋实际历史保护，是区分“保护实现不准确”和“当前辅助目标无效”的控制实验，
不是核心创新已经成立。若保护确实达成而新炮收益仍不足，下一步须改变反馈所学习的信息，
并用同一步长、同一父模型、正确／破坏时序关系等对照证明，而不是继续增加保护项。
