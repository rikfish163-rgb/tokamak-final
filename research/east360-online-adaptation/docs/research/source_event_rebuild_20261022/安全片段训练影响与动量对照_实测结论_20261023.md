## 结论先行

本轮有一个比“训练损失降了、指标没好”更具体的发现：**训练安全片段时，参数更新会连带压低63226的原有破裂预警；Adam历史动量还会延续这种改动。** 但仅关闭编码器的一阶动量，仍没有恢复及时报警，也没有产生独立炮内收益。

因此，这不是优化器参数调一下就解决的问题。当前证据更支持检查不同轨迹共享表示时的相互干扰：模型对某些安全片段的纠正，没有限定在这些片段所代表的状态范围内。这个解释仍是待验证的机制假设，不是已经识别出物理规律。

所有计数来自历史20炮开发交叉验证：4破裂、16安全，每折15炮准备、5炮留出。**不是TEST360，不是连续投运，更不是独立未来测试。** 本轮不替换原模型，不扩大失败候选，不调整报警阈值。

## 1. 如何定位，而不只看梯度夹角

本轮复现上一轮两个模型在四折中的完整64步准备过程，共512个实际训练步骤、8份最终模型。每步使用同一EAST安全片段、EAST破裂片段和J-TEXT源训练批次。

在每一个真实训练前状态，额外试算五种情况：完整梯度；去掉当前安全片段梯度；去掉当前破裂片段梯度；去掉当前源批次梯度；当前所有梯度置零。每条试算都保留相同的Adam历史状态，重新进行相同的全局梯度裁剪。试算结束后恢复参数、梯度和优化器，再执行原本完整的一步。

这里有两个必要限制：

1. 去掉当前安全梯度，不等于删除它在此前步骤中留下的动量。因此不能把单步差值相加，解释成“不使用安全炮训练”的完整重训收益。
2. 观察端点依据已经封存的原静态曲线和事后结局选取。它只用于错误分析，不能进入在线查询、参数更新或阈值选择。

20炮全部纳入：破裂炮原来及时报警的，固定在首次及时报警点；漏报炮固定在及时区间的原静态峰值；安全炮固定在原静态峰值。端点不会随训练移动。下文“固定端点风险”和“整炮及时区间峰值”分别报告，不混用。

## 2. 63226究竟在哪一步被改坏

原静态对63226提前258ms报警。固定该首次报警端点，原风险为0.727226，略高于固定门槛0.725895；原整炮及时区间峰值为0.744595。

在上一轮适应感知准备的第40步（从1开始编号）中：

| 项目 | 实际记录 |
|---|---|
| 安全训练片段 | 63712，目标端点1536—1663，末端记录时间4.663s |
| 破裂训练片段 | 70868，目标端点3968—3992 |
| 63226固定端点风险 | 0.748172 → 0.715341 |
| 固定报警门槛 | 0.725895 |
| 固定端点logit变化 | −0.167422 |
| 本步去掉安全梯度，相对完整一步的logit差 | +0.141656 |

也就是说，在这个真实优化器状态下，去掉当前安全片段梯度会明显减轻原报警端点的风险下降。四折中的63226只属于第0折留出炮，未进入该折准备训练；这不是模型在本炮标签上训练后重新评估自己。

此后第41步的实际logit下降为0.164375；即使把当前全部梯度置零，同一历史Adam状态仍导致下降0.154643。它证明历史状态会继续推动更新，**不是证明94%的总损伤都由动量造成**：两条试算是局部非线性干预，不能做这种累计贡献解释。

第48步处理安全炮63645时，再出现一次较大下降。其风险损失为1.517659，而同批破裂片段64677的风险损失只有0.018595。两类样本数量相同，并不意味着对参数的推动程度相同；损失值本身也不等于梯度范数或物理重要性。

## 3. 全部步骤和其他炮是否支持这个解释

对63226的固定端点，两种准备模型各有46/64步使风险下降。每一步去掉当前EAST安全梯度，风险都比完整更新略高：两种模型都是64/64。相反，去掉当前源梯度，多数步骤会使该端点风险更低：普通模型41/64、适应感知模型40/64。这与上一轮“源回放能减轻损伤，却不能彻底恢复报警”的观察一致。

不能因此直接删掉安全训练。以安全炮63645为例，去掉当前安全梯度会使它自己的风险更高：普通模型61/64步、适应感知模型58/64步。安全监督既有应有的作用，也存在对另一条危险轨迹的连带影响。

也不是所有破裂风险都被统一压低。以下均是固定原端点，不是训练后重新挑选的峰值：

| 破裂炮 | 原固定端点风险 | 普通准备后 | 适应感知准备后 |
|---|---:|---:|---:|
| 63226 | 0.727226 | 0.146186 | 0.166818 |
| 63824 | 0.776586 | 0.834928 | 0.830412 |
| 64677 | 0.735198 | 0.788704 | 0.782386 |
| 70868 | 0.007643 | 0.007515 | 0.007552 |

这说明需要检查轨迹差异，不能把问题简化为整个输出分数都偏低。

### 输入相似性只能作描述，不能当物理因果

第40步所选安全片段与63226观察窗口，在共同有效通道的源asinh坐标中，窗口中位数RMS距离为0.62487；同批破裂片段的对应距离为1.12684。这只是该步两个代表窗口的比较，不是全数据最近邻证明。它不包含完整时序演化，通道之间也有相关性。

例如两个窗口的Mir_avg_amp、Mir_avg_fre中位数相同，而电流、磁场、ne_nG、位移及部分辐射统计不同。不能据此认证破裂原因。ne_nG单位和提取来源等既有疑点仍在，本轮没有凭统计距离重新标定或删除通道。

## 4. 真正改代码验证：只关闭编码器一阶动量

不是看到动量作用就直接宣布修复。本轮另做了一次完整配对：编码器准备优化器从Adam(0.9,0.999)改为Adam(0,0.999)；预测头保持原Adam，其他条件不变。

相同父模型、64步、EAST片段及源批次、风险目标、直接辅助梯度隔离、编码器学习率1e-5、预测头学习率1e-4、梯度裁剪上限1。冻结风险头和原归档均不改。关闭动量会改变实际参数位移，这是干预的一部分，不声称等位移。

**部署时的炮内SGD未修改。** 它不是此次发现的准备阶段Adam。临时编码器仍只用已到达信号更新，每炮重置；没有炮间学习或报警参数调整。

| 方法 | 静态TP/FP | 炮内TP/FP | 炮内相对自身静态ΔJ |
|---|---:|---:|---:|
| 原准备起点 | 3/1 | 2/1 | −0.2500 |
| 上一轮普通联合准备 | 2/1 | 2/1 | 0 |
| 上一轮适应感知准备 | 2/1 | 2/1 | 0 |
| 本轮普通准备，编码器无一阶动量 | 2/1 | 2/1 | 0 |
| 本轮适应感知准备，编码器无一阶动量 | 2/1 | 2/1 | 0 |

新模型均为TPR=0.50、FPR=0.0625、J=0.4375，低于原静态J=0.6875。判定仍严格lead>30ms；>3000ms报警均为0。四个破裂身份只适合开发排错，不能据此估计全流效果或声称误报已达标。

63226的整炮及时区间峰值有变化：普通准备静态0.162389、炮内0.251386；适应感知准备静态0.201513、炮内0.505193。后一项高于上一轮0.321514，但仍低于门槛，未报警，且仍不及原起点炮内的0.577888。它不是新的及时检出收益。

## 5. 对下一步的实际约束

- 停止围绕这一候选扫描动量、回放系数和报警门槛。单纯优化器修改没有解决问题。
- 准备阶段的静态损伤与部署炮内损伤要继续分开，不能用较差的新静态起点衬托炮内回升。
- 下一项表示诊断应比较相似运行水平下的正常/危险演化，而不是再用窗口均值相似就假设机制相同。已有条件预测、变化量预测和注意力更新对照都需作为反例，不能换个名字重做后称新方案。
- 当前20炮只有4个独立破裂过程，反复在其上构思已经产生明显开发依赖。它可以定位错误，不能代替更完整的固定炮流评价。本轮失败候选不扩大；后续新方案必须明确准备、开发和测试身份及累计标签使用量。
- 本轮没有产生最终可用的炮内策略，也没有证明模型学到新的物理规律。完整EAST流的FPR和独立炮内净收益仍未解决。
