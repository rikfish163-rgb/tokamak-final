# 同类事件中的危险轨迹配对：事前约定

- Origin Mode: run
- Origin Date: 2026-10-24
- Verification Status: UNVERIFIED
- Version Label: event_pairing_v1

目标是给EAST炮内更新寻找与预警任务相关的历史经验选择依据，不是增加风险分数头。上一轮改变梯度几何没有超过缩小普通梯度对照；本轮不继续调该曲率方案参数。

只用J-TEXT TRAIN已标注事件窗口训练辅助相似性编码器，原源风险模型不动；VAL只评估，不选epoch/seed；不读取TEST220新预测或EAST360结局。事件A–F来自离线全记录聚类，历史划分已被标签生成过程接触，因此结果仍是开发诊断。

训练监督仍为原max(25ms,AdvancedTime)窗口，且端点提前量>10ms；安全炮为0，破裂炮窗口外也为0，不能把整炮结局贴到所有时间点。未标注事件区间不当正常。先检查近预警窗口覆盖：TRAIN六类均有可用正负窗口，A类正窗口只有4炮，需明确样本不足风险。

输入为过去128点的source-asinh平均状态23维、8段中心化状态184维、对应可用性184维，共391维。MNM因当前EAST不可用而在本辅助比较双方都屏蔽，不改原源模型。只用TRAIN拟合标准化，禁止时间/炮号/事件年龄/结局作为输入。保持同一EAST既有输入映射；此处不声称认证了物理单位。

四个固定训练臂，每个seed131/132/133、1024步、batch128、AdamW lr0.001、weight_decay0.001，391→64→16单位向量，最后一步，不选择最好轮次：

1. risk：正例为同事件、同窗口风险、不同炮；负例为同事件、相反窗口风险、不同炮。
2. mean：同risk配对，但输入时间变化置零，可用性沿时间平均；检查是否只有平均水平在起作用。
3. shuffle：在TRAIN各事件类别内打乱窗口风险标签，保留每类计数，重新配对；只是负对照，不保留原风险时间相关性。
4. family：正例同事件且同风险；负例不同事件但同风险；检查只有事件分类是否足够。

每个锚点候选取相应条件下平均状态最近的四个不同炮，各炮仅一个窗口；锚点按事件×风险×炮均衡抽样。风险配对损失为softplus((相似度负例−相似度正例)/0.1)。它是受监督对比构造，不是完整复现Temporal-SCL，不强迫所有同结局状态坍缩成同一点。

验证不把事件类别作为查询输入：用三个最近的不同历史炮分别估计正／负类距离，分数=负类平均距离−正类平均距离，仅作诊断，不接正式风险。VAL报告总体及六类内AUC、先按炮均权的类别内宏AUC。EAST只用既有20准备炮320窗口，留出整个查询炮检索其他19炮，不训练新EAST参数；报告按炮均权AUC及危险炮／安全炮的近邻分数。

额外对照为固定原信号距离、仅均值距离、真实训练编码器的倒序查询。只有risk在VAL条件宏AUC和EAST留炮AUC均高于mean/shuffle/family及对应倒序，且EAST高于原信号距离，才进入后续360整炮实验。这个门槛只是进一步研究资格，不等于炮内增益。失败则保存反例，不把探针分数当线上成绩。

参考：Temporal Supervised Contrastive Learning for Modeling Patient Risk Progression，ML4H2023，方法§2–3 https://proceedings.mlr.press/v225/noroozizadeh23a/noroozizadeh23a.pdf 。其局部邻居与标签共同定义相似性提供构造启发，医疗结果不是EAST证据。另检索RAINCOAT(ICML2023)、多视角时序迁移(CHIL2025)、EDEN(NeurIPS2025)官方页面；不声称已复现或获得这些论文的聚变效果。
