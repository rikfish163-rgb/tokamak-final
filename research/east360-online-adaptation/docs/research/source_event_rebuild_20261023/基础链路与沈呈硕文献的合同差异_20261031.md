# 基础链路与参考文献的合同差异

日期：2026-10-31。本备忘只核对指定文献的输入、标准化和评价合同，不把文献成绩当成本项目结果，也不修改正在运行的实验。

## 1. “零炮训练”不等于没有目标域统计

本地[paper_131.txt §4.5.1](</media/hetaisheng/044A81D94A81C83E/Fuison/docs/literature/paper_131.txt:2832>)明确描述：EFD实证使用10炮EAST破裂炮计算均值和标准差，但不将这些数据用于分类器训练。因此应区分：

- 未使用EAST监督梯度训练分类器；
- 已使用EAST信号估计输入统计；
- 第一炮前完全没有EAST信号或标签。

这三个条件并不等价。本项目允许前20炮结束后建立映射，仍需将前20炮预测计入整条流；不能提前借用后来的EAST统计后再称为从第一炮零信息适应。

## 2. 对齐的对象不是任意同名列

Shen等PGFE/S-CORAL原论文§2.1要求针对两台装置设计对应的物理特征提取；文中明确讨论EAST的MNM提取困难、不同壁条件下CIII的局限。其Table1中的25项还包含密度剖面统计和n=1相位，并不等同于当前HDF5的23项。[原文§2.1/Table1](https://arxiv.org/pdf/2309.05361)

工程推论：应核准每列的定义、提取和可用性，不能仅靠名字相同或均值相近认定一致。本文献没有给当前HDF5认证单位；统计映射也不自动提供这种认证。

## 3. 当前破裂炮早期负标签的缺席，是明确选择

原论文§3.1只将破裂前末段作为正样本，并解释为何不使用破裂炮更早时段作负样本。当前`disruptive_positive_only`与此有相似的保守思路，但不是完整复现。[原文§3.1](https://arxiv.org/pdf/2309.05361)

论文随后采用更精细标签的改进工作，才重新利用破裂炮的非破裂片段；本地论文§4.4.2还设置J-TEXT和EAST不同的灰区。不能为了补安全样本，悄悄把所有早期片段都当作确定安全，也不能把当前末端125ms标签叫作真实前兆起点。

对本项目当前360的短历史候选，新增破裂端点均在正标签窗口之外，因而被现有loss过滤。扩展采样实际补充的是安全炮早期监督，而不是新破裂机理信息。

## 4. 报警连续点数不能跨采样率直接照搬

本地[§3.4.4](</media/hetaisheng/044A81D94A81C83E/Fuison/docs/literature/paper_131.txt:1916>)在0.1ms采样背景下使用连续10点，即1ms；[§4.3.2](</media/hetaisheng/044A81D94A81C83E/Fuison/docs/literature/paper_131.txt:2397>)说明跨装置工作改用每样本1ms。

因此不能由“连续10点”推定应在当前1kHz代码中直接设置10点，那会变成10ms；也不能仅凭本次读取的章节断言后续每个实验都继承完全相同报警规则。当前项目固定首次越阈和严格lead>10/30ms，若另做持续报警对照，应单列决策层变化，不能计作炮内神经更新收益。本轮短历史实验不修改这一规则。

## 5. 文献不能替代当前失败诊断

原论文Table3零样本AUC为0.642；§4.2在其数据与阈值下报告U-CORAL仍有较高FPR。它说明协方差对齐不是自动达标的保证，不能据此为本项目的高误报免责，也不能将不同特征、样本、阈值及标准化的成绩直接配对。[原文Table3与§4.2](https://arxiv.org/pdf/2309.05361)

本轮能检验的是当前基础链路中的一个具体缺口；下一步仍需在同一完整在线流、同一父模型、同一报警器上区分基础准备、炮内反馈和炮间监督各自的贡献。
