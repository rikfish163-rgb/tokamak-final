# 八维工况状态：内部适应结构的可回退试验

## 问题和证据

本轮零初始记忆配对尚未完成，不能提前判定其效果。已有五组360显示风险普遍上移，且时距扰乱
没有改变炮级成绩。与其继续添加分数修正，本原型检验限制内部更新自由度能否提高样本利用效率。
这是新结构探索，不把过去的失败归因为已确认的“参数太多”。

参考CoDA、LEADS和NCF的工况适配思想（见同目录文献登记），但不复制其ODE求解器，也不声称
八个变量对应八个真实物理参数。J-TEXT分类基模与风险头保持冻结；在线更新仅部署在EAST。

## 前向与反馈

每8个已到达采样点组成一个诊断块；23维数据仍保留原单位合同和缺失掩码，再使用既有源统计变换。
当前观测与可用性生成9维特征k，其中最后一维为常数。
源训练学习的系数张量把k映射成四个时距、23个通道、8个工况变量的矩阵B。

每炮工况向量c从0开始，只在真实信号到达后更新；一次性预测四个后续诊断块的变化：

    prediction(h) = B(h) c

这里预测的是归一化诊断量的增量，不是未来破裂标签。源训练的B和key在EAST炮内冻结。
第j块到达后，汇总已经到达的1–4个时距的误差，计算对同一个c的梯度：

    g = sum(B^T (B c - observed_change)) / (1 + sum(B^2))
    c_new = project_to_unit_ball(c - eta * g)

只在真实可用通道上求和；eta仍为0.5*sigmoid(rate)。分母限制该线性预测任务的梯度步幅，
不等于对预警无害的证明。四个未来窗口直接输出，不拿预测结果递归生成真值。
此前封存的预测不重写。当前c产生的92维预测变化经既有output层作用到两个Transformer块之间。
最终风险头、阈值不增加任何残差。

与828维矩阵记忆相比，炮内只更新8个数；共享预测系数增加、须在源域训练并如实统计总参数量，
不能把“临时参数少”说成总模型更小。源训练及EAST炮后仍可更新既定可训练参数，不混称纯无训练推理。

## 对照与验收

- 初期只用固定8维，不扫描维数挑EAST成绩。沿用源TRAIN1353、VAL160和固定两轮预算。
- 源教学沿用已停止参照侧梯度的损失；不同时新增事件头或更改标签。
- 与零初始矩阵记忆比较时明确是结构对照；先比较各自cold→intra，再比较最终成绩。
- 时距扰乱只交换已到达增量与预测时距的对应关系，不把预测矩阵和目标一起交换（那样共享状态的梯度和会不变）。
  采用相同状态范数，零方向情况显式计数；它不是未来数据访问或真实工业策略。
- 完整360含启动20炮，180D/180S、提前量严格>30ms，固定原阈值；同一输入映射、炮序及炮间协议。
- 必须独立intra有益、FPR≤0.20，并检验真实反馈优于扰乱反馈；之后再看both是否互补。
- 先测零变化、未来不可见、缺失通道、跨炮重置、真实梯度和源分类器冻结，再训练和运行完整流。

当前是开发原型，不是已验证物理模型。阶段性代码和单测完成不能替代完整在线成绩。
