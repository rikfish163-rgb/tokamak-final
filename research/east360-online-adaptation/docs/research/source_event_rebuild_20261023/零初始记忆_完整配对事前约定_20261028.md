# 零初始记忆：检验炮内修正是否依赖真实信号变化

本轮事前固定：原J-TEXT分类基模、输入映射方法、冷启动20炮、炮序、标签、风险阈值、
炮间训练和报警规则均不变。只比较源教学时允许初始诊断记忆学习，或把它固定为零。
不承诺零初始方案一定更好；若损失了有用预测先验，应如实报告负结果。

## 1. 为什么检验这一点

已有完整事件三组与参照梯度两组均未证明足够的独立炮内收益。
事后参数拆分发现，源教学后的模块已对后340炮普遍提高风险，冷启动进一步放大。
这不是简单的EAST类别比例错误：冷启动loss按破裂/安全分组等权。

当前临时矩阵以可学习的P开始，收到真实诊断增量d后更新：

```
W_new = W - eta * key * (key^T W - d) / (1 + ||key||²)
内部读取 = key^T (W - P)
```

实际代码对四个预测步的列分别更新，并对W-P实施范数限制。
当d=0而P非零时，矩阵仍会向更接近零预测的方向变化，因此内部读取不必为零。
这是合法的预测误差学习，但预警教学可能借用这段“先验消退”作为共同分数偏移。
目前只能把它列为可检验假设，不能把数学可能性当作已确认根因。

将P固定为0后，在整段诊断值不变且有效性处理相同的情况下，每次d均为0，W保持0，
内部修正严格为0；真实变化到达后仍可学习。不会删除基础编码器中的绝对物理量信息。
key、更新率和内部读出仍可在J-TEXT源训练集学习；不新增风险分数修正头。

## 2. 两臂训练与部署

- profile：`zero_prior_ablation_v3`，臂为`detached`和`zero_prior`。
- 两臂均用已实现的detached参照方向损失，无新增损失项或系数。
- 相同seed131、初始权重、TRAIN1353顺序，VAL160只报告，固定2epoch，不以EAST挑epoch。
- Adam学习率0.001、每8炮累计梯度、梯度裁剪1；零先验臂的prior不加入优化器。
- J-TEXT标签max(25ms,AdvancedTime)，局部及时点严格>10ms；基础模型文件保持不变。
- 每臂运行完整360炮（180D/180S），前20炮也计分；其后逐炮封存再揭示。
- 输出source/aligned/cold/intra/inter/both/both_shadow/intra_reverse全部臂。
- 同一阈值0.7258946895599365、EAST及时标准严格>30ms，超过3000ms另报。
- 每臂内部cold/intra对比识别炮内作用；两臂间冷启动参数会随源教学变化，不能只比最终both。

## 3. 验收与退出

先测零变化时严格无修正、真实变化可写入、参照梯度合同和冻结参数审计，再跑源训练与完整流。
独立审计检查源参数未改、1513源记录完整、prior冻结为零、360封存成绩可重计、两臂合同匹配。
零先验必须始终为零；缺失梯度仅在这一明确冻结参数上允许，其他学习参数仍要求有限非零梯度。

成功至少需要独立intra净收益、FPR≤0.20，并证明真实反馈优于扰乱反馈；之后再判断both互补。
若只有所有炮一起提高/降低风险或与扰乱反馈相同，不晋升，不加报警补丁弥补。
全流结果为开发诊断；不称独立确认、工业安全保证或新物理规律。
