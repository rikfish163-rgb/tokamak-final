# 不止Ai：从文献到炮内学习任务

2026-10-26；AI辅助原文核查和代码分析。用途是决定下一项可检验实验，不是系统综述或新颖性认证。
本轮补充MIT、JET/CIEMAT、华中科技大学、RIKEN及通用测试时学习研究。
各项实际读取范围见[证据登记](literature_claim_manifest_mechanisms_20261026.md)；
已有跨装置对齐、PhyDANet、HL-3、事件识别、FusionMAE、TTT++等见[上一轮扩展核查](跨团队文献扩展_数据对齐事件标签与炮内适应_20261026.md)。
只读到摘要或索引方法段的项目没有升级为“全文已读”；不同版本不重复计数。

## 1. 文献首先改变了什么判断

不是“找一个更新的网络，再加一个重建损失”就能实现有效炮内学习。
需要分别回答四件事：输入量是否可比、预警目标是否正确、这一炮能提供什么反馈、这个反馈怎样改善后续风险判断。
这些是不同实验因素，不能用同一条总成绩曲线替代。

### 1.1 MIT：时间点判断正确，不等于整炮报警正确

Keith、Nagpal、Rea、Tinguely，**Risk-Aware Framework Development for Disruption Prediction: Alcator C-Mod and DIII-D Survival Analysis**，JFE 43,21 (2024)。
[出版社全文](https://link.springer.com/article/10.1007/s10894-024-00413-y)。
<!--ref:keith2024risk--><!--anchor:section:Models; Methods for Comparing Disruption Predictor Performance-->

论文把训练分类窗口和操作所需提前量分开，并在整炮上模拟首次报警。
它还明确指出其同装置结果不能直接代表新装置表现。这支持我们检查训练目标与报警规则的关系，
但不构成炮内适应有效的证据。

**对应本项目：** 破裂前167ms的报警满足lead>30ms，却处在125ms正标签窗口外；
前29ms可能已有正标签，却不满足及时报警。不能一边在训练中强行压低所有早期风险，
一边在评价中奖励这些早期报警。如何处理窗口外片段必须作为独立标签政策实验，不能事后改计分。

### 1.2 RIKEN：训练时间范围与报警截止时间需要明确配合

Koshizuka、Yaguchi，**Horizon-Aware Early Event Prediction for Tokamak Disruption Alarms**，
[arXiv:2609.24443v2](https://arxiv.org/html/2609.24443v2)，2026-10-16预印本。
<!--ref:koshizuka2026horizon--><!--anchor:section:3.2; 4.3–4.6; 7.6-->

该文在相近编码器下比较不同预测目标，区分阈值无关排序与验证集校准后的报警成绩。
其主要截止时间为40ms，并非我们的30ms；其中整炮分类目标也不能等同我们的125ms时间点目标。
它没有验证在线炮内训练。

**对应本项目：** 下一种适应任务应以“更新之后的及时预警是否变好”作为离线训练依据，
不能只要求下一段诊断信号的误差下降。部署评价仍保留原来严格>30ms和完整360炮，不挪动门槛制造提升。

### 1.3 JET：轨迹输入、炮后学习、报警器变化要分开

Murari等，**Adaptive learning for disruption prediction in non-stationary conditions**，NF 59,086037 (2019)。
[CIEMAT作者全文](https://documenta.ciemat.es/server/api/core/bitstreams/6dc8a336-248f-449f-b485-f6e507e15021/content)。
<!--ref:murari2019adaptive--><!--anchor:section:3–6; 8–9-->

工作分别研究炮后更新训练集、输入历史轨迹、决策函数切换和过时样本移除。
其轨迹学习是利用多个时刻作为输入，并非在当前炮内持续反向传播；5ms及时标准、过早报警和启动炮计分也与本项目不同。

**对应本项目：** 增加历史长度可能有用，但只能称“利用历史”，不能自动称炮内适应。
回放也不宜只保留最近几炮而丢掉稀缺安全或破裂模式；这需要单独比较，不照搬论文的具体历史长度。

### 1.4 华中科技大学：活动的组合和演化，比单一幅值更值得研究

Zheng、Wen、Shen等，**Decoding density limit disruption precursor patterns in J-TEXT using interpretable machine learning**，NF 66,096030 (2026)。
[出版社](https://doi.org/10.1088/1741-4326/ae8d38)。
<!--ref:zheng2026density--><!--anchor:section:2–4; 6–7-->

该文排除Greenwald比例与核心密度，分析边缘密度、辐射不对称和MHD等联合特征。
其结果针对密度极限破裂子集；解释性归因是统计证据，不是因果定律。
当前23维缺少论文所用的部分空间阵列信息，不能由一个ne_nG重建这些物理量。

**对应本项目：** 不再把“MHD强”硬写成“将破裂”，也不把“持续活动”自动解释为危险。
应比较相似活动起点之后的恢复、持续和加剧过程。J-TEXT A–F弱标签可以辅助划分活动片段，
但未核实语义的类别不能命名为真实破裂原因；未标注区间也不等于安全。

### 1.5 TTT：应学习“怎样适应”，不只是执行一次自监督更新

Sun等，**Learning to (Learn at Test Time): RNNs with Expressive Hidden States**，ICML 2025。
[官方出版记录](https://proceedings.mlr.press/v267/sun25h.html)；
[已核查的方法版本](https://arxiv.org/html/2407.04620v1)。
<!--ref:sun2025tttlayers--><!--anchor:section:2.1–2.3; 2.7-->

其内层更新序列内的快速状态，外层则学习输入、目标和读取方式，使内部学习服务于最终任务。
这比“随便选一个重建目标”多了一层关键训练。论文实验是语言建模，不能直接外推到EAST。

更早的[TTT，ICML2020](https://proceedings.mlr.press/v119/sun20b.html)也不能被理解为
“辅助损失下降，分类就一定改善”；相关梯度论证有明确假设。
<!--ref:sun2020ttt--><!--anchor:section:Theorem 1 and assumptions-->

**对应本项目：** 当前临时记忆使用固定随机输入投影；只有读出及持久适配器接受风险监督。
它有真实更新，但并未完整实现上述可学习任务。不能将本轮失败表述为“TTT在EAST不适用”。

### 1.6 物理背景不能用额外规则补造

Murari等，**A control oriented strategy of disruption prediction to avoid the configuration collapse of tokamak reactors**，
Nature Communications 15,2424 (2024)，[全文](https://www.nature.com/articles/s41467-024-46242-7)。
<!--ref:murari2024control--><!--anchor:section:Results; Discussion-->

该研究结合辐射、能量与配置演化及控制背景开展风险判断。我们的23维和控制记录不具备同等信息。
因此不能把没有破裂的异常炮都解释为“模型其实正确、只是控制救回”，也不能据此更改FP定义。

Zhu等的[低参数→高参数研究](https://arxiv.org/abs/2109.08956)同样提示：
低参数样本多不意味着高参数覆盖充分，工况匹配需要检验。
<!--ref:zhu2021scenario--><!--anchor:section:Abstract-->
现有首100ms电流/磁场排序仍只能称离线运行参数代理；没有足够的储能、热负荷等信息，不能称真实损伤排序。

## 2. 代码审查：当前炮内模块到底在学什么

本节是代码事实，不是上述论文的结论。代码：
`experiments/risk_aligned_online/delayed_recurrent_memory_20261025/model.py`、
`lifecycle_stream_20261025/model.py`与`learning.py`。

1. 23通道每8点汇总一次；一次预测未来4段变化，不把自己的预测递归作为真值。
2. 等相应观测全部到达后，用预测误差更新本炮的临时矩阵；每炮重新初始化。
3. 临时矩阵为9×92；输入key由固定随机46→8投影加常数构成。更新率固定，状态范数有界。
4. 读数经92→64线性层进入冻结Transformer两层之间；不是在最终风险分数上再加校正值。
5. 现在的轨迹生成在`no_grad`内完成，风险训练没有穿过“临时矩阵如何学习”的过程。
   换言之，读出在学，但“什么样的自监督更新值得执行”没有被端到端学到。

因此当前失效至少存在一个明确候选解释：诊断拟合任务与风险任务脱节。
它不是已被唯一证明的根因；数据语义、历史覆盖、短暂预警边界和冻结表示能力仍可能限制效果。

需要纠正一个范围表述：本目录当前lifecycle版本只将事件标签用于源回放抽样。
更早分支已做过事件分类、配对和梯度对齐实验，不能说整个项目“从未使用事件监督”，也不能再次换名字重复这些实验。

## 3. 下一候选必须与旧失败实现有明确差异

建议保留原J-TEXT基模和风险头，另训练一个小型内部适配模块，优先验证下面的差异：

|环节|当前版本|待验证的改变|
|---|---|---|
|炮内学习目标|固定随机key下拟合诊断变化|在J-TEXT训练炮上学习哪些信号组合与更新方向有助于后续预警|
|训练梯度|风险监督只训练读出和持久层|梯度穿过因果临时更新，训练输入投影及受限更新规则|
|补充eventlabel|选取源回放窗口|仅作弱辅助；与同窗口无标签、标签置乱成对比较|
|在线访问|只用已到达诊断；炮后才读结局|保持不变，任何源域离线教学也模拟这个时序|
|验收|完整流中独立炮内无增益|先要求intra优于冻结对照及倒序/假反馈，再讨论both|

**最小验证不是先加一长串损失。** 先只比较“固定学习任务”和“可学习任务”，
其余信息和训练预算相同；事件监督在第二轮单独加入，不能同时变更多个因素后无法归因。
与旧20炮策略拟合相比，关键差别是使用J-TEXT TRAIN上的多炮训练信号，并让风险梯度穿过实际内层更新，
不是继续在少量EAST炮上拟合几个更新权重。该方案尚未完成实现或实验，不宣称已有效。

真实信号反馈仍需与倒序、假反馈以及无状态模块比较。
如果这些对照同样提升，只能说明静态附加容量或平滑有用，不能声称模型学会了炮内轨迹纠偏。

## 4. 本轮真实实验对设计的限制

已完成一项完整360炮单因素实验：把诊断记忆读数从去除共同分量改为保留完整分量。
结果未通过：单独炮内124TP/32FP，冻结对照125TP/32FP；倒序同为124/32。
具体失败炮、协议和复核证据见[完整结果](炮内完整读数_360实测与后续约束_20261026.md)。

这排除了“只恢复被删除的共同变化信息就能产生独立收益”这一具体猜想；
不排除其他可学习任务，也不证明某条物理机制。现阶段不继续扫同一读数的幅度或报警阈值。
所有既有数据均参与开发，结果属于开发诊断，后续仍需要锁定的独立未来流。
