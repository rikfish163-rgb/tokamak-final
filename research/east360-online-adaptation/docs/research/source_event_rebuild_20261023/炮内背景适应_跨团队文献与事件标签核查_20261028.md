# 炮内适应还应参考什么：跨团队文献与事件标签核查

2026-10-28。研究记录，不是系统综述、论文新颖性认证或新模型成绩。

## 本轮结论

不能继续只围绕Ai的部署流程设计。需要分别研究跨装置数据可比性、当前炮的背景变化、危险轨迹的识别，以及更新是否改善后续预警。已有文献不是同一个问题的不同名称。

本轮新增核读JT-60SA炮内无监督检测方法；补读、复核JET状态监测、时距预警和跨装置增强原文，不重复计算为新论文。也核对了沈呈硕的2026事件链会议摘要和本地标签说明。**没有声称读完100篇全文，也没有把搜索条目数当阅读量。**

本地新增的是源事件监督的只读统计：不改模型、阈值、标签或EAST炮序，没有新EAST预测成绩。前轮条件读出失败的结论不变。

**标签归属：用户补充的是J-TEXT阶段标签，不是EAST阶段标签。** 下文对A–F含义和数量的检查全部针对J-TEXT。可以借助它设计源域组件，但EAST不得获得对应的阶段真值，也不新增J-TEXT在线学习分支。

## 1. 文献各自解决什么，不能直接照搬什么

### 1.1 JT-60SA：每炮学习背景，但不把异常迅速吸收到背景中

Yokoyama等，*Online un-supervised tearing mode detection with sequentially discounting algorithms for JT-60SA*，Fusion Engineering and Design 222,115440，[出版社原文](https://doi.org/10.1016/j.fusengdes.2025.115440)。

已读官方搜索索引返回的§1–4、公式、表1及图2–4说明；直连403，未审查原PDF图像。方法在炮内更新统计背景，以两阶段ChangeFinder检测变化，再用Hotelling统计量判异常。两阶段遗忘常数为80/20ms；第一阶段结合装置壁时间选择。输入是磁探针构造的n=1正余弦分量，不是任意23个统计量。文中还讨论低性能投运阶段调试。它是特定磁模检测，不能当成神经炮内微调或全类型破裂预测的实证。

**本项目推论：** 应检查学习背景的速度是否把危险演化也吸收了。但我们的23列没有同样的磁探针相位输入和已核实壁时间，不能照抄其常数、重建n=1分量，或用统计告警替代神经更新验收。

### 1.2 JET：活动识别和破裂预测的指标不能混用

Bürli、Pau等，*Towards Transparent and Accurate Plasma State Monitoring at JET*，[作者稿v1](https://arxiv.org/html/2502.12182v1)。本次复核§2–6；属于既有阅读的扩展。

论文联合训练状态表示、破裂判断、边界时间及平滑任务。完整诊断筛选后430炮；序列网络原始FA为23.3%，考虑附近不稳定事件后改记为FA′=8.18%，再加200ms报警持续条件为6.13%。这些定义不同；不能把后两个数字解释为纯神经适应的严格误报率。

**本项目决定：** 安全炮出现报警仍计FP。事件标签可帮助解释它为何误报，不能替模型改答案；轨迹平滑也必须有取消平滑的对照。

### 1.3 RIKEN：先明确预测目标，不必更换更大的网络

Koshizuka、Yaguchi，*Horizon-Aware Early Event Prediction for Tokamak Disruption Alarms*，[当前v2](https://arxiv.org/html/2609.24443v2)。本次重读v1方法/评价和v2引言，完整v2方法阅读沿用既有登记；版本不混用。

该研究区分整炮结局、有限时距目标及生存目标，并区分排序能力与固定报警策略。它是装置内监督实验，采用40ms评价，不是J-TEXT到EAST炮内适应。本项目保留J-TEXT严格>10ms、EAST严格>30ms；不引用v1数值代替v2或本地结果。

**本项目决定：** 诊断预测误差下降不足以验收；必须报告更新后及时危险窗口与安全窗口分别怎样变化。不能把固定标签窗口称为物理前兆起点。

### 1.4 MIT合作团队：时序增强不是零样本迁移的保证

Chayapathy等，*Time Series Viewmakers for Robust Disruption Prediction*，[作者稿v1](https://arxiv.org/html/2410.11065v1)。本次复核§1–6和附录A/B及表4开头；此前已读，不新增计数。

该方法学习时序增强，在C-Mod作为目标装置的实验中效果依赖模型和样本条件。表1的零样本GPT-2 AUC由无增强0.575变为Viewmaker0.527；论文说明没有多种子运行。不能根据平均提升推断零样本必然更好，更不能把增强训练称为实时炮内学习。

**本项目决定：** 若加入增强，应明确它保留了什么物理语义，并保留无增强对照；不能任意扭曲时间或幅值后假定破裂标签不变。

### 1.5 沈呈硕及合作者：事件链值得研究，但本地导出不是完整物理真值

沈呈硕，*Autonomous Discovery of Disruption Precursor Event Chains in Tokamak Plasmas via Progressive Multiple Instance Learning*，[IAEA2026官方摘要](https://conferences.iaea.org/event/451/contributions/42899/)。本次读官方索引完整Description；直连403，没有取得完整讲稿。摘要介绍弱监督前兆发现、时间剥离及聚类，不把会议摘要当作已复现完整方法。

本地`字段说明.txt`明确：仅导出冻结K=6最终合并事件，**不包含MIL原始onset点**；A–F不是人工确认物理模态，且没有强制A→F顺序。所以不能把摘要的onset数量和CSV的最终事件数量直接比较，或擅自补出恢复标签。

跨装置对齐的Shen S-CORAL、Zheng等Communications Physics、Xue物理先验，以及Murari持续学习、TCV动力学和TTT研究已有分项核读；详见[既有跨团队综述](跨团队文献扩展_数据对齐事件标签与炮内适应_20261026.md)、[方法约束](从文献到炮内学习任务_扩展核查与设计裁决_20261026.md)。它们继续作为对照依据，不以此次新检索冒充首次阅读。

## 2. 真正清点本地标签后，能训练什么

只按既定TRAIN1353和VAL160身份统计。CSV文件本身包含历史测试炮标签，上游生成也接触完整记录，因此仍是开发诊断。本轮不读取任何HDF5、模型checkpoint、EAST信号或TEST220缓存。

| 数量，非预测成绩 | TRAIN1353 | VAL160 |
|---|---:|---:|
| 有事件标注的炮 | 327 | 83 |
| 只有1段事件的炮 | 259 | 56 |
| 有2段事件的炮 | 62 | 25 |
| 有3段事件的炮 | 6 | 2 |
| 最终事件段总数 | 401 | 112 |
| 相邻事件对 | 74 | 29 |
| 两段之间存在未标注空隙的事件对 | 54 | 16 |

TRAIN只有68炮含多个事件，占有事件炮的20.80%，不是1353炮都有完整事件链。74组事件对中30组同字母、36组字母升序、8组降序。这只是注释序列的统计，不是恢复/恶化统计；多个事件对也不是独立炮。

六类在TRAIN都出现在两种炮级结局中。例如D类涉及114个破裂炮和44个安全炮；C→D相邻组合在破裂炮出现23次、安全炮出现4次。这些事件对间可能有空白，不能据此估计完整链的转移概率或因果效应。

这排除了三种不可靠的直接用法：

1. 用A–F字母顺序作为风险单调上升标签。
2. 用某段结束或空白区间作为恢复/正常标签。
3. 用识别事件类别的准确率替代“是否及时预警破裂”的成绩。

可行用途是训练片段分层、构造同类活动下的不同结局对照、检查误报与漏报覆盖。以前已经做过事件分类和配对，本次不会将其改名当成新架构。

## 3. 对下一项实验的具体约束

以下是从文献和本地失败归纳的设计判断，尚非有效性结论。

**要检验的区别：** 慢背景适配是否能减少装置/工况差异，同时保留比背景变化更快的异常轨迹。与旧`context_separation`的窗口均值/局部拟合、以及当前八维变化预测不同，新增假设必须涉及背景更新和危险演化的时间尺度分离，不能只给现有读出换一种激活函数。

先做按真实时间计量的诊断：用已有原始时钟检查各通道变化尺度与当前反馈延迟，不能把8个采样点在不同装置上都当成相同毫秒。需要同时检查短暂活动、安全但持续的活动和临近破裂窗口；eventlabel只作分层，风险方向由源训练结局及合法炮后反馈提供。

随后若实施候选，应保留四项区分：固定背景、仅动态背景但无神经更新、相同预处理下的内部神经更新、扰乱已到达反馈。只证明动态标准化改善，不等于证明神经适应；只证明后处理改善也不算。

不再预设某个信号升高就应上调风险，也不要求每个诊断异常都触发学习。源训练要检验同一次内部更新对**后续**风险的影响；当前EAST炮只使用已到达观测产生更新，结局在封存后进入炮间经验。临时状态每炮重置，源基模和风险输出头保持可追溯。

最终仍在同一完整在线流上比较冷启动后冻结、intra、inter、both，并计入最初冷启动炮；阈值、计分、炮序相同。要求独立intra有收益，然后才讨论组合。本文没有启动新GPU训练，没有声称达到上述目标。

### 3.1 可借鉴阶段标签的组件位置

用户澄清后，候选按下面的信息边界设计；这是待验证组件，不是已实现有效的方法：

| 组件 | J-TEXT离线学习时 | EAST逐炮使用时 |
|---|---|---|
| 阶段辅助表示 | 用TRAIN的已标注区间监督一个小型辅助编码器；空白区间不补成正常 | 只能从当前及过去信号估计软表示；不能读J-TEXT标签替当前炮定阶段 |
| 条件诊断预测 | 将模型估计的表示用于区分不同演化背景，预测多个未来时距的诊断变化 | 一次直接输出未来窗口；相应真实观测到达后才计算误差，不递归喂入自己的预测 |
| 内部更新规则 | 用源训练炮结局检验：在不同背景下，同一次诊断反馈更新是否改善后续预警 | 只更新临时内部参数；炮结束后才用结局积累持久经验 |

这里的软表示仅是模型坐标，不宣称J-TEXT阶段在EAST具有一一对应物理含义。源训练也应使用当前前缀产生的预测表示作为条件，而非把完整记录导出的阶段真值直接喂进前向；标签只在离线监督端出现，避免训练/部署信息不一致。

之前“多加一个A–F交叉熵头”已经失败，不能原样重做。新增组件必须证明它改变了**有用的诊断反馈及内部更新方向**，而不是仅提高阶段分类分数。至少保留同容量无阶段监督、源阶段标签按既定分层置乱两项对照；同类阶段中的破裂与安全炮都需覆盖。若没有额外收益，删除此组件，而非为了使用补充数据强行保留。
