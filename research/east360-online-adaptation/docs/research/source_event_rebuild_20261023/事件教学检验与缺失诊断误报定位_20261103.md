# 事件教学检验与缺失诊断误报定位

日期：2026-11-03。源事件教学筛查、完整TEST220静态缺测对照及数值／缺失标记分离对照均已完成。EAST独立炮内收益的总目标尚未完成。

## 1. 先说目前最重要的结论

**J-TEXT原模型本身没有掉到0.6：原始完整诊断的TEST220成绩重新复现为TPR>10ms=0.909091、FPR=0.118182。** 但是，若在完全相同的J-TEXT测试炮中隐藏CIII，FPR便上升至0.245455；同时隐藏CIII和MNM时为0.263636。这个差异在还没有换到EAST时就存在。

因此，不能只问“为什么炮内损失不降／更新不够大”，还要先问：源模型在目标域缺少诊断时，内部表示是否仍在它学过的适用范围内。缺失诊断是本轮直接控制的因素，但它不能独自解释EAST全部域差异、尺度问题或在线失败。

J-TEXT补充事件标签已经实际用于新一轮离线辅助教学。教师在留出事件片段上的顺序判断为84/102，但其临时神经更新反而使靠近破裂窗口的风险损失增加，并未胜过随机或打乱标签教师。**这项候选被拒绝，不把辅助任务做对等同于炮内预警有效，也不继续用它跑完整EAST360。**

## 2. 本轮始终固定的内容

- 是否破裂和DownTime统一采用HDF5。源域窗口仍为`max(25ms,AdvancedTime)`，EAST仍125ms；及时报警分别严格>10ms和>30ms。
- 原合格源模型SHA为`c7270c1ea3652db2e30e972d4ca9a4a2d33220a68e4a3765c8b7f5bcceeaeb02`，没有重训、替换或写回其参数。
- 原23维输入及源归一化不重排、不重新标定；J-TEXT电流仍只乘一次1000。
- 事件教学只训练新的离线辅助线性教师，原Transformer与风险头均冻结。源域临时状态只用于独立episode的离线作用检查，**没有运行J-TEXT在线流**。真正在线适应的目标仍是EAST。
- 所有结果均为已多次参与开发的数据诊断，不是独立未来验证，也不证明新物理规律。

## 3. event label具体怎样用，而不是只口头引用

只在TRAIN/VAL已标注区间中选择前后相距25个采样点、两端同属于一个导出事件的片段。每事件最多选四个分位位置；再为每对找同炮±50点内、监督分组相同的最近对照，其两端不能同属任一已标事件。两端没有同属一个区间不代表“正常”或“无事件”。A–F是名义类别，不按字母当危险等级。

直接重读HDF时钟和结局后，实际得到：

|数据|匹配后炮数|事件数|片段对数|靠近源监督窗的破裂炮数|
|---|---:|---:|---:|---:|
|TRAIN|149|158|376|10|
|VAL|31|37|102|8|

VAL匹配片段中安全样本只来自5炮，因此不能用它单独证明低误报。风险检查使用原先固定的全部946个VAL诊断episode，来自145炮，其中638个安全、117个源监督窗内、191个更早的破裂炮端点。后两组炮号有重叠，不能把64和51相加当独立破裂炮；合并后为65个不同破裂炮。

每端的特征由第一层FFN的有效数据token均值与最后有效token组成，共128维。固定TRAIN两端特征的标准差，仅缩放、不拟合VAL或EAST。新的线性教师判断哪个片段在后，使用softplus顺序损失。三组教师同初始化、同抽样、同训练预算：真顺序、整事件打乱顺序、匹配其他片段的真顺序。另保留未经训练的共同初始教师。

三组各用512个AdamW步，batch64、lr0.001、weight decay0.001、seed131，固定末轮。只对教师反向传播，不更新源分类器。新的实际GPU计算另在每个VAL episode从零构造一个4×64的临时第一FFN状态，沿顺序损失梯度单位化走0.1步，内部位移按原0.25 RMS上限限制，再看更晚query的原风险头输出。不存在把顺序分数加到最终风险上的操作。

主要风险量是相对固定报警阈值的margin BCE：对所有可及时预警的破裂炮query取目标1，安全为0。原监督窗点标签及普通BCE另行保存，没有修改基模训练标签。如此不会把破裂炮在训练窗外的有效早报警一概当错误。

## 4. 顺序学会了，但更新方向仍不对

真教师在TRAIN376对中判对317对，VAL102对中判对84对；匹配其他片段教师在同一VAL事件对中判对80对。高顺序判断率不是独立炮数，也不是破裂TPR。

完整诊断视图也未通过预设筛选。真教师不是没有学会辅助任务，而是辅助任务学到的方向未对准更晚的破裂判断。该问题在源域本身已出现，不能只归咎于EAST分布变化。此结论只拒绝本轮具体教师，不否定所有event label用途。

解析审查还表明：同一对片段上正向与反向softplus损失梯度天然相反；单位化会抵消损失置信度的标量幅度。第一FFN的这一线性池化更新在零状态处矩阵秩至多为2。故同一片段的顺序损失下降，不能作为“学到了本炮机制”的证据。真实GPU筛查包含随机与匹配教师，避免只靠正反方向比较。

本轮共计算9,460条方法－episode记录；10批实际第一FFN插入与缓存路径的零状态、更新后logit逐值一致，每批64个query。完成用时6.649秒。它不是完整炮流，也不是J-TEXT在线模型。

另一次独立CPU审查对全部9,460条记录重算，margin BCE差的最大误差为5.45e−16，炮级宏平均差的最大误差为2.13e−17；160个VAL HDF元数据核对无结局、点标签、分组或提前量差异。原946个episode没有覆盖其中15个破裂炮，不能把局部筛查当作完整VAL成绩。全部临时状态有限且非零，范数与0.1的最大差为1.72e−9；反向状态只是在浮点容差内近似相反，不冒称逐位反号。该独立审查没有重训教师或重跑神经前向。

## 5. 冻结源模型的完整220炮缺测对照

这一步只做静态推理。所有组用同一源模型、同一源scaler、同一0.7258946895599365阈值、同一110破裂／110安全炮、同一首次报警规则；没有在线梯度、没有重校阈值。

|输入条件|TP / 110|FP / 110|TPR>10ms|FPR|J|
|---|---:|---:|---:|---:|---:|
|原始合格输入|100|13|0.909091|0.118182|0.790909|
|仅应用当前CIII无效值合同|100|13|0.909091|0.118182|0.790909|
|隐藏MNM|92|15|0.836364|0.136364|0.700000|
|隐藏CIII|100|27|0.909091|0.245455|0.663636|
|同时隐藏MNM+CIII|97|29|0.881818|0.263636|0.618182|

原始组的全部220炮结局、报警、及时与否以及提前量，与原资格记录一致（时间差容差1e−6 ms）。原始组中位提前量仍65.5573 ms。CIII单独隐藏新增14个误报，没有救回或丢失及时破裂炮；MNM隐藏则丢失8个及时破裂炮。两者共同隐藏的作用并非简单相加，不可用一个通道的重要性排名代替。

**这些是J-TEXT的静态缺测反事实，不是EAST成绩。** 它们证明这个固定模型对诊断缺失不够稳健，却不能把EAST的全部误报归因于这两个通道。EAST现行输入始终把MNM标为不可用，CIII只对局部无效值标缺失，并非每炮都把整个CIII删除；真实覆盖比例与本对照不能混称。

独立CPU审查另从220个封存NPZ重读1,100条方法－炮曲线、重新读取HDF结局与时钟，逐炮评分和汇总均一致。GPU静态计算用时8.503秒，没有修改源模型。

## 6. 信号信息丢失与缺失标记：已完成分离对照

上述删除诊断同时改变了两个输入：该通道的数值信息，以及可用性标记。因此目前尚不能只凭FPR上升断言是缺失标记在起作用。

固定对照保留原可用性，把原本有效的CIII／MNM数值替换为源中心，使其归一化后为零。与合法缺测输入相比，两者的对应归一化数值相同，但可用性位不同。**这是人为的计算诊断，不是真实观测补全，更不能拿“假装传感器有数据”作为部署方法。** 仍是同一静态模型、110破裂／110安全、严格>10ms、阈值不变：

|信号操作|中心数值、保留可用标记：TP/FP|合法缺测、标记不可用：TP/FP|
|---|---:|---:|
|CIII|99 / 21|100 / 27|
|MNM|98 / 16|92 / 15|
|CIII+MNM|96 / 21|97 / 29|

对比原始100/13，可见丢失数值信息本身已有影响；在CIII中心数值组上再改变可用性标记，又净增加6个误报，同时救回1个及时破裂炮。联合组改变标记后则新增9个误报、移除1个旧误报，净增8个。这不是对物理危害的因果实验，也不能把沿这一人为路径的净变化当作普遍贡献百分比。

独立CPU检查重算全部660条新曲线，并逐点构造两组归一化输入：所有23列的归一化数值完全相同，最大差0；每个时间点“是否至少有一个观测”的状态也相同，只有指定通道的可用性位不同。因此，上表两列的差异可定位到模型内处理通道可用性的路径，而不是另换阈值、归一化数值或标签。5组基线曲线是明确复用先前封存结果，并未冒称本轮又重新计算它们。

### 6.1 为什么这不是一个可以忽略的小标记

模型在每个时间点把23个归一化数值与23个可用性位拼接，再进入线性patch嵌入。重新扫描当前TRAIN、VAL、TEST的CIII、MNM与Bt，三个角色分别476,194、48,606、67,375个时间点，CIII/Bt与MNM/Bt的可用性不一致次数均为0；CIII无−10局部缺测哨兵。前置窗口padding则让这些标记同时为0。

在这种共同观测模式下，两个标记的嵌入贡献可写成“CIII权重×标记＋Bt权重×标记”，输入只展示两组权重的和。把一部分权重从其中一组转到另一组，在共同可用／共同缺失输入上的线性结果不变；当目标域只缺其中一个通道时，结果却会改变。这是当前数据与输入层下的可辨识性限制，不是“可用性标记一定没有用”，更不是把全部EAST误报归因于一个公式。优化器、初始化、正则化可以选出某一组权重，但不等于其单通道缺测语义得到了数据验证；历史训练中全部增强细节也未由这次扫描追溯证明。

另在实际源模型嵌入权重的CPU副本上做了一个合成patch检验：把CIII标记列的权重转到Bt标记列，共同可用输入的嵌入差最大4.44e−16（float64），而CIII缺失／Bt存在时的最大坐标差为0.2257422。原模型与文件均未改变。这是线性层数学示例，不是实际炮的风险收益，也没有把这种权重再分配作为部署修复。

本次对照已经说明，**需要分别处理真实信息缺失和缺测输入反应**。下一轮可以在保留原合格主干的条件下，检验一个经过源数据缺测任务教学的内部适配部件，并把时间padding与诊断不可用明确区分。静态缺测修复必须单列为静态对照；之后仍需从同一起点比较无更新、仅炮内、仅炮间及联合更新，不能把静态修复换名为炮内增益。这是后续研究方向，尚未宣称已经实现或有效。

## 7. 文献怎样影响判断

- [Shuffle and Learn，ECCV2016](https://arxiv.org/abs/1603.08561)说明时间顺序可以作为视频表征学习任务，但不保证该任务的梯度改善破裂风险。本轮没有声称顺序学习概念新颖。
- [TCN作者项目页](https://sermanet.github.io/tcn/)使用多视角同时间配对和时间邻居对比。本项目没有这种多视角条件，不把两者当同一任务，也不把时间相邻自动视作物理状态相同。
- [Vega等，Nuclear Fusion 64,046010（2024）](https://documenta.ciemat.es/items/8dfa0d73-919b-40a9-8c4e-39a613c0a8d0)明确区分训练可用、运行不可用的诊断信息，采用SVM+特权信息学习。这里核对了机构原文的摘要与第1节；它不是本项目神经炮内适应的直接验证，原文指标不与本项目严格提前量指标直接比较。
- [EAST多模态蒸馏预印本（2026）](https://arxiv.org/abs/2607.04241)的摘要说明训练用图像与时序、推理只留时序学生。当前仅核实摘要与元数据，未声称复现其结构；本数据没有对应图像，event区间也不是同质量的物理机制真值。

这些来源支持把“缺少诊断时怎样保留决策信息”独立出来研究，不构成我们已经得到在线增益的证明。此次定向补查不冒称重新完整阅读了100篇论文。
