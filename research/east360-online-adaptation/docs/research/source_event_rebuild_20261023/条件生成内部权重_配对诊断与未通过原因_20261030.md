# 条件生成内部权重：配对诊断与未通过原因

## 结论

新实现已经运行并复现，但**尚未证明当前炮新到达的信号能带来额外预警收益**。两种内部更新规则都降低了部分危险窗口的分类损失；把新到达反馈换成历史均值，效果却不差。新规则没有通过运行前规定的筛选，因此不进入完整360炮实验，不报告新的TPR或FPR。

达标J-TEXT源模型、EAST冷启动父模型、输入映射、原风险头和报警参数均保持不变。在线适应对象仍只有EAST。本次不是J-TEXT在线实验，也不是对V3C的复现或改写。

## 1. 这次实际改了什么

旧规则先产生一个64维内部表示目标，再反向计算第一层注意力Q/K矩阵的临时改动。新规则根据相同输入，直接生成Q、K各自的两个低秩因子，形成两个临时矩阵：

\[
\Delta Q=B_Q(c)^\mathsf{T}A_Q(c),\qquad
\Delta K=B_K(c)^\mathsf{T}A_K(c).
\]

这里，\(c\) 是截至更新时刻已经可见的358维上下文；每个因子是2×64矩阵，因此每个矩阵改动的秩不超过2。两组改动的联合Frobenius范数限制为0.1。限制的是**最终权重矩阵改动**，不是因子自身的大小。

358维包含起点的CLS表示64维、末端token表示64维，以及随后25个已到达点分成5段后的通道变化均值和有效比例，共5×46维。变化量采用现有源模型的asinh坐标，MNM不进入这部分反馈。它不是下一状态预测误差，也不是当前炮真实破裂标签。

新生成器有29,100个参数，旧表示目标生成器有14,316个参数。二者都通过已结束历史炮的监督训练学习更新规则。**新方法在当前炮内只做前向权重生成，没有无监督反向传播；旧方法在当前炮内有一次表示目标梯度计算。** 这两者必须分别命名，不能用“参数变了”替代“在线反向训练”的证据。

新方法的动机参考了冻结主模型、由历史监督训练低秩权重生成器的研究，但这里只采用确定性生成，不复现其分布采样或语言模型成绩。[Khan等，2026年预印本，第3.1与4节](https://arxiv.org/html/2610.01934)。

旧方法的单步改动位于起点CLS对Q/K的Jacobian转置像空间中。新方法没有这一显式限制，但增加了低秩限制：**两种可行改动集合一般互不包含**。本实验没有测量实际动作的子空间外比例，不能据结果断言“突破表示瓶颈”或把差异唯一归因于几何结构。

## 2. 数据和时序边界

使用已经结束的冷启动20炮：17个破裂炮、3个安全炮。复用之前封存的2707组固定时点，没有读取后340炮信号或结局。

每组起点为\(o=127+25k\)，到\(o+25\)才允许使用随后25点，临时权重只评价在更晚的\(o+50\)输入上。每组从零临时状态开始，不在窗口之间或炮之间累积。这是**更新组件诊断**，并不是完整逐炮在线流。

2707组中，安全炮窗口527组，及时危险窗口63组，破裂炮较早阶段2095组，迟报阶段22组。及时危险指查询时刻满足\(30<\mathrm{lead}\le125\) ms。窗口彼此相关，不能把2707当成2707个独立实验；安全独立单位仅3炮。

三折按炮划分，每折留出1个安全炮及5或6个破裂炮。上下文尺度、均值和生成器仅用该折拟合炮。但是**cold20父模型已经使用过全部20炮**，所以留炮只隔离新增组件的训练，不能称为整个系统的独立交叉验证。

每种规则每折固定训练256步，Adam学习率0.001，批大小24；12个安全窗口和12个及时危险窗口，类内先等概率抽炮，再抽该炮窗口。两种规则使用相同抽样序列、seed 131、相同矩阵范数上限，只使用最后一步，不按留出结果挑epoch。参数量和计算路径不同，因此不是严格等容量对照。

**训练没有纳入破裂炮的较早阶段和迟报阶段。** 它们仅用于评估，因此不能用拟合损失代表整条轨迹。较早阶段按125 ms训练窗口记为0，但这不等于物理上确定正常；是否应纳入训练及如何监督，需要同时考虑实际报警标准。

## 3. 如何判断是否真的利用了新反馈

每种规则都保留不更新基线，并评价四个分支：

| 分支 | 改动的输入 |
|---|---|
| 真实反馈 | 起点表示和按时间排列的已到达变化 |
| 倒序反馈 | 保留起点，将5个变化块倒序 |
| 均值反馈 | 保留当前起点，仅把反馈部分换成拟合炮的平均值 |
| 固定上下文 | 起点表示和反馈都换成拟合炮平均值 |

对照的矩阵改动范数匹配真实分支，匹配之前、半径投影之后的范数也保存。**这些是借用真实分支幅度的归因对照，不是完全不依赖当前反馈的独立部署策略。** 旧表示目标规则即使固定控制器上下文，动作仍经过当前起点的Jacobian。比较回答的是：在相同改动幅度下，真实反馈产生的方向是否优于替代反馈产生的方向。

报告数值是“更新后BCE减去不更新BCE”：先在每炮同类窗口内平均，再对炮等权平均；负值表示这一组查询点的分类损失降低。不是准确率、救回炮数或报警率。

运行前要求真实反馈同时改善安全与及时危险两组，至少2/3安全炮和9/17危险炮改善，而且两组均优于三个反馈对照。另检查真实与倒序动作是否足够不同。这是开发筛查，不是统计显著性或部署安全认证。

## 4. 全部主要结果

| 内部更新规则 | 反馈 | 安全炮平均ΔBCE | 及时危险平均ΔBCE |
|---|---|---:|---:|
| 直接生成低秩权重 | 真实 | −0.126746 | −0.257515 |
| 同上 | 倒序 | −0.129594 | −0.252074 |
| 同上 | 均值反馈 | −0.128836 | −0.287389 |
| 同上 | 固定上下文 | +0.107619 | −0.235225 |
| 表示目标再反传 | 真实 | −0.140617 | −0.291600 |
| 同上 | 倒序 | −0.140678 | −0.272414 |
| 同上 | 均值反馈 | −0.142842 | −0.313652 |
| 同上 | 固定上下文 | +0.160589 | −0.331640 |

两种真实反馈均有2/3安全炮、14/17破裂炮的相应平均损失降低；**这不是救回14个破裂炮**。直接生成器在两组平均损失上均没有超过同协议重新训练的旧表示目标规则。

直接生成器真实/倒序动作方向余弦中位数0.987167，99.41%的后续logit差超过1e−4；旧规则分别为0.995219和97.52%。这说明顺序能改变动作，却不说明动作更有用。直接生成器未通过三项效用条件：安全组不优于倒序、两组均不优于均值反馈；旧规则另有危险组不优于固定上下文和方向相似度条件失败。

较早阶段的点标签拟合也发生变化：直接生成器平均ΔBCE为+0.082797，旧规则为+0.078819，两者均有15/17炮损失增加。**这里的“变差”仅相对于125 ms内为1、此前为0的点标签。实际及时报警只要求提前量>30 ms，超过125 ms的报警并不因此失败。** 因而，这一损失增加既不能直接当成新增误报，也不能当成已证明的更早预警收益。超过3000 ms的过早报警仍需在完整流另报；本组件没有计算首次报警。

两种规则变差的炮相同：安全炮70404，及时危险组70327、70861、71370。直接生成器在70327上的平均ΔBCE达到+1.557148，不能只用总体均值掩盖此类反例。

### 拟合时有用，留炮后优势没有保留

训练汇总显示，两种规则三折内的真实反馈都优于均值反馈的危险组损失；但六个对应留出比较全部反转。例如直接生成器三折的“真实减均值反馈”在拟合炮上为−0.034808、−0.050408、−0.072279，在留出炮上变为+0.000784、+0.044451、+0.047287。

这支持一个比“参数没有更新”更具体的判断：**拟合出的新反馈优势没有迁移到其他炮**。但不能唯一归因于过拟合、信息压缩或样本不足。拟合部分来自保存的最终汇总，未保存逐窗口训练预测，故未独立重算其BCE；留出部分已从原始NPZ独立复算。三安全炮和单seed只能用于排错，不构成稳定泛化证据。

## 5. 可以下的结论，以及不能下的结论

- 可以确认：历史监督能训练出会改变内部注意力权重的规则；新规则实际输出不同动作，问题不是“更新完全没有发生”。
- 本规格下没有证明：新到达反馈比保留起点、换成平均反馈更有价值。不能把总体损失下降全部归因于炮内学习。
- 没有证明：已到达信号本身不含有用信息，或所有注意力更新方法都失败。当前信息压缩、训练目标、训练炮覆盖和参数化同时存在限制，不能由一次阴性结果排除整个方向。
- 没有新的完整流TPR/FPR，不覆盖炮间经验积累，也没有检验J-TEXT事件阶段标签在本规则中的作用。它不能代替用户要求的完整系统验收。

下一步若继续该方向，应先把“安全炮误报”和“破裂炮较早报警”分开诊断，并使历史教学目标与首次报警的实际要求一致，而不是继续增大学习率。只优化30–125 ms查询点损失不能保证整炮收益；反过来，把破裂炮所有较早窗口强压为0也可能损害合法提前量。当前仅3个安全炮，不足以证明更新在正常工况下可靠。是否补入较早窗口、如何兼顾其监督，必须另立配对实验，**不能将其当作已经找到的修复方案**。
