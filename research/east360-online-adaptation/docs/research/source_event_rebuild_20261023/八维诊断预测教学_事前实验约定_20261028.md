# 八维结构的诊断预测教学：单因素实验约定

## 问题与唯一改变

已完成的context8_v1源VAL160诊断预测平均误差0.451471，保持当前值基线为0.450783，
仅28炮改善；完整EAST流intra124TP/32FP，cold125/32。源目标只训练风险，诊断误差仅记录。
本次检验显式学习诊断预测能否提供更有用的炮内更新信号，不预先认定它是全部失败原因。

固定结构、初始化seed131、源TRAIN1353/VAL160、两轮、Adam0.001、8炮累积、梯度裁剪1。
原J-TEXT基模与风险头不变。与既有源目标相比，只增加系数为1的诊断预测均方误差：

    L_new = L_existing_risk + L_diagnostic_forecast

原目标仍为bag + 0.5 local + 0.5 direction（参照分支停止梯度）。
预测的是源归一化后的23列诊断块增量，每8点一块，一次输出后续1至4块。
逐炮损失使用所有四个时距均在记录内的起点；仅在起点与对应真值都有效的通道上计分。
这次不更改通道选择、标签、目标归一化、基模、报警阈值或炮序，也不扫描权重。
系数1是预定的首轮对照设置，不是文献已证明最优的物理常数。

源训练可使用已完成源TRAIN的未来观测计算监督误差；前向快速状态仍只能依赖已到达观测。
EAST部署不读取未来真值，不递归使用模型输出冒充观测，不改变临时状态炮末丢弃的约定。
新profile为context8_forecast_v2，与旧context8_v1分别存储，禁止把两者混称同一模型。

## 源域筛选条件：先登记，再运行

固定使用epoch2，不依据EAST选择轮次。进入EAST完整流前，在全部VAL160上必须同时满足：

1. 等权按炮平均的诊断MSE不超过保持当前值基线的0.99倍；1%是开发筛选幅度，不是显著性界限。
2. 至少81/160炮的诊断MSE优于保持当前值。
3. 真实反馈MSE低于相同状态范数的时距扰乱反馈。
4. 源VAL采样端点的bag与local风险损失均不高于epoch0。

全部条件满足也不说明达到课题目标，只表示该候选值得进入EAST；若失败，保留实际结果和失败原因，
不再为它进行EAST阈值扫描。VAL本身已经参与开发，不能将该筛选称独立验证。

## 后续EAST对照

若通过，沿用相同完整360（包含启动20）、180D/180S、严格lead>30ms、固定阈值、
同一输入映射与炮间监督合同。比较cold/intra/inter/both、组合关闭当前炮内反馈、反馈时距扰乱。
先要求intra独立改善且FPR≤0.20，再检查组合与时序贡献；不以预测MSE下降替代及时预警验收。
源VAL误差和任何未完成的EAST前缀都不作为完整流成绩报告。

## 实现与约束

复用既有context8代码，通过显式开关加入预测损失。默认旧损失保持不变，梯度与profile均加回归测试。
源缓存与原数据摘要照常核查。源模型不覆盖，结果写新目录。
只改变这一个源训练因子，因此仍保留已知23列定义/对齐不确定性；不声称物理规律已识别。
参考CoDA/NCF/LEADS与TCV状态表示的设计边界见同目录文献表，本轮不是这些方法的完整复现。
