## 只改一个因素

沿用现有`direction_teaching_20261026`源教学与完整流，显式启用`--reference-ablation`。两个臂：

1. `direction`：更新前、更新后两条计算路径均参与方向项反向传播。
2. `detached`：只在方向项中把更新前误差视为本次计算的固定参照。

设B为以冻结报警门槛为中心的二分类损失，a=B(z_after,y)，b=B(z_before,y)。

```
joint:    L_direction = 0.02 mean[softplus((a - b) / 0.02)]
detached: L_direction = 0.02 mean[softplus((a - stop_gradient(b)) / 0.02)]
L_total = L_bag + 0.5 L_local + 0.5 L_direction
```

前向损失数值完全相同，只改变反向梯度。这里不是永久冻结一个teacher；两个预测仍共享参数，下一次前向时参照预测仍可能变化。因此不保证每一次更新都改善预警。

## 完整流与验收

两臂分别从相同源起点运行EAST完整360炮（180破裂、180安全），原始前20炮也计入总成绩。
相同炮序、20炮后对齐及冷启动、后续炮间回放、固定阈值0.7258946895599365、固定报警器、同一严格lead>30ms指标。
每条流保留source/aligned/cold/intra/inter/both/both_shadow/intra_reverse。结局只在本炮全部预测封存后揭示，fast每炮清空。

主要先看每条流内部intra−cold：J须增加且FPR≤0.20；再看both是否优于intra，以及reverse反证是否仍与正向等价。
不同源教学得到的冷启动权重可能不同，不能把跨运行intra差值全部归因于炮内更新。
记录每个翻转炮、提前量、秒级过早报警及副作用；总成绩和冷启动后成绩分开，总成绩为主。
未满足验收则不晋升；不得用阈值重选补救或只报告有利区段。所有结果为开发证据，不是独立验证或物理规律发现。
