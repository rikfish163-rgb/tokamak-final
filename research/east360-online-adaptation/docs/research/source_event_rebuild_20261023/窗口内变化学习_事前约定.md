# 窗口内变化学习：固定的一次架构检验

## 依据与假设

上一轮已经排除平方损失步长过大：校正后所有辅助误差下降，但炮内开启仍比关闭少检出 2 炮、多误报 2 炮。内部审计显示变化项梯度范数与总梯度范数的比值中位数只有 0.00320。新完成的 J-TEXT 事件信息消融显示：平均水平即能达到约 0.732 的六类宏平均 F1，全特征约 0.774；因此高事件分类成绩不能替代危险轨迹建模。

本实验只检验：去掉辅助回归中的窗口平均项，是否会使内部临时更新更有益。不是新物理机制识别，不声称时序预测。

## 唯一结构改动

在过去 128 点窗口对应的有效测量 token 中，对学习得到的 K、V 分别减去各自平均值；CLS 和填充值不参与平均与梯度。以中心化后的 K、V 计算平方误差及一次梯度步：

`G = Kcᵀ(Kc W0 − Vc) / N`

`Wfast = W0 − [eta / (1 + trace(KcᵀKc/N))] G`

沿用 eta = 0.5 sigmoid(rate)。不增加幅度放大或新阈值。主干原始状态、query、风险头不去均值；因此这里只移除辅助目标中的均值驱动力，不保证最终风险对所有水平变化不敏感。反转有效 Vc 的时间位置作为对应关系对照。

Transformer 第一层在整个已到达窗口内编码，不能把其中较早 token 的表示称为当时已经封存的未来预测。这里是对当前过去窗口的内部关系拟合，而非严格的下一时刻预测。每个端点从 W0 开始，不积累跨窗口或跨炮临时状态；本轮不测试炮间经验。

## 固定训练与比较

- 完全复用已核对的 20 炮准备集、原来的 10 炮阈值校准和 360 炮顺序；这些是已参与开发的历史划分。
- 不修改源模型、已准备的静态 parent、输入映射、阈值或报警器。
- 与前轮相同初始化、512 步准备、种子131、样本、优化器、损失和 batch32 推理。
- 比较 parent、同参数额外静态容量、适应模型关闭、适应模型开启、适应模型反转目标五臂。
- 额外静态容量臂必须逐步训练日志、最终参数和完整风险曲线精确复现上一轮，parent 曲线也必须精确复现。
- 主要比较同一适应模型开启与关闭，另外必须超过 parent 才能称为对已有迁移方案的实际增益；跨实验重训前后分数差不能当炮内收益。
- 360 炮结局只在全部预测封存后用于评价。源模型标签不变，EAST 及时报警严格 lead >30 ms，FPR 上限0.20。

## 晋级标准

首先确认有实际内部参数变化与风险变化；要求同模型开关的及时检出减误报净改善，并满足 FPR 限制。不达标则保存阴性结果，不把训练误差下降或事件分类成绩写成在线成功。本轮无需先添加事件损失；事件信息先用于决定研究方向，避免混合改动。
