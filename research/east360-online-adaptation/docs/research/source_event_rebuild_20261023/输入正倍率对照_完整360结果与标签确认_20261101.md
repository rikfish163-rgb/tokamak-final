# 输入正倍率对照：完整360炮结果与标签口径确认

日期：2026-11-01。研究对象为独立重构分支，不是旧V3C。固定已经保留的J-TEXT源模型，只研究EAST侧；所有数据均已参与开发。

## 1. 本次结论

**四个新候选均未达到要求，不替换现有基线。** 只调整输入倍率，虽然可以改变检出和误报的取舍，但本轮没有找到在误报上限内提高及时检出的方案。此实验没有炮内更新，也没有后340炮的炮间更新，不能算作炮内自适应收益。

用户已经明确确认“HDF5数据准确”。正式结局采用HDF5的`IsDisrupt`，破裂时刻采用`DownTime`。此前18炮的名单差异不再是结局权威待裁定问题；69854继续按HDF5破裂炮处理。当前运行本来就采用该口径，因此没有重标、删炮或改分数。shot list仍提供划分身份和J-TEXT的AdvancedTime。详情见[确认记录](HDF5标签权威确认_20261101.md)。

本轮复核通过表示记录、计算与抽查重放一致，不表示方法有效，也不表示已取得独立未来验证。

## 2. 同一完整在线流，究竟比较什么

使用`stratified_cold20_context360_v1`的同一360炮身份和顺序，按HDF5为180破裂、180安全。前20炮为8破裂、12安全，全部先用源模型预测并封存；20炮结束并揭示结局后才拟合映射，第21炮起启用。前20炮的7次及时检出、6次误报计入所有方法的总成绩，不能从分母中移除。

该顺序是利用已有记录的初始电流代理构造的离线投运模拟，不是自然历史炮序，也不是经认证的破裂危害排序。所有比较共用该顺序；不利用后340炮标签训练或挑选本轮检查点。

固定项为：源网络、源归一化缓冲区、风险头、概率门槛`0.7258946895599365`及首次越阈值报警规则。及时检出要求EAST提前量严格大于30ms；超过3000ms的报警按现行合同计入及时检出，同时单独列出数量。J-TEXT仍用`max(25ms, AdvancedTime)`训练正窗口，本轮没有重新训练或评价J-TEXT。

两个参照是“源模型直接预测”和“只用前20炮统计得到的密度倍率”。四个候选构成2×2对照：

- 参数范围：仅密度1个参数，或9个参数作用于10列。
- 训练目标：对候选时间点求平均损失，或对每炮最高风险时间点求损失。

9参数方案涉及密度、CIII、Mir_VV、Mir_avg_amp、n=1幅值、水平位移、垂直位移、SXR响应和XUV响应。SXR均值乘以倍率、方差乘以其平方；XUV仅缩放方差。全部倍率为正，没有通道混合、加性平移或最终风险附加分数。其余13列保持原输入处理。共同响应倍率是声明的建模假设，**不等于恢复了传感器的真实单位或标定关系**。

四臂共用256对预先生成的破裂／安全炮训练配对，种子2131，Adam学习率0.03，梯度范数上限1，对数倍率平方和正则系数0.01。固定取第256步，不根据后续表现选轮次。模型原权重逐位未变，梯度仅更新输入倍率。不同损失的计算量不同，不声称算力完全匹配。

## 4. 为什么损失下降不等于预警改善

破裂炮的训练候选是破裂前30–125ms内、满足原正标签的点；安全炮使用全部有效保存时间点，包含不足128点的前缀。没有合格候选就报错，不静默删炮。

设当前风险分数为z，固定报警门槛换算到同一分数空间后为b。安全点的损失为`softplus(z−b)`，破裂正点为`softplus(b−z)`。平均版本要求整段候选都向标签方向靠近；峰值版本只通过当前最高风险点反向传播。它们都是近似训练目标，均不与最终离散炮级成绩完全等价。

一个真实例子来自第0步的破裂炮71304：其95个候选点中，最高分3.3986已经超过门槛；该炮平均损失仍为2.4301，而峰值损失只有0.0848。平均版本因此仍强烈推动其他正窗口升高。若这种调整也推高其他安全轨迹，就可能增加误报。**例子说明两种目标施加的训练压力不同，不证明这就是全部误报的唯一原因。** 同步配对的安全炮63097有3498个候选，平均损失0.0292、峰值损失0.0613。

最终单密度平均方案把倍率由0.0002405推到约0.0009707；峰值方案降到约0.0001880。9倍率平均方案的垂直位移倍率约4.48，峰值方案约0.37。这些相反变化说明监督目标会影响经验映射，不能把拟合倍率解释成“发现了正确物理单位”。

## 5. 与基础数据审查合在一起看

现有证据支持以下区分：

1. **没有查到的简单错误：** 当前23列错位、电流重复乘1000、当前360炮秒／毫秒混用、按时间点而不是按炮计算FPR。检查正常不代表上游传感器和特征提取已经独立认证。
2. **仍存在的输入差异：** 多个幅值、位移、辐射和代理量的分布不同；部分特征缺失方式不同；源与目标记录长度不同。只缩放密度不能宣布已完成跨装置对齐，也不能将所有分布差异一律认定为单位错误。
3. **已经排除的一条乐观推断：** 给前20炮标签后，仅拟合正倍率并改为炮级峰值损失，并没有在本流上自动解决检出与误报的矛盾。
4. **标签不再悬而未决：** 正式结果继续以HDF5为准，不再以shot list差异解释训练失败或选择更好看的标签。

上一轮正常参考均值／协方差映射也未通过：其直接坐标实现完成360炮后FPR仍为0.43–0.50，且协方差混合可产生不满足原始方差非负约束的隐含输入。本轮正倍率避免了这类映射结构问题，但性能仍未改善。两轮共同说明，不能把所有失败都归结为“缺一层标准化”。不同映射的失败也不能证明所有成熟对齐方法都无效。

下一步回到核心问题：在固定可复查输入合同下，当前炮已经到达的信号，能否指导内部时序表示朝有利于风险判别的方向更新。应先区分误报发生在可用反馈之前还是之后，再检查真实时间顺序的反馈是否优于不更新、反序或仅保持最近状态等对照。已有相同对照不重复包装成新实验；没有炮级改善时，不以辅助预测损失下降或报警参数变化代替炮内收益。
