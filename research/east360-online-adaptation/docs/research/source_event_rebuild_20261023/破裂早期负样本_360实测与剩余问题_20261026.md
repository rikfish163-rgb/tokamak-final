# 破裂早期负监督：完整360炮实测

## 结论先说清楚

改变目标侧标签使用策略后，炮间模型TPR从0.5000恢复到0.7000，FPR从0.0667升到0.1667。
在新策略内部，炮内＋炮间比冷启动后冻结多1个及时检出、少3个误报；但炮内单独没有新增正确炮。
因此：**监督策略冲突得到实验支持；独立炮内增益仍未证明，总目标未达到。**

本轮是单种子开发诊断，不是独立测试确认，也不是旧V3C复现。
360炮均曾参与方法开发；所有数值包括前20炮冷启动，180破裂、180安全。
固定阈值0.7258946895599365，EAST及时预警严格lead>30ms，未调报警参数。

## 1. 为什么做这个对照

原完整360的事后核查发现：冷启动固定模型检出的120个破裂炮里，79炮首次报警早于125ms。
评价把它们计为及时检出，但时间点标签在125ms之前为0。若把这类时刻用于负监督，会推动分数下降。
其中31炮的“提前超过30ms区间内最高分点”标签为0。旧炮间模型丢失30个及时检出，其中17炮旧首次报警早于125ms。

这是评价和时间点监督可能冲突的证据，不证明所有早报警都具有真实先兆意义，也不证明它解释全部失败。
447个被选中的高分负标签点来自33个冷启动后破裂炮；这是候选训练点计数，不是447次已接受更新。

来源：[旧完整曲线诊断](../../../experiments/risk_aligned_online/runs/lifecycle_stream360_v3_20261026/loss_semantics_audit.json)。
运行前约定：[单因素实验协议](破裂早期负样本_完整360单因素约定_20261026.md)。

## 2. 实际改了什么

没有把早期片段改成破裂标签，也没有改变125ms定义。

- EAST安全炮：所选有效窗口仍为负监督。
- EAST破裂炮：所选窗口中只让已有正标签的窗口承担监督损失；更早的零标签窗口不参与。
- 端点采样器本来就排除破裂前不足或等于30ms的点，因此实际正监督端点位于提前量(30,125]ms。
- 同一掩码用于目标侧历史保护损失；J-TEXT源回放仍使用原标签。
- 相同架构、源检查点、顺序、首20炮、输入映射、种子、回放规则与学习率。

训练和保护同时采用这一策略，因此不能从本实验独立分离两者贡献。
各臂仍按自身已封存预测采高分端点；预测变化会使端点集合变化，这是固定策略的下游结果。

对一个已揭示的EAST破裂炮，原策略分别求正窗口和负窗口BCE的均值，再两组等权；
新策略只求正窗口均值。安全炮仍求负窗口均值。随后在炮与类别层面均衡聚合。
炮后总目标仍为0.5倍当前炮、0.25倍近期回放、0.25倍源回放；没有额外叠加风险修正头。

文献依据与适用边界见[跨团队核查](跨团队文献扩展_数据对齐事件标签与炮内适应_20261026.md)。
这一实验仅借鉴负样本处理思想，没有照搬其他论文的窗口长度或宣称完整复现。

### 与同次冷启动模型配对

- inter救回73405、74970，丢失93995；减少85599、93306的误报，无新增误报。
- both救回和丢失的破裂炮与inter相同；减少73790、87689、85599、93306四个误报，但新增70043误报。
- intra与cold没有任何炮级正确/错误翻转；倒序对照同样没有。
- both相对其同状态影子预测，只减少73790一个误报。这是条件于已学习炮间状态的局部现象，
  不能代替“先独立证明炮内收益”，也未证明时间顺序的必要性。

### 不回避仍不理想的部分

1. 新旧inter比较多36个TP，同时多18个FP；不能只报TPR恢复。
2. 相对裸源模型，both仍少19个及时检出，只是误报明显减少；绝非所有指标全面改善。
3. 固定阈值改善不代表整个ROC更好。事后FPR≤0.20扫描中，旧inter最佳TPR为0.7722，
   新inter为0.7167。这些扫描使用开发标签，不是部署成绩，且不能取代固定阈值的主对照。
4. >3000ms报警仍有18个，必须继续检查是否是持续偏高分数，而不能全部解释为更早发现危险。

## 4. 全流与后期不能混报

首20炮按先验运行参数代理排序，自然形成17破裂、3安全；所有方法均先用裸源预测，只有6TP、1FP。
本轮不靠事后换顺序隐藏这部分错误。

both在后340炮为120/163及时检出、28/177安全误报，即TPR0.7362、FPR0.1582；
最后90炮为31/38、5/52，即0.8158、0.0962。
后期分段可以描述表现，但样本组成不同，不能把后期0.8158写成完整360炮TPR，也不能仅由分段上升断言学习因果。
最后90炮中cold为31/38、7/52，配对收益主要为少2个误报。

## 6. 下一步判断

保留该完整实验作为标签使用策略的对照，不把它升级成已完成的炮内方法。
下一项关键问题仍是：**已到达诊断数据怎样改变内部表示，且这些改变能让同一炮的后续预警更准？**
源事件信息尚未真正作为识别任务训练，临时记忆也未被证明具有足够的风险辨别能力。
新架构须明确相对已有事件配对、更新方向学习的差别，并保留无更新、倒序和恒定反馈对照。

此外，当前经验映射只修正ne_nG一个通道；这不等于23维物理语义已经完全对齐。
参数代理排序也不等于真实损坏成本。需要继续核对可用数据、文献假设与实现边界，不能由单轮恢复声称问题全解决。
