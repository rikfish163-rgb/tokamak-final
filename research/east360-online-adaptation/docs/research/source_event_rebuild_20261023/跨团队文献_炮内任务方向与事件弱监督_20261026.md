# 不只参考Ai：将文献落实为可检验的炮内学习任务

## Material Passport

- 状态：文献与本地实现核对；方案部分为研究假设。
- 核查日期：2026-10-26。
- 文献证据：[逐篇读取范围与限制](literature_claim_manifest_direction_20261026.md)。
- 本轮实验：对已完成360炮实验作事后更新方向诊断，不新增或替换在线成绩。

## 1. 对项目最重要的三点

**第一，信号拟合变好不等于预警变好。** TTT++讨论了这类失败，并强调辅助任务与主任务的联系。这里应检查“用真实到达信号更新后，及时预警所需的风险方向是否改善”，不能把重建损失下降直接叫作炮内收益。[官方论文](https://papers.neurips.cc/paper_files/paper/2021/file/b618c3210e934362ac261db280128c22-Paper.pdf)

**第二，先兆识别与结局判断是两件事。** Montes等的工作提供少量标注扩展事件库的参考；这并不意味着事件一出现就会破裂。我们的J-TEXT补充标记应先用于学习局部活动，再检验这些活动怎样持续、恢复或组合，不能直接变成EAST真实破裂原因。[MIT论文记录](https://dspace.mit.edu/entities/publication/e800cf5e-03cf-4caf-a394-af232f5bce5b)

**第三，事件链这一想法本身不能声称首创。** Shen团队最新会议摘要已提出炮级弱监督、逐步寻找更早前兆、聚类及事件转移。我们可能的差异应落在：只读取当前前缀、到达信号驱动临时参数、炮后标签改善后续更新，并独立证明炮内收益。该差异目前仍是待检验目标，不是已确立创新。[IAEA会议摘要](https://conferences.iaea.org/event/454/contributions/43124/)

## 2. 当前代码距目标还有什么距离

- 已有内部适配：快状态的读出进入两个Transformer块之间，不是在最终风险分数后另加保护头。
- 快状态拟合四个时距的23维变化；分段真值到达即写入，每炮重置。
- J-TEXT的A–F标记目前只用于源域回放抽样。`lifecycle_stream_20261025/learning.py::source_replay`没有训练A–F分类器，也没有训练事件转移模型。
- 已尝试只在源域训练更新规则，但两轮教学的验证损失没有证明优于固定规则；不能把“存在非零梯度”当作已学到有效适应方法。
- 前20炮的Ip/Bt排序是运行参数代理，不是实测损伤。实际标签构成17破裂、3安全，提示低代理值也不能叫“安全炮”。这不自动证明排序无效，但需要单列覆盖范围问题。

## 3. 本轮先查更新方向，不增加模型分支

固定原源模型、cold模型、炮序、输入映射和门槛，对后340炮执行相同端点规则：

1. 破裂炮选提前量大于30ms的最高静态风险点，安全炮选全炮最高点；另报末125ms内的破裂候选点。
2. 重现原风险曲线，再比较最后一次信号驱动写入前后变化。
3. 同时报信号拟合误差和风险损失；寻找“前者改善、后者恶化”的冲突。
4. 逐一移除诊断变量对应的四时距读出，检查哪些内部信息推高或压低风险。

这种检查借鉴了Bonalumi等将敏感性与遮挡联合使用的思路，但本项目删除的是内部预测读出，不是原始物理量，不能借此认定密度或辐射是破裂原因。[期刊原文](https://www.frontiersin.org/journals/physics/articles/10.3389/fphy.2024.1359656/full)

真实结局只在事后解释时使用。以上分析不能直接当作可上线的“知道什么时候改对了”策略。

## 4. 下一候选必须满足的设计条件

以下是本项目提出的实验方案，不是文献已经保证有效的方法：

**保留基模，重新设计临时更新的学习目标。** 用J-TEXT训练炮及其已标记活动区间教学；未标记区间保持未知，不补造正常标签。学习目标应奖励“已到达信号带来的更新改善后续及时风险判断”，并显式统计原本正确判断被破坏的情况。

**区分拟合工况和吞掉危险征兆。** 模型要能描述当炮背景、变化方向与持续程度。单纯让所有变化都更容易重建，可能将真正异常也适应成常态。应比较仅预测信号、带活动监督、活动标签打乱三个版本；只有真实活动监督在后续预警上更有益，才能支撑事件信息有用。

**源域训练与EAST部署使用同一反馈时点。** 当前源域记忆规则按完整四步到达训练、EAST按分段到达部署，属于显式的训练/部署不一致。下一次教学必须匹配，不能同时改输入对齐、报警器和更新规则后将增益全部归给炮内。

**先独立炮内，再炮间组合。** 每个候选仍需完整360、包含冷启动20、同一父模型/阈值/顺序，报告cold、intra、inter、both。模型根据前炮结局学习；当前炮结局不能反向改写当前成绩。

## 5. 什么不能说

没有通读100篇、没有证明新物理规律、没有证明所有异常都是破裂前兆，也没有完成独立未来验证。
保留失败结果，是为了排除不成立的更新目标，而不是把失败重新命名为系统成功。
