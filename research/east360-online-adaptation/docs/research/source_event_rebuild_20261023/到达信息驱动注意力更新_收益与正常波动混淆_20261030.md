# 到达信息驱动注意力更新：危险阶段改善，但正常波动也被推高风险

日期：2026-10-30。材料状态：**ANALYZED / 开发诊断**。本轮真实GPU实验完成，未通过进入更大实验的方向筛选；不是新的360炮TPR/FPR，也不是独立验证。

## 1. 结论先说清楚

保持已达标的J-TEXT基模和现有冷启动父模型不变，仅利用新到达的25个时间点，确实可以产生使后续危险窗口判断改善的注意力参数更新。本轮17个破裂炮中，15炮的及时危险阶段平均交叉熵下降。

但同一个更新也使全部3个安全炮、全部17个破裂炮的早期正常阶段损失上升。因此，**这个固定规格仍失败，不能宣称炮内预警增益，更不能把15炮损失下降写成救回15炮**。本轮没有运行完整360炮，也没有调整报警阈值。

进一步分解发现：在安全炮上，约99%的正向反馈来自25点内的波动幅度。当前参照是“信号完全不变”，而正常工况也存在波动。结果支持下一步重点研究“当前工况下正常变化应有多大”，不支持继续直接放大更新力度。

## 3. 新信号如何成为训练反馈

### 3.1 先描述新到达的变化

每个可用通道的25点变化，以归一化后的当前观测为参照，取四个数：平均变化、末点减首点、去均值均方根、末点变化。23通道共92维；通道需要25点完整有效。MNM缺失、离散模数排除和其余缺测规则沿用原合同。

这些是对信号的统计描述，不是新增的物理测量，也不等于已识别破裂机制。

### 3.2 将新信号与旧前缀分开

训练折内拟合两个逻辑回归：第一个看64维前缀表示和23维可用性；第二个再看92维到达信息。两者使用相同炮/阶段均衡权重、固定0.1的L2正则。归一化仅从训练折计算，不扫描参数。

设前缀为h，到达信息为d，两个辅助模型的分数为b0、b1。直接取b1(h,d)−b0(h)，可能混入重新拟合旧前缀的影响。因此预先指定的主要反馈是：

\[
e=b_1(h,d)-b_1(h,0).
\]

这里的0表示“新观测相对当前点完全不变”，不是缺测；两次计算使用相同通道可用性。该差只保留到达量的贡献，但**零变化未必代表真实正常运行**，这正是本轮发现的限制。

完整差、零变化差、倒序信号、错位训练标签和零反馈也一并运行，不能只挑主要实验臂展示。

### 3.3 真正改变的是网络，不是直接替换最终分数

前缀风险分数z先封存。25点到达后，计算伪目标r=σ(z+e)，仅用于形成梯度反馈：

\[
\Delta\theta=-0.05\,[\sigma(z)-r]\,
\frac{\nabla_{\theta}z}{\|\nabla_{\theta}z\|}.
\]

θ只代表临时Q/K参数。随后第26—50点的风险由改变后的原网络重新计算；r不是对外输出。零梯度或无有效通道明确不更新。这个固定步幅是与上一轮共用的诊断约定，不是调出的最优策略。

本次主要反馈是线性统计量的加权和，尚不具备复杂的工况条件化能力。两个辅助分类器也没有证明满足条件概率校准，不能将e称为可靠的贝叶斯证据或物理风险增量。分类器分数与似然比之间需要额外条件；本文方法论依据只支持这种区分，不证明本项目有效。[Cranmer等，§2.1—2.3](https://arxiv.org/html/1506.02169v2)。

## 4. 全部预定对照的真实神经更新结果

下表为“更新后−更新前”的交叉熵变化，**负值较好**。括号为该组损失下降的炮数。危险阶段要求破裂前125ms内，且未来评价点的提前量严格大于30ms。

| 反馈方式 | 安全炮，3炮 | 及时危险阶段，17炮 | 破裂炮早期正常阶段，17炮 |
|---|---:|---:|---:|
| 真实到达信息，主要实验臂 | +0.011153（0/3） | −0.053997（15/17） | +0.006273（0/17） |
| 完整双模型差，包含前缀重拟合 | −0.004670（2/3） | −0.018418（10/17） | −0.002673（13/17） |
| 仅前缀重拟合，实际变化置零 | −0.013093（3/3） | +0.023293（0/17） | −0.008711（16/17） |
| 25点倒序 | +0.010952（0/3） | −0.020439（15/17） | +0.006195（0/17） |
| 炮内阶段标签错位后拟合 | −0.005477（3/3） | +0.024080（0/17） | −0.004373（16/17） |
| 零反馈 | 0 | 0 | 0 |

各非零臂均完成2707个独立片段的真实Q/K更新；零反馈严格0更新。单次GPU运行约32.56秒，不代表单炮实时延迟或工业在线耗时。

更严格的交集口径还要求：前缀本身已进入125ms窗口，且25点到达时仍有大于30ms提前量。真实臂变化为−0.059433，15/17炮改善；安全和早期正常阶段的问题没有因此消失。

**如何解读完整双模型差的正向结果？** 它在三个分组的平均值均改善，是值得保留的诊断线索，但安全炮仍有1/3变差。不能事后把它换成预先指定的主要方法，也不能据此证明新到达信息有独立净收益。单独的前缀重拟合反而伤害危险阶段，说明“全是旧分数重拟合的作用”同样不准确；下一轮需要拆清正常变化参照与旧风险校准的作用。

## 5. 失败原因已经缩小到具体统计项

对真实反馈e按四个统计项精确分解，先对每炮对应的未来评价点加权，再对炮平均。数值是**辅助反馈分数的贡献**，不是最终网络风险改变量：

| 统计项 | 安全炮 | 及时危险阶段 | 早期正常阶段 |
|---|---:|---:|---:|
| 平均变化 | +0.003691 | +0.189123 | +0.004339 |
| 末点减首点 | −0.000772 | +0.306178 | +0.010770 |
| 去均值均方根，即波动幅度 | +0.690472 | +0.930695 | +0.575824 |
| 末点变化 | +0.001668 | +0.285687 | +0.015933 |
| 合计 | +0.695059 | +1.711682 | +0.606867 |

安全炮的波动项占正向总分约99%；早期正常阶段也主要由它贡献。按炮平均后，安全组约95.6%的相应反馈为正。**这不是正常工况没有信息，而是“有波动”被大量转换成了“应该提高风险”。**

危险阶段确有更强的变化信息，真实顺序的效果也好于倒序；但不能由此推导某个通道导致破裂。上述是模型内的描述性分解，不是物理干预或因果识别。

下一项应检验的假设是：利用此前可见前缀预测正常变化范围，将新到达信号与该工况下预期的变化比较，而不是只与完全不变比较。该新参照本轮**尚未实现或验证**；也不能先删除波动项，再宣称风险问题已经解决。

1. 相关性不等于因果：通道贡献不作为破裂原因。

3. 时间点不作为独立样本：先炮内平均，再跨炮统计。
4. 不使用总体平均掩盖类别损害：安全、危险、早期正常分开。
5. 没有显著性检验，不宣称统计显著；3安全炮尤其不足。
6. 没有把辅助探针损失下降等同于最终预警收益。
7. 不将新生效的Q/K参数解释为已学到新物理规律。
