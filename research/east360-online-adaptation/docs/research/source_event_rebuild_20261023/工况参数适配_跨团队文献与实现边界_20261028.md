# 不止Ai：从工况适应文献确定下一步检验什么

## 结论

当前最需要解决的不是再增加一种报警修正，而是：**已到达的信号能否帮助模型辨认本炮工况，同时保留危险演化信息。**
本轮新增CoDA、NCF、LEADS、TTT理论及JET状态监测五篇方法阅读；具体版本、读取范围和限制已先登记在
[证据表](literature_claim_manifest_privileged_20261026.md)。并非通读100篇，也不把同一论文多个版本重复计数。

## 2. 本项目已知问题，而不是文献替我们下的结论

五组完整360对照已经结束，见[实测复核](事件与参照梯度_五组完整360复核_20261028.md)。

- 真实事件辅助训练没有优于无事件和打乱事件对照；目前不能宣称eventlabel已经带来炮内收益。
- 最好的本轮炮内读数是130个及时命中、35个安全炮误报；冷启动对照为125/32。
  净改善仅2炮，时距扰乱对照也为130/35，时序收益的归因不足。
- [参数阶段拆分](风险上移来源_只读阶段拆分_20261028.md)显示：在相同EAST输入映射下，
  源教学阶段的适应模块已普遍提高风险，冷启动进一步放大这一倾向。
  这不能解释成“模型识别到所有炮都更加危险”，也没有证明某一项损失是唯一原因。

因此，不继续把信号误差下降、更新次数多或事件分类变好当作主目标达成。

## 3. 下一候选：少量工况参数驱动的内部适应（待实现）

这是一项受上述文献启发的工程假设，不是NCF/CoDA完整复现，也不预先声称新颖性或有效性。

数据流拟保持：

```
当前及过去的23维观测
  → 冻结的J-TEXT基础表示
  → 由少量本炮工况参数调节的内部时序层
  → 原风险头与固定报警规则
          ↑
过去一次性预测的未来诊断窗口 → 真值实际到达 → 更新本炮工况参数
```

主要差异是减少炮内自由度，让它拟合“当前环境下怎样演化”，而不是给每个风险输出单独找修正量。
第一版只尝试一个预先固定的小维数，不扫描大量维数挑EAST成绩。
J-TEXT源分类器不改写；源TRAIN1353训练适配接口，VAL160用于设计检查，TEST220不训练此接口。

具体约束：

1. **更新对象**：小维工况向量及其受限内部作用，不更新最终风险头，不新增输出分数补丁。
2. **反馈信号**：一次预测多个后续诊断窗口；只有实际到达的观测才能计算该部分误差。
   不用模型自己生成的后续值当真值，也不用当前炮最终结局构造炮内目标。
3. **源域教学**：模拟“前缀适应、后缀预测”，检查适应后的破裂判断是否改善。
   事件标签只帮助源域覆盖不同状态区间；无标注区间不能自动当正常，A–F也不直接命名真实机制。
4. **物理检查**：保留绝对量和变化信息，核对单位及缺失掩码；分别检查安全工况变化、持续异常、恢复过程。
   与电流、磁场、密度代理的关联可报告，但不把工况向量直接解释为可测物理参数。
5. **状态寿命**：本炮临时向量炮末丢弃；炮后真实结局用于持久模型与回放，影响后续炮。
6. **启动与比较**：前20炮仍在总分中；其Ip/Bt顺序只是离线运行参数代理，不称真实危害排序。
   所有实验臂共用炮序、基础模型、标签合同、数据对齐和报警器。

## 4. 什么结果才算支持这个方向

第一层必须是完整流的cold、intra、inter、both，而不是局部窗口上的重建误差。
主标准继续为EAST提前量严格大于30ms、炮级FPR不超过0.20，并另报秒级过早报警。

第二层检查贡献来源：无更新、真实到达反馈、时距扰乱反馈三者比较；逐炮列出救回、伤害和新增误报。
如果真实反馈与扰乱反馈同样好，就不能认定学到了有用的演化关系。
如果both差于intra或inter，必须解释冲突，不用组合平均掩盖。

第三层才是稳健性：多个源训练随机种子、冷启动构成变化和后续独立流。
现有数据都参与过开发，当前结果只能用于开发诊断。

## 5. 先完成正在运行的单因素检查

现有“可学习初始记忆”和“固定零初始记忆”配对实验保持原协议运行；它检查普遍风险上移是否与初始记忆有关，
不是这里的新工况向量方案。源端两轮教学及源数据审计已完成；EAST完整配对尚在运行时不报告部分成绩。
先看这项检验能否解释偏差，再决定新接口是否值得进入完整流，避免同时改多个环节后无法归因。
