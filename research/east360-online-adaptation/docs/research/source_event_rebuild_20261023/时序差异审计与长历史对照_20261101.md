# 时序差异审计与长历史对照（2026-11-01）

## 结论

时序结构和数值对比度的源—目标差异具有明显通道异质性，不能根据标签窗口的 25 ms 与 125 ms 推断 EAST 各通道统一慢 5 倍。固定模型的长历史对照中，d2 比 d1 少 4 个 TP、少 4 个 FP，完整 360 炮的 J 均为 0.5；这不是炮内神经更新收益的证据。

这里的25 ms只是J-TEXT正样本窗口的下限，实际逐炮使用`max(25 ms, AdvancedTime)`；EAST训练正样本窗口固定125 ms。两者都是监督标签的时间范围，不是经过测量的装置统一时间常数。

## 时序差异审计：TRAIN1353 与已结束 EAST20

结局和 DownTime 以 HDF5 为准。源 J-TEXT 仅用 TRAIN 1,353 炮，其中安全 1,165、破裂 188；目标仅用已结束的前 20 炮，其中安全 12、破裂 8。两域类别比例不同，以下合并组只作描述；安全组和破裂组应分别查看。目标输入映射也由这 20 炮估计，不能把本比较当作未来留出流的结果。

以 `record_windows` 为例，每炮在有效记录内取至多 16 个 128 点窗口，先在炮内对窗口取均值，再对炮等权取中位数及 q10/q90。下表是中位数；该视图有窗口的源炮为 1,317，目标炮为 20。q10/q90 是炮间分位数，不是置信区间；各窗口和视图可以重叠。

| 通道 | D1：J-TEXT → EAST | 源坐标 asinh 标准差：J-TEXT → EAST |
| --- | ---: | ---: |
| `sxr_mean` | 0.0230 → 0.5569 | 0.0452 → 0.0102 |
| `sxr_var` | 0.1052 → 0.4900 | 0.0484 → 0.00125 |

`sxr_mean`、`sxr_var` 的目标 D1 较高而对比度较低；`Mir_VV`、`v_loop` 的目标 D1 较低。不能把前一模式泛化到全部 SXR 特征：合并组的 `sxr_kurt`、`sxr_skew` 方向相反。

原始 D(lag) 是同窗差分平方均值除以两倍可用值方差。在观测掩码不变、方差非零时，它对非零整体缩放和常数偏移不变，因此不能把 D 差异仅解释为量纲缩放；缺测不足和常量情况记为未定义。`asinh_std` 则使用固定源 center/scale，目标先应用既有输入映射，反映该工程坐标下的对比度，不是神经网络逐点激活。两种描述都不认证物理时间尺度。

时序核验的数值结果为 **PASS**：21 项检查通过，覆盖全部汇总字段，并抽查 8 炮的 40 个实际窗口；容差为 float64 `rtol=1e-10`、`atol=0`、`equal_nan`，计数、索引和哈希精确。完整状态为 **PASS_WITH_SCOPE_INCIDENT**：核验准备时的诊断命令意外显示了目标后缀的聚合性能／结局计数，越过原定的后缀结局访问边界；未打开后缀单炮 HDF5 信号或结局，也未因此新增样本选择或改变预设判据。

预先审查没有发现所审代码中的致命因果错误，但有三点解释限制：第一，前缀截断／未来扰动检查与同代码重放是不同证据，后者本身不能证明没有未来访问；第二，索引160开始可能受影响的是当前状态视图，长历史参数首次有有效信息的更新要到索引287、最早影响288；第三，固定视图对照不是同容量的32参数固定模型，即使实测超过这些对照，也只能支持相对于这些对照的反馈贡献，不能直接声称学习了物理时间尺度。接受更新仅意味着当前已到达数据上的含正则目标下降，不保证未来预测或报警改善。
