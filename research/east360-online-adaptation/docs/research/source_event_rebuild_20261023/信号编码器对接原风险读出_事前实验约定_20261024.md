## 这次改变什么

保留达标源模型的第二个 Transformer 块、归一化、已学得 fast_origin 和风险头。
复用已有 masked_state NONE / REAL 的信号编码器（输入投影、位置/CLS、第一个时序块），
用一个 64→64 线性映射对接原读出。映射作用在时序 token 上，不叠加最终风险分数。
原源模型归档不覆盖；这属于源域离线准备，不是 J-TEXT 在线学习。

依据 CTA 的“自监督编码器对齐冻结监督模型”思想，但不是其原样复现：
本实验采用掩蔽通道重建和 token/分数蒸馏，而非视觉 SimCLR。
来源：https://arxiv.org/html/2507.05221v1 （已读方法3.1—3.5）。
该论文不能证明本候选对 EAST 有效，更不能支持新物理规律主张。

- 源模型报警阈值固定，不在 TEST 重选；两候选同预算、同训练样本 RNG。

## 固定训练预算与目标

先只拟合线性接口256步；然后编码器+接口6轮×256步，batch64。
AdamW：接口1e-3，编码器1e-5，weight_decay=0，梯度范数裁剪1。
源域对齐损失 = 原读出分数的 SmoothL1 + 0.25×有效token均方差 + 0.20×信号重建损失。
分数及 token 参照只来自冻结源模型，且仅用于源域离线训练。
重建使用每batch前16个窗口的4种整通道遮蔽；每个有效连续通道恰被遮蔽一次。
这些系数是本轮固定工程设定，不是假装来自物理定律或已证明最优。
选择优先满足VAL FPR<0.15，再按及时TPR、FPR、对齐误差选轮次，不读TEST选轮。

## 不可绕过的资格与后续边界

新组合网络必须先达到 J-TEXT TEST220 TPR≥0.90、FPR<0.20（严格lead>10ms）。
不合格不进入新的360炮宣传或替换原模型。达标不等于在线有效。
炮内更新只复制信号编码器，用已经到达的信号重建误差更新；接口和读出冻结。
快参数同炮可累积、下一炮必须重置；不能把当前未知结局用于炮内目标。
后续 EAST 应比较同父网络的 off/on/恒定输入/倒序输入，再比较炮间及直接迁移。
EAST准备预算、阈值、窗口和完整评分协议须在启动该阶段前单列锁定。
所有集合已有开发暴露；没有独立确认或收益保证。
