# 不止Ai：这次扩展阅读具体改变了什么

本页补充前几轮文献核查，而非把同一论文反复计数。读取范围见
[逐项登记](literature_claim_manifest_feedback_20261026.md)。下面明确区分论文结果、代码事实与待检验推论。

## 1. “20炮能迁移”不能脱离其余训练数据

Zhu、Rea等跨装置HDL研究的高性能配置使用20炮EAST破裂数据，同时使用5995炮EAST非破裂数据；这不是总预算20炮。该文也有10D+10S的小样本配置，二者不能混淆。报告的是AUC，且使用50 ms评价要求，不能当作我们的TPR。[作者稿§5，Table 3/4](https://arxiv.org/pdf/2007.01401)

**本地事实：**当前360炮前20炮只有17D、3S；此前完整运行显示裸源145TP/94FP，对齐后119TP/26FP。它说明当前映射降低误报的同时丢失了及时检出，不能只报FPR改善。

**工程推论：**下一项冷启动研究应同时记录正常工况覆盖和样本数。不能先看未来结局、挑20个安全炮放前面，再假称在线选择；也不能用所有360炮估计归一化统计。本轮反馈实验保持既定冷启动不变，避免混入这个因素。

## 2. 有MHD活动，不等于应当报警

DECAF用状态与演化的组合判断事件链。其案例中，早期出现旋转MHD活动并不立即达到危险警告；后续幅值、频率、转动等条件共同改变，才形成不同的危险过程。该文也强调前兆起点可能与最终破裂时的参数位置很不同，应分析完整运行时段。[Sabbagh等，2023，§III B、IV](https://scientific-publications.ukaea.uk/wp-content/uploads/032506_1_ONLINE.PDF)

**对当前23维的限制：**我们有部分磁扰动、辐射统计、位置和密度比例信息，却没有该文完整的转动剖面、平衡与稳定性计算。不能把一个诊断幅值阈值称为已复现DECAF，也不能把低Ip/Bt排序称为实测低损伤。当前代码实际排序为`(初始电流/100000)^1.2×初始|Bt|`，只是离线投运代理。

**可检验的方向：**需要区分相似初始异常之后的恢复、持续和扩大。若以后设计事件相关的炮内目标，应先验证它能否区分这些轨迹，再检查及时报警；不因增加“物理”命名而直接宣称学到机制。

## 3. eventlabel的使用还远没有达到“机制教学”

Jia等EAST会议报告以专家标注的ELM、MARFE和H–L回跳支撑多任务学习；这为联合事件与风险目标提供相关依据，但并非本项目自动A–F类别的验证。[IAEA2024官方摘要](https://conferences.iaea.org/event/377/contributions/31666/contribution.pdf)

**代码事实：**`lifecycle_stream_20261025/learning.py::source_replay`按A–F每类选8个J-TEXT训练区间，48个中32个有可用及时窗口；损失仍是原破裂窗口分类，A–F仅用于覆盖抽样。它没有学习六类事件输出，也没有学习事件转移，因此不能写成“充分利用eventlabel识别破裂机制”。未标注区间仍为未知。

**后续边界：**若增加事件教学，至少需要同预算无事件与置乱事件对照，并按炮分离训练/检查；EAST在线只能读取当前已到达信号，J-TEXT完整炮离线标签不得变成EAST的在线输入。保留达标基模，不能把整个源模型重新训练造成的差异混作炮内收益。

## 4. 已到达的真值，应在能使用时使用

TAFAS区分完整未来窗与部分已到达真值，并指出等待整个窗口会造成更新延迟；它同时承认更短片段可能缺乏足够信息。[Kim等，AAAI2025，Challenges/O2及PAAS](https://arxiv.org/html/2501.04970v1)

**本轮已经实施的检验：**一次预测4个诊断片段，每段8个采样点；每段真实值到达后仅更新相应预测步，仍不递归使用预测值作为目标。其他训练、阈值和流顺序保持，完整360炮计分。详见[事前约定](分段到达反馈_完整360单因素约定_20261026.md)。这不是TAFAS原模型的复现，也不是已有破裂预测收益的声明。

## 5. 阅读后的优先级

1. 完成本轮完整360反馈时点消融，报告实际救回和改坏哪些炮。
2. 如果独立炮内仍无收益，不能再把“诊断拟合更快”当作“危险识别更准”；应检查外层教学是否真的奖励适应收益、以及事件轨迹是否提供风险可辨识信息。
3. 冷启动正常工况覆盖是另一条有文献依据的假设，单独实验；先解决数据覆盖证据，不靠提前读取未来安全标签制造优势。
4. 全部结果仍是开发诊断，不能写作独立确认、工业安全保证或发现新物理规律。

目前没有通读100篇的证据，不作这一声明。完整已读方法、局部方法、官方摘要和访问失败均分开登记。
