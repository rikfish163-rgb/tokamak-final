# 原生接口的EAST炮内对照

2026-11-04。状态：本轮开发试验完成，四组候选均未达标；不作为新的完整流成绩。

## 1. 这次改变和没有改变的内容

保留合格J-TEXT静态模型，把临时更新放回模型原本预留的128维token增益／偏置接口，而不是上一轮新增的第一FFN4×64状态。源模型、两种诊断头、真实掩码、scaler、风险阈值和HDF5结局均不改动。

在同一批已结束EAST20、同样100个时间坐标上，比较原生／源域外部诊断头与绝对／去时间均值损失的四种组合。每种组合均有静态、真实反馈、倒序、保持反馈，共1600条预测。四份静态记录来自同一个父模型，不是四个独立基线。

原生更新使用既有代码的0.05归一化参数步和半径1。它与前一轮FFN的0.05隐表示步长并不等价，不能把两轮数值差异全部归因于更新位置。

## 3. 新定位出的时间覆盖问题

归档中，此前源域辅助训练的512个破裂正例采样，435次来自10–30ms，只有77次来自30–125ms。完整源域TRAIN池的378个30–125ms破裂窗口中，350个原点标签是0；VAL的155个对应窗口中，125个原点标签是0。这是`max(25ms, AdvancedTime)`与未来125ms事件目标的区别，**不是HDF5结局错了，也不表示要把原J-TEXT分类标签改成125ms**。

诊断头forecast_only没有外层风险损失，前述采样只影响它见到的例子；使用原标签监督风险方向的是先前的meta对照头。不能混为一谈，也不能把归档辅助训练的日程当作全部源基模训练的追溯证明。

因此下一步准备一个明确分离的辅助目标：保留原点标签，另外记录“当前起125ms内是否破裂”，检验能否教出更适合EAST提前预警的无标签更新方向。它只用于离线辅助老师，不修改合格基模或原分类标签。此前更早窗口未进入辅助训练的采样因素也需保持匹配，不能把增加数据和改变目标混成一个增益。

这是待验证假设，不是已确认的唯一失败原因。相关数据构造工作已限定在J-TEXT TRAIN／VAL的HDF5元数据与时钟，不读取TEST或EAST原始数据；不存在新增J-TEXT在线分支。

## 4. 因果边界、核对和后续

模型在q−26点的前缀上发出25点诊断预测，用已到达的q−25至q−1真实诊断更新临时状态，只评价q的新风险。全部神经预测封存后才读取HDF5结局评分。该开发脚本会先加载整炮数组再截前缀，数值映射也用过同一已结束20炮，不能当作真实流式I/O或独立未来验证。

本轮原生接口与评分合并CPU测试35项通过（2.50s），相关代码Ruff E9/F通过；CUDA运行10.85s完成1600条记录。源与诊断头状态未变，未读取后340炮，未读取旧cold状态。测试通过证明计算实现可核对，不代表方法有效。
