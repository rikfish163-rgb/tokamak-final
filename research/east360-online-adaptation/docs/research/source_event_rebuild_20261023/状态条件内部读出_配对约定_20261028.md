# 状态条件内部读出：源域配对实验

本轮是新假设的机制筛查，不晋升未通过预测准入的v3，不更改其已封存门槛或结果。v3的反馈发生器暂时固定，仅用来隔离“同样的反馈如何作用于当前时序表示”。不声称其信号预测已经合格；不产生EAST成绩。

## 假设

上一轮160炮只读消融：输出权重第一方向占94.84%，实际内部变化合并能量占99.90%；只保留该方向基本复现风险影响。低秩本身并非错误，但配合安全炮退化和扰乱反馈更优，值得检验固定加性读出是否缺少对当前状态的区分。

设h为第一Transformer块的末端token（64维），d为已到达反馈驱动的四时距诊断预测（92维），W为64×92无偏置矩阵。

```
u = 0.1 tanh(W d)
additive:          h_new = h + u
state_conditioned:h_new = h + u * h / sqrt(mean(h²) + 1e-8)
```

两臂均只作用于同一末端有效token；之后使用相同第二Transformer块和原风险头。两臂的改变量L2上界均为0.1√64=0.8，但实际范数不保证相等，不能把差异全部归因于方向。

采用按特征调制的已有基本思想，不声称FiLM是本项目创新。[Perez等AAAI2018 §2.1](https://cdn.aaai.org/ojs/11671/11671-13-15199-1-2-20201228.pdf)；本项目与图像任务、完整仿射FiLM及其训练协议不同。这里只检验诊断反馈和当前时序特征相乘是否有作用。

## 固定训练合同

- 基础分类器、风险头、原输入尺度和阈值冻结；仅TRAIN1353训练W，VAL160描述性筛查。TEST220与EAST均不读。
- 两臂都从W=0开始，均5888个训练参数；相同v3反馈发生器，八维临时状态逐炮清零；发生器及尺度不更新。
- 两轮、seed131、Adam0.001、每8炮累积、梯度范数上限1；同炮序、同采样端点、同类别权重。
- 沿用现有bag+0.5local+0.5direction目标，参照分支停止梯度。不加预测损失，因为本实验不训练发生器。
- 保留当前标签定义。源域教学不是新增J-TEXT在线实验。

## 固定报告与筛查

固定epoch2，不选择最好epoch。报告两臂每类的off/真实反馈/匹配状态范数的时距扰乱反馈损失，以及全部训练炮覆盖和梯度。hold控制若零方向不能匹配，明确记录，不据其推断有效适应。

候选必须：真实反馈的bag、local总体均比off低至少1e-6，破裂和安全两类分别不恶化超过1e-6；真实反馈总体bag、local均优于时距扰乱至少1e-6；并优于同预算additive臂总体bag、local。只要有一项失败，就不能据此启动该候选的EAST性能试验。

这是开发筛查而非显著性检验；不能证明物理机制。若通过，也仍需先运行完整在线流（含冷启动）独立证明炮内收益，再测炮间及组合；报警阈值不变。失败则保留证据，不叠加输出修正或补扫阈值。
