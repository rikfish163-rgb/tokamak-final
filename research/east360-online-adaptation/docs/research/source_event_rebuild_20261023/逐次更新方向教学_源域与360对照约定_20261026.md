# 逐次更新方向教学：源域与完整360对照

## Material Passport

- 日期：2026-10-26；状态：运行前固定方案，效果未验证。
- 起点：340炮诊断中，信号拟合改善常伴随预警损失增加。
- 目标：使真实到达信号触发的内部更新对预警有益，不增加最终分数修正或报警调参。

## 固定条件

保留合格J-TEXT源检查点及其阈值。源训练TRAIN1353、描述性验证VAL160，TEST220及EAST不进入源域教学。
J-TEXT标签保持max(25ms,AdvancedTime)，及时条件严格>10ms。
两个训练臂均使用同一初始化、样本缓存、炮序、两轮训练、Adam0.001、每8炮累积及梯度范数上限1。
所有记忆参数key/prior/rate/output可训练，基础网络、风险头、slow参数冻结。
训练与EAST部署均使用progressive反馈；四步直接预测，真值分段到达写对应列，每炮重置。

## 两个训练臂

**bag对照**：沿用原炮级及时候选最大风险损失，只修正训练/部署反馈不一致。

**direction候选**：在同一炮级损失上增加局部已知标签损失和单次写入方向损失。
破裂炮仅对既定正标签窗口且lead>10ms的端点提供局部正监督；不把更早未知阶段一律改为安全。
安全炮有效端点提供负监督。方向损失只用于至少已有两完整patch、能够发生写入的端点。

对同一历史输入端点，z_after使用全部已到达信号写入，z_before仅撤销最近一次写入，其余历史状态相同。
定义门槛中心化的二分类损失B(z,y)=BCEWithLogits(z-logit(threshold),y)。

```
L_bag = B(max(z_after), shot_outcome)
L_local = mean(B(z_after, point_label))      # 只在上述有效局部标签上
L_direction = 0.02 * mean(softplus((B(z_after,y)-B(z_before,y))/0.02))
L_candidate = L_bag + 0.5 L_local + 0.5 L_direction
```

方向项对before和after均求导，而非把before设为固定teacher；它惩罚一次真实写入令风险损失升高。
0.02为损失差的平滑尺度，0.5为预先固定的实验权重，不声称为物理常数或文献推荐参数。
候选同时改变局部监督和方向项，首轮只能检验组合教学目标；如有收益，再分拆两项消融。
A–F事件标签本轮仍只维持原回放作用，不宣称本轮已训练事件分类或发现物理机制。

## 验证与选择

固定使用epoch2，不按EAST成绩挑epoch。VAL报告相同的炮级采样损失、局部损失和方向冲突数，不能充当全炮测试TPR。
两个检查点分别运行相同完整EAST360：冷启动20炮计入总成绩，20后继续炮间学习。
每次均有source/aligned/cold/intra/inter/both/both_shadow/intra_reverse；固定阈值及原报警器。
重点在各自运行内比较intra与cold。不同教学规则可能改变cold拟合，跨运行不能假装cold参数完全相同。

验收：intra相对cold的J严格提高且FPR≤0.20；再检查both是否优于intra。
单seed及既有开发流不证明稳健性，不满足则不晋升。源模型校验不变、信号访问因果、所有360炮结局在封存后揭示。
