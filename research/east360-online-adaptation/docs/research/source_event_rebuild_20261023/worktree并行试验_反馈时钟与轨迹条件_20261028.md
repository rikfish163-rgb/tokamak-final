# Worktree配对试验：反馈时点、变化方向与更新强度

## 结论先行

本轮完成两个隔离工作树的实际工作：完整EAST360的只读反馈时钟核查，以及两臂源域接口教学、验证和后续求解器诊断。**没有新EAST在线增益，候选没有替换主线。** 原J-TEXT分类基模、风险头、阈值和主分支保持不变。

证据支持三个有限结论：

1. 既有完整流中，冷启动后未及时检出的44炮，在30 ms截止前都有已到达信号可用于更新，也都已产生预测变化。问题不是完全没有更新机会。
2. 显式加入此前的变化方向，没有改善本次固定预算下的风险结果；不能据此说原模型缺少变化方向就是唯一根因。
3. 对已到达信号求更充分的拟合，会扩大临时状态，但同时损害安全炮和后续诊断预测。继续增大学习率、更新次数，缺乏这轮证据支持。

以上不是对所有轨迹模型的否定。源试验只有一个种子、固定两轮；其结果是源VAL抽样端点损失，**不是新的TPR/FPR，也不是EAST测试成绩**。

软链接只是共享路径，**不是操作系统强制只读**；本轮程序只读这些输入，新输出限定在各工作树`probe_outputs`。没有提交、推送、删除历史结果，也没有把这些开发分支接入部署加载器。当前代理接口不能选择项目要求的命名角色，因此没有启用继承默认角色；实际并行的是CPU时钟核查和本机CUDA配对实验。

## 2. 时钟核查：不是“信号还没来，模型就已经来不及改”

使用已经完成的`lifecycle_context8360_service_20261028`，不重算或改写当时的预测。360炮全部180破裂、180安全，前20炮属于冷启动。主成绩一直包含这20炮；下面单列44炮只用于失败原因诊断，不能替代全流成绩。

本次360炮真实采样率全部为1000 Hz。每8个采样点形成一个片段；四个直接预测时距为8、16、24、32 ms。

- 第一段数据位于索引0—7；下一段到索引15时完整到达。
- 当前索引映射`ends//8-1`保守地从索引16开始使用这次反馈，比完整片段到达多等1个采样点。
- 这是**数据到达的逻辑时钟**，不是实测端到端计算耗时；实时推理开销仍需另测。

| 冷启动后未及时检出的破裂炮 | 核查结果 |
|---|---:|
| 数量 | 44 |
| 截止前有可用反馈更新 | 44/44 |
| 截止前已出现炮内／静态预测差异 | 44/44 |
| 截止前可用反馈次数：最少／中位／最多 | 42 / 348 / 3023 |
| 最早可用更新到截止点的间隔：最少／中位 | 329 / 2782.5 ms |

时钟按HDF5真实时间复算，与360份封存曲线逐点相同；44份失败炮预测的SHA与原封存凭据一致。严格排除提前量恰好等于30 ms的端点。

这里证明的是“有观察和改动机会”，**不证明截止前已存在可识别前兆，更不证明这些炮一定可救回**。1 ms的边界保守性不是这44炮完全没有更新的解释；本轮没有为争取分数而更改它。

## 3. 配对试验：同样数值、不同变化方向，是否需要不同映射

### 输入和更新位置

原Context8的诊断映射根据当前23维数值及23维可用性生成。新增方案再提供最近两个已完成片段的23维变化量及23维共同可用性，缺失时变化量置0并显式标记。

这些变化量是在既有归一化、asinh变换后的差值，**不是已校准的物理时间导数**，也没有重新启用17＋8分组。两组均用92→8的输入投影：对照的新增46列恒为0，候选使用实际过去变化；新列初始权重均为0。两组初始张量与预测一致，名义参数均13257个，但有效输入信息量不同，不能声称有效容量完全相等。

仍由已到达的四时距诊断误差更新8维临时状态；状态每炮重置，作用于Transformer两层之间的末端token，不向最终风险分数另加修正项。

### 固定条件

- TRAIN1353仅用于教学这个适应接口；VAL160用于机制筛选；不读取TEST220或EAST信号。
- 不是新增J-TEXT在线主线，也没有重新训练J-TEXT分类基模。
- 沿用既有TRAIN估计的通道／时距尺度；报警阈值0.7258946895599365不变。
- 相同种子131、相同炮序，两组各两轮，Adam学习率0.001，8炮累积、梯度裁剪1。
- 固定epoch2，不根据VAL结果加轮数或选epoch；目标沿用既有风险方向项与诊断预测项。
- 本轮未使用J-TEXT阶段标签。阶段标签没有被误当作EAST标签或模型实时输入。

### 实测结果

训练及评估共305.98秒。两组各340次优化步都有非零梯度；候选新增变化量投影列340步均有非零梯度，对照相应列全为0，说明对照开关确实生效。

下表均为源VAL160抽样端点的平均损失，越小越好，不是准确率：

| 方法 | 炮级风险损失 | 时间点风险损失 | 安全炮风险损失 |
|---|---:|---:|---:|
| 关闭炮内反馈，冻结基模 | 0.302920 | 0.457361 | 0.239258 |
| 当前数值，对照 | 0.290172 | 0.446642 | 0.241187 |
| 当前数值＋过去变化，候选 | 0.290918 | 0.447977 | 0.240986 |
| 候选：扰乱已到达时距反馈 | 0.290800 | 0.448161 | 0.241646 |

“扰乱”指重排已到达的时距目标、保持对应状态范数，不是整炮时间反转。候选时间点损失优于扰乱，但炮级损失不优于扰乱；不能只选择其中一项宣称学会了演化。

| 四时距诊断预测 | 对照 | 候选 |
|---|---:|---:|
| 加权误差 | 0.02529009 | 0.02528838 |
| 相对保持当前值的平均改善 | 0.0600% | 0.0668% |
| 优于保持当前值的炮 | 79/160 | 78/160 |
| 安全炮中改善的炮 | 30/80 | 30/80 |

保持当前值的误差为0.02530528。虽然平均预测误差略降，候选没有超过对照的风险结果，安全炮风险损失仍升高，也未达到事前多数炮预测改善条件。因此按事前计划不进入EAST。

这些筛选量用于节省开发成本，不等于用户最终验收标准；不能据源损失退化直接断言EAST完整流必然失败。正式验收仍须完整流的严格TPR30、FPR上限和炮内独立贡献，当前没有这种新证据。

## 4. 为什么不直接把更新加大

配对结束后增加**事后诊断**，固定全部神经参数，不再训练：

1. 原更新：当前归一化梯度步。
2. 到达目标精确拟合：只用此刻已到达的1—4时距目标，在相同单位球约束内求最小二乘临时状态。它不用未来，但只保留这批局部约束，未使用此前更长历史。
3. 同范数对照：沿上述解的方向更新，但范数缩放到原更新的范数。零方向单独记录，不伪造方向。
4. 未来信息拟合：为了检验固定诊断映射的表达空间，使用每个起点的真实未来诊断求最佳状态。**它只计算诊断误差下界，绝不接入风险预测，不是可部署方法或成绩。**

候选结果如下：

| 临时状态求法 | 后续诊断误差 | 破裂炮风险损失 | 安全炮风险损失 |
|---|---:|---:|---:|
| 原更新 | 0.025288 | 0.340849 | 0.240986 |
| 已到达目标精确拟合 | 0.027457 | 0.283332 | 0.288660 |
| 精确拟合方向、匹配原范数 | 0.025253 | 0.356342 | 0.240731 |

精确拟合的平均状态范数由0.02870增至0.17453，约6.08倍；破裂炮损失下降，但安全炮损失比原更新升高约19.8%，后续诊断误差升高约8.58%。范数匹配后，不能保留破裂炮的改善。**不能把更强更新的总体损失下降当成正确的适应方向。**

使用不可部署的未来诊断拟合时，误差能降到0.022837，比保持当前值低约9.75%。这只表明固定8维映射存在一定拟合余地；并不说明这些状态能从过去可靠识别，更不证明相应风险更准。未来拟合从未进入风险函数。

这次诊断没有训练新的神经参数，也没有获得新的EAST结果。12个真实最小二乘系统用独立SciPy约束优化复核，最大目标差约9.93×10⁻¹⁴；原生产预测在诊断中逐炮复现。

## 5. 下一项应检验的结构区别

当前Context8把未来变化直接表示为“状态相关映射×临时状态”，临时状态从0开始；它需要同时承担原本可预测的演化和本炮的偏差。现有结果提示应该分开检验这两者，而不是继续放大学习率。

候选假设：先用源数据学习**预期演化**，再用已到达的实际变化与预期之间的差异更新临时状态。预期演化包括源域已见过的安全与危险轨迹，不能把它笼统称为“正常背景”，也不能把所有预测偏差叫作破裂前兆。

这一结构尚未实现，尚无效果证据。下一试验应保持8维临时状态、同一基模和风险头，明确区别于此前已试过的高维可学习prior；比较有／无单独训练的预期预测器，禁止把先验自己漂移当作反馈收益。之后再考虑J-TEXT事件标签作为源域辅助监督，前向输入仍只能来自可见信号。

J-TEXT事件类别A—F不是单调风险等级，也不是EAST阶段真值；无标注区间不能当正常或恢复。不能依靠增加未经验证的损失项，把上述困难隐藏在更复杂的结构里。
