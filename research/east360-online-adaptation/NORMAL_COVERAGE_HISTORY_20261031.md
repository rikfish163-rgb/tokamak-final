## Bottom line

1. The **unchanged fixed order** does gain distinct safe shots as the prefix grows: 3, 4, 7, 17, and 28 safe shots at prefixes 20, 30, 40, 60, and 80. These are retrospective labels, not an outcome-based re-ranking and not a real-world prevalence estimate; distinct shots are not necessarily statistically independent.

Worst-group teaching has also been tried at the same Q/K update site, but for a **forecast head**, not this context target. Merely adding shot-balanced draws or a worst-group slogan is not a new experiment.
3. Within the searched representation-step call sites and nearest historical implementations, I found **no completed exact** bias-free, feedback-only `v = V U (feedback − fit_mean)` rank-4/8 CLS target trained through the real representation-loss inner step. This is a bounded negative search, not proof of absence in every archive or of benefit.
4. The ready current-parent representation cache is for cold20 only. Beyond 20, the first 80 raw files exist by path and there are saved sealed prediction curves, but I did not find a verified, ready-to-use prefix30/40/60/80 observation/teacher cache for this parent.

## Exact feedback-only low-rank target: deduplication

The proposed target has feedback dimension 230 (five blocks of 23 means and 23 availability fractions), `U ∈ R^(r×230)`, `V ∈ R^(64×r)`, `r=4 or 8`, no biases, and `v=VU(f−f̄_fit)`. It would have 1,176 or 2,352 trainable factor entries, respectively. With the existing detached reference and [actual representation loss](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/context_vector_20261030/learning.py:72), the unclipped step is `η J_originᵀv` (or the corresponding maturity Jacobian if that clock is chosen); the action is then radius-clipped.

- The completed [AnchoredTarget](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/anchored_feedback_20261030/learning.py:21) instead subtracts two outputs of the same `LayerNorm(358) → Linear(358,32) → SiLU → Linear(32,64) → tanh` network. It has 14,316 parameters, includes 128 origin features and can use them to modulate its feedback response. The maturity run imports this same target and fit function, changing the Jacobian clock. The 32-unit hidden layer is not the proposed bias-free linear rank-4/8 feedback map.
- The [conditional direct generator](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/conditional_weights_20261030/learning.py:12) directly emits low-rank Q/K matrices; the [attention-basis method](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/attention_basis_20261029/learning.py:29) projects a forecast gradient in Q/K parameter space. Neither is a low-rank CLS target passed through this representation-loss gradient. The [source feedback-only logistic probe](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/context_vector_20261030/source_diagnose.py:130) was a classifier/information diagnostic, not an online representation target.
- Search evidence: all WT `representation_step(...)` call sites and the nearby explicit representation-loss implementations were inspected, along with the relevant target/low-rank history notes. No completed exact candidate was found in this bounded search. This does not exclude an old differently named implementation outside that scope.
- A paired rank test on the **existing cold20 cache** is an unrun idea, not evidence of efficacy. Use identical fixed parent, fold IDs, teaching draws, controller budget, causal clock, feedback controls, and radius as the anchored comparator; report action norms and functional effects. Both factor matrices initialized to zero would give zero factor gradients, so initialization must be declared and tested. A comparison against the nonlinear anchored network changes origin dependence and nonlinearity as well as rank; a feedback-only unrestricted linear reference would help isolate rank. Origin still affects the signal-change anchor and masks as well as the Q/K Jacobian, even though the target network receives no explicit origin representation.

## Causality, labels, and a nonduplicate coverage test

Current fixed-clock records use `o=127+25k`, maturity `m=o+25`, and query `q=o+50`; the arrived observations stop at `m`, and an update can affect predictions only **after** maturity. EAST safe is a nondisruptive ended shot; timely danger is `30 < lead_ms ≤ 125`; early disruptive points (`lead >125`) and late points are not relabeled as safe for this teaching. [Classification](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/relational_attention_20261030/run.py:29), [pool construction](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/conditional_weights_20261030/run.py:31). By contrast, the source experiment uses the original source positive horizon `max(25 ms, AdvancedTime)` with missing values falling back to 25 ms, and requires lead strictly greater than 10 ms; do not silently substitute the EAST 125/30 rule. [Source selection](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/context_vector_20261030/source_episodes.py:95), [horizon](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/io23.py:166).

**Unrun, bounded nonduplicate comparison:** retain the same qualified source, cold20 mapping, `slow` parent and threshold; at a declared later boundary, compare (A) a teacher using only ended cold20 shots with (B) the same teacher and same 256-step/class→shot→window budget augmented with all eligible safe shots that have already ended in that fixed prefix. Use the same 17 disruptive cold shots in both; do not change or re-rank the order. Fit scaling/mean only from each arm's permitted fitting shots, and use paired random streams plus no-update, reverse, and fit-shot donor controls. This tests **additional normal support for the auxiliary teacher with a frozen cold20 parent**, not a new cold-parent fit or a pure separation of shot count from diversity. The necessary post-20 observation cache has not been established here.

Both arms must preserve all predictions already sealed before the boundary, and their first valid causal comparison is on later shots; include startup cost and report per-shot safe/danger outcomes, first-alarm rescues/harms, and very early alarms. Historical 70404 cannot be retrospectively "rescued" by a teacher using shots that ended after it; a separate held-70404 component check would remain parent-contaminated unless the entire parent and mapping were rebuilt without it. The existing 360 roster and suffix have prior development exposure, so even a favorable exploratory result is not independent confirmation. Selecting 40/60/80 after seeing this table is post hoc; a genuinely prospective follow-up needs an independently fixed boundary and an untouched stream.
