# 追求连续越线没有扩展可救炮范围

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run, with independent whole-shot recount and raw CUDA witness
- Origin Date: 2026-11-06
- Verification Status: verified for this TRAIN feasibility diagnostic; no online policy validated
- Version Label: patch_sustained_margin_v1

**决定：不把连续两帧目标推进到 EAST。** 在同一写入位置、时钟、
实际保护与状态上限下，连续目标确实比单帧目标少触发潜在误报，
但没有独有的持续救回。更积极的单帧目标也只在旧动作库之外多救回
一个物理炮，而且只在屏蔽诊断的视图上、只越线一帧。

## 方法与对照

按[冻结方案](PATCH_SUSTAINED_MARGIN_PROTOCOL_20261106.md)，用三个已封存
的 J-TEXT TRAIN1353 视图，覆盖全部静态迟报／漏报的破裂炮，另在每
视图选 48 个最接近报警线的无警安全炮、24 个有警安全炮和 24 个
及时破裂炮。共 313 炮–视图、207 个原炮。分层只使用原始 HDF5 真值
和已封存的静态曲线；此集合故意偏向难例，不估计总体 FPR。

对每个已有释放点 `m`，保留前八个观测值，只有 `m+9…m+32` 的真实
采样点可改。两个目标在相同的可写时间和及时范围内，分别最大化
一个采样点的局部余量，或相邻两个采样点中较小的余量。以冻结
网络在零状态的梯度作局部优化，使用同一个输入 patch 的 8×8 临时
状态。过去四个锚点的风险梯度共同投影掉，两方向及其负号共用同一
尺度，实际历史偏移限制为 `0.10−0.00002` logit，状态范数上限为
`0.35`。随后以真实网络重算整个可写后缀，保留原首越线报警器和
原阈值；两帧仅用于生成方向和衡量持续性。源域及时仍为提前严格
`>10 ms`，不是把训练正窗或 EAST 的 `>30 ms` 用作这里的判据。

候选生成可用未来诊断和破裂时刻，是**事后能力诊断**；不是从已达
前缀学成的更新策略。两个新目标各一条正向动作；旧库在相同释放
支持上允许全部 12 个原方向及符号，不做搜索预算等价的声称。

## 整炮判定

| 视图（迟报／漏报破裂炮） | 旧库：可救／两帧／可新增误报 | 单帧：同三项 | 连续两帧：同三项 |
| --- | ---: | ---: | ---: |
| 原生（6） | 2 / 0 / 12 | 2 / 1 / 32 | 1 / 1 / 26 |
| 缺 MNM（10） | 1 / 0 / 18 | 3 / 0 / 28 | 1 / 0 / 23 |
| 缺 MNM、CIII（9） | 2 / 0 / 22 | 4 / 2 / 38 | 3 / 2 / 31 |
| 三视图按原炮去重 | **5 / 0 / 48** | **6 / 2 / 85** | **4 / 2 / 71** |

每个数字表示存在至少一次单写入产生该翻转，不是把所有候选一起
运行的成绩。各视图误报列的分母为 48 个近阈值、静态无警的安全炮；
不同视图可以包含同一炮。旧库全时钟和匹配时钟的这些计数相同。
两种新目标在正向都没有丢掉原本及时的炮，也没有去掉已有误报；
允许负向后，单帧／连续分别可消除 25／26 个原误报，同时各有 2 个
原及时炮可能被改坏。不能事后为每炮挑有利符号来报在线增益。

两个新目标真正出现连续及时越线的是**同样的两个物理炮**
（1052388、1055239）。它们也是旧库已可单帧救回的炮。唯一扩大
单帧救回范围的 1056381，原生视图已经提前 106.46 ms；两个屏蔽视图
的冻结首报均只有 8.46 ms。新单帧动作在二者都提早到 26.46 ms，
但下一帧未继续及时越线；连续目标仅在双屏蔽视图用单帧勉强越线，
余量约 `+0.009`。持续目标新增两帧及时原炮为 **0**，未达到事前的
两个病例门槛。

## 为什么继续追更高分不够

2,094 个成对块都能满足共同保护，1,972 块（94.2%）使用满尺度，
所以多数情况下并不是缩步拒掉了候选。在有合法写入时刻的 23 个
迟报炮–视图中，18 个的最佳静态及时点仍比阈值低至少约 0.5 logit；
而允许看未来的单帧生成器也仍有 7 个差超过 0.5。另一方面，允许
其在安全难例中寻找最大上推方向，会暴露更多可误报病例。这里
区分了**及时前风险余量不足**和**能上推但不具危险选择性**，不能
靠统一放大步长同时修好。

[Sun 等的 Test-Time Training](https://proceedings.mlr.press/v119/sun20b.html)
在凸模型的特定条件下把主任务和自监督梯度的方向关系与适配效果
联系起来；这里的整炮首报结果进一步提示，单有同向梯度还不能保证
及时且低误报。这是本实验的推断，不是该论文对托卡马克的验证。
[Shen 等的跨托卡马克工作](https://arxiv.org/abs/2309.05361)支持将物理特征
和跨装置对齐分开考察，不为这次屏蔽视图提供 EAST 在线验证。

下一步不再加大风险上推或继续扫连续点数。把此前 [EAST 首层适配](LAYER0_PHASE_AND_TRANSFER_RESULT_20261106.md)
已经暴露的取舍当作验收对象：内部更新需在同一风险余量、放电阶段
和可用诊断下区分危险演化与安全瞬态。应把匹配安全响应约束放到
**方向的训练**里，而不是在最终风险上再加一道门；训练只用授权的
源训练和已结束准备炮，留炮对照固定阈值和等幅的假反馈。只有证明
新方向的选择性，才值得完整回放 EAST 的炮内、炮间及联合。
