## 2. 真正更新什么

输入仍是原23维及可用性；8个未来采样点同时预测21个连续诊断的增量，目标只排除不可用MNM及离散mode_number_n，风险输入不删除它们的槽位或重建17+8分组。目标保留通道身份，但在源模型asinh坐标中计算，不是统一物理单位、守恒方程或已识别的破裂机制。

快速线性网络W有168×70=11,760个权重。键是末点值、两段8点均值之差、16点可用比例及常数；W0用已结束20炮的9,036组真实直接预测配对作岭回归拟合。每炮从W0重置，每32点用刚到达的完整8点真实目标作归一化LMS更新，偏离W0的范数上限2。

无偏置168→128连接共21,504参数，只在20炮结束后按其HDF标签训练512步；它把 `(W−W0)k` 放进原模型的token gain/bias接口。这个接口位于Transformer之前，最终风险头不训练，也不叠加新的风险分数。**变化的是系统内的快速动力学权重和条件化时序表示，不是原Transformer权重被在线反向传播。** W=W0或连接为0时，风险逐点等于parent。

这是“20炮监督学习连接＋其后每炮无结局标签的快速更新”，不是整个系统无监督、不是零EAST标签启动，也不是已经实现炮间持续监督学习。当前没有后340标签训练。

## 3. 对物理解释最重要的反证

前20拟合上，直接预测MSE为.0382135，保持末值为.0409268；只是训练集拟合。后340按照每炮先平均其有支持的更新坐标、再对炮等权，结果如下：

|---|---:|
| 真实炮内网络，更新之前的后续目标误差 | .0322233 |
| 固定W0预测 | .0286393 |
| 保持末值 | .0294162 |
| 真实更新之后，对刚训练目标的误差 | .0138446 |

仅81/340炮的真实后续预测优于固定W0，11/340优于保持值；破裂炮分别27/172、10/172，安全炮54/168、1/168。**更新后误差下降主要是对刚见目标的拟合，不是后续动力学预测改善。** 因而当前报警收益可以支持“真实反馈包含有用信息”，不能支持“快速模型更准确地学到了物理演化”。

`pre_update_mse`是到达时重建的辅助预测：8点前后没有另一场权重更新，数学上与当时可计算的预测相同，但当时没有独立发布或封存该诊断预测。它不等于原Transformer forecast head的误差。若要验证实际部署，仍需真正的逐点I/O、预测队列及延迟测量。

## 4. 阈值、对照和时间边界

在保存曲线上，用后340结局事后选阈值、首20成绩固定，仅为诊断且**不可部署**：全流FP≤36时最大TP，native为122TP36FP，真实反馈为125TP35FP。这个固定曲线容量对比说明真实结果不完全等同于简单降低原模型的全局阈值，但提升仅3炮，不能把事后阈值当新的在线成绩。

事后阈值搜索必须与正式评分一致，先把提前量统一到小数点后9位毫秒，再严格比较>30。直接比较浮点减法会把 `30.00000000000025ms` 当作大于30：实际native71013、真实63656恰处这个边界。正式结果将二者按30ms处理，不算及时；未为提高成绩改旧评分器。其余结果与原规则一致。

通道错位控制同时旋转目标及mask，可能改变每个通道的支持，不能单靠它证明模型识别了物理对应。常量控制也不是幅度匹配的安慰剂；仍需更严格支持和幅度匹配的假反馈。当前不同训练损失／容量的旧cold20静态迁移不能冒充完全匹配的同预算架构对照。
