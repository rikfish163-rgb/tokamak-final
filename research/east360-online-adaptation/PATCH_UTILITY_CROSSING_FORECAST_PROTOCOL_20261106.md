# 固定阈值的成对首越线预测：效应识别，不是报警策略

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run, frozen before main-label inspection and fits
- Origin Date: 2026-11-06
- Verification Status: protocol; no crossing model output
- Version Label: patch_utility_crossing_forecast_v1

继承同一源模型、三封存 TRAIN1353 视图、正负成对动作、限幅、阈值、
五折和写入时钟。在 m+8 已观察八帧静态与候选影子响应；只对
此时尚未静态报警且至少有一个受保护非零候选的块作比较。
后续 k=1..24 指 m+9..m+32 的实际记录；不增加单次写入作用范围。
目标是**冻结模型分数的首次越线**，不是物理破裂风险或炮间收益。

1. **绝对首次越线**。每个候选及不写入的路径从 t 之后开始计；
   大于等于原阈值算越线，之前影子越线不算真正报警。
   把未来分成 3 个八帧区间；每区间拟合一个条件于尚未越线的
   每帧概率 h_j。已观察 n 个风险帧、其中 e=1 则已首越，
   用二项形式 `-e log h_j - (n-e) log(1-h_j)`，在
   首越或记录终止后停止累计。尾部部分记录仍能贡献其真实
   已观察帧，不把缺失填充当成从未越线；运行时不提供末端长度。
   逐帧概率质量用 `P(F=k)=h_j * product_{u<k}(1-h(u))`。
   拟合前按原炮、视图、块、动作均分基础权重，各区间按
   总在险帧质量归一，标准化与截距用训练折，L2 固定 .03。
2. **成对首次越线差**。对于后 8／16／24 帧都实际存在的对应
   时限，目标是动作首越指示减同块静态首越指示，取 −1、0、+1。
   直接拟合三个类，按类、原炮、视图、块、非零动作等权、
   L2 .03；使用 `p(+1)-p(-1)` 的排序分数（重加权，非自然概率）。
   这个对照检测“先分别预测后相减”是否把小而关键的效应淹没。
   若预定训练折缺任何类，完整记录无支持，不以另一折代替。
3. **信息消融**。每类拟合分别用不看八帧影子、幅度、真实相对
   时序、倒序四臂；均有相同风险时钟、原保护和原动作身份。
   另作保持最后已到达 logit 的确定性对照。三折拟合、同一个
   预留折不使用、最后一折检验，原炮的缺失视图从不跨折。
4. **评价**。比较绝对发生率 Brier/平衡 AP；主要机制比较
   非零候选的相对越线：每个有对照的同块，评估提前/增加
   （或推迟/消除）候选对其他候选的成对排序准确率，先平均
   同块对，再等权同炮内块、视图和独立原炮。等分算半分。
   同时报两种真翻转方向的原炮数和严格符号正确率（零不计对）。
5. **有利窗口的归因上限诊断**。单独给绝对模型正确的离线
   “越线在此帧对整炮是否有益”的 payoff，取预测首越质量
   与静态首越质量之差的逐帧加权和，验证是否选得到真实有益
   动作；也以真实曲线和同锚恒定偏移给诊断参照。此步骤
   明确使用真结局和未来静态轨迹，不能运行在线、不报 TPR/FPR、
   不作为 policy gate 替代物。真序至少须在两个方向的三时限
   平均同块排序不输对照且有独有的迟报首选，才值得进一步
   拼接不依赖真结局的状态证据；本轮不写入任何评估炮。

HDF5 只用于既有 seal 和评分真值核对；前两个拟合的目标仅来自
封存的风险曲线和实际记录时钟，不以炮结局筛样本。不改变 J-TEXT
原训练正窗、EAST 固定 125ms、及时门限、阈值、分集、冷启动或
查询预算。不访问新 VAL／TEST／EAST，无真实在线回放。
