# EAST 当前主实验图

## 图的结论

固定 EAST360 历史回放中，完整方法及时检出 146/180（81.11%），误报 34/180（18.89%）；第 5 步相对前四步增加 2 炮及时检出，误报名单不变。相同主阈值用于另外 2,593 炮历史扩展时，误报为 434/1,575（27.56%），超过 20% 上限。

## 四个面板

- **a：逐步贡献。** 静态及依次增加第 1–5 步的及时、误报炮数；两类各 180 炮，准备段 20 炮计入评分。第 4 行已经含炮内处理。
- **b：历史扩展。** 静态、前四步和完整方法在 2,593 炮中的误报率；阈值沿用主档，没有针对扩展样本重校。完整方法及时检出 706/1,018（69.35%）。
- **c：70320。** 同一报警线下，首报提前量从 12 ms 增至 225 ms。淡橙区域是破裂前最后 30 ms，落在该区的首报不算及时。保留原始采样点和单点尖峰，不平滑。
- **d：67900。** 未破裂炮在记录开始后 176 ms 误报，第 5 步首次实际修正要到 287 ms，晚 111 ms。

## 数据与评价口径

数据来自已同步研究分支的封存计分、双炮曲线及历史扩展结果。`source_metrics.csv` 保留计数、分母、比例及所属报告章节；`source_curves.csv` 保留逐采样点分数；`source_metadata.json` 保留报警线、案例时刻和配对核对信息。

每炮按首报计分，破裂前提前量严格 **>30 ms** 才算及时。原始 HDF5 的 `meta/IsDisrupt` 与破裂炮的 `meta/DownTime` 为既有回放的结局依据。图中呈现一次固定历史回放的精确计数，不把采样点当作独立重复，不绘制训练种子误差条或显著性星号。

360 炮参与过开发和选型；2,593 炮也是历史扩展，后续研究还使用了其中的离线监督。两者都不标为独立未来测试。70320 的首次越线只有一个采样点，连续两点确认下该炮不再及时。

## 重画与导出

```bash
PYTHONDONTWRITEBYTECODE=1 CUDA_VISIBLE_DEVICES='' \
  python outputs/east360_main_nature_20261117/plot_main_result.py
```

在研究目录（本 README 的上两级）执行。脚本使用 Python、NumPy、matplotlib、Pillow 和 pypdf，从同目录的 CSV 和 JSON 读取数据。四个面板独立出图，再按原尺寸合成。最终画布为 **183 × 136 mm**；PDF 保留嵌入字体，SVG 保留文字；PNG 与 TIFF 为 600 dpi。数据图采用白底、无衬线字体、克制配色及不同线型。

**当前版本：** `EAST_main_result_nature.pdf`、`.svg`、`.png` 和 `.tiff` 是同一组数据的主交付版本。所有图片由 Python 生成，不手改导出文件。
