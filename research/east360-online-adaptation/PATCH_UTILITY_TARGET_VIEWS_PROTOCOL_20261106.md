# EAST 观测缺失条件下的源域炮内纠错容量：先测动作，再学选择

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run
- Origin Date: 2026-11-06
- Verification Status: protocol before generating any new masked candidates
- Version Label: patch_utility_target_views_v1

源域原生 TRAIN 的首报监督只有 10 个独立的单写入受益炮，
用稀有事件加权也不能可靠选择。这一阶段不换报警阈值、不换基座、
不添加标签、不拟合选择器；只问在 EAST 实际可用的诊断子集下，
能否产生更多可教的有界内部纠错，而不是只让静态模型变差。

- 同一锁定 J-TEXT TRAIN1353，每炮并列 native、缺 MNM、缺
  MNM 和 CIII 三视图。native 复用原封存。对应 EAST 已确认的
  MNM 不使用，以及 CIII 在部分炮完全不可用；这里用两种明确
  缺失反事实，不伪造新物理波形，也不模拟量程、时序或全部漂移。
- 只把指定通道的数值与可用性设置为未观测；其他通道、采样时刻、
  原 scaler、父模型、.10 历史 logit 保护、.35 参数范数、六轴、
  释放时钟和固定报警阈值保持。各视图用自身已到达前缀计算
  候选，但结构与动作索引相同；看不到当前结局或未来采样。
  两个新视图的完整候选库都封存之后才另开评分进程。
- 每视图分别报告静态及时／误报、非零有益／有害标签、独立炮数、
  可被单写入或多块独立动作改变的炮。用同一候选锚点偏移构造
  **完整标量动作库**，不是只比较一个挑出来的动作。
  “仅内部可救的迟报”指在该视图的真正动作有可行单写入、而该炮
  所有同锚点标量单写入都不可救。跨视图去重及分折必须按原 shot ID，
  不把两个视图算两次独立炮。
- 进入下一次选择器拟合的最低支持：原生和两个新视图的单写入
  有益炮合并去重达到 20（原生 10），且新视图合计至少 4 个
  仅内部可救的独立迟报，分布在至少 3 个原固定折。达标也只是
  教学数据有支撑，仍需跨视图独立留炮、同等分数和乱序控制。
  若不达标，停止继续拟合本菜单，转去比较不同内部作用位置的
  实际能力；不得宣称 EAST 泛化。
