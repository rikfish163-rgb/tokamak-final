# 影子响应可观测前，迟报纠错是否已失去时机？

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run, scope before any delayed result
- Origin Date: 2026-11-06
- Verification Status: no delayed measurement at protocol freeze
- Version Label: patch_utility_shadow_timing_v1

本试验不寻找最佳等待时长，不运行新的报警器或学习器。问题是
一个必要条件：同一低秩动作在真正有机会改变首报之前，能否
先留下几帧可在线测量的候选影子响应？以前的影子采用检验
目标是诊断**预测误差**，这里检验的是同一已冻结动作在到达
信号上的实际**风险响应**及其后续可作用时间，不沿用旧拟合
结果当作新方法。

1. 只读三个原封存 TRAIN 动作库，不打开新波形，不改原
   阈值、方向、更新上限或结局。动作仍在释放 m 时由 ≤m
   的观测确定，实际无写入地等待 d 帧；到 m+d 才可使用
   这段时间已到达信号上的候选风险。比较 d=0、4、8、16，
   8 帧为主设计，其余为固定敏感性。原 32 点作用窗终点
   不延长。
2. 对每个固定动作曲线，将前 d 个已越过点严格恢复为静态，
   其余作用不变。真实/同锚点恒偏移按同样时钟；每炮保留
   未知最优的事后单动作和多块独立上限。任何早报不得撤回。
   这是对旧动作库的**可达性诊断**，不声称到 m+d 时重新
   满足了当前现场安全保护，也不把事后选择当运行策略。
3. 分视图列出严格 >10 ms 可救迟报、可消原误报、潜在新增
   误报及原炮去重。逐个迟报保存最迟的事后可写锚点；明确
   标注是否在每个等待时长后还存在真实动作胜过全体等偏移。
   若 d=8 不保留至少两个独立的“仅真实可救”迟报，则不拟合
   本等待设计的选择器；过门也只值得检验影子响应可辨别性。
4. 不读取新的 J-TEXT VAL/TEST 或 EAST，不改先前阳性门。
   后续如果做有监督方向选择，继续按原炮 ID 分折，方向输入
   只限已到达的候选风险，真实未来首报只作训练和评分标签。
