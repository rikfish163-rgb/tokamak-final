# 三种内部时序视图的炮内梯度适应：预先固定的开发实验

## 问题与边界

统一 d2 历史窗口减少4个FP、同时损失4个及时检出，完整360炮J不变。
本实验不再扩大统一倍率扫描，而检验：利用已经到达的诊断信号，能否在
Transformer两层之间逐炮调整时序视图，并产生超过静态视图的报警收益。
这不是新的风险分数修正，不改风险头、报警阈值或物理时间轴。

固定 c727…eb02 J-TEXT 源模型；固定当前 stratified_cold20_context360_v1
父实验的完整360炮、顺序、前20炮代价、冷启动参数和密度输入映射。
前20炮仍为原始源模型预测；第21炮起使用同一个已结束20炮准备的模型。
这里只检验炮内参数；不进行后续炮间更新。结局以HDF5为准，当前结局仅在
完整曲线写盘封存之后用于计分，不进入炮内更新。

## 插入位置与参数

在第一层Transformer之后，构造16个数据token的三种视图：

1. 原始连续128点（short）；
2. 已到达254点历史内每隔2点抽样（long）；不足历史时与short相同；
3. 每通道最近一次有效观测重复到原窗口（snapshot），保留原有效掩码。

snapshot是内部表示对照，不宣称真实过去恒定。
CLS在插入位置保持short原值。对每个数据token使用两个临时门控参数，
非负且两者和不超过1，其余权重属于short。总计32个临时参数，逐炮清零。
合成token后仍经过原冷启动slow层、原第二层Transformer、原风险头。
三种视图第一层均冻结；只有32个参数接受梯度，不修改源模型张量。

## 已到达信号如何训练

沿用源模型完整25点、23通道的直接预测头；一次输出全部未来窗口，非自回归。
每128点一次反馈；第一个反馈时刻为索引159（零起），原预测起点134。
下一次为287，原起点262；依次类推。完整原点窗口均已存在。
先计算并封存到反馈时刻的风险及原点预测，再访问原点后25点真值。
本次更新只影响反馈时刻之后的风险。固定32端点推理批，反馈位于批末，
避免改变历史数值路径。当前炮的标签、结局、未来尚未到达信号均不作为目标。

真实目标mask需每个未来点与原点均有效；排除离散mode_number_n。
所有反馈臂使用同一mask：再与逆序mask求交以保证逆序对照观测支持相同。
MNM遵循既有缺失合同，不凭空补数据。

目标为原forecast_loss（masked SmoothL1，源归一化坐标）加
0.01 mean(beta²)。固定步长0.1；单位范数梯度下降，再投影到非负和≤1集合。
仅在已到达目标的同一目标函数严格下降时接受候选；否则保留原门控参数。
无有效目标明确不更新；非有限值报错，不跳过异常继续计分。
训练目标下降不自动等于报警改善，需要以下实测对照。

## 七臂与主要验收

| ID | 插入位置的门控 | 有无当前炮梯度 |
|---|---|---|
| cold | 全部short | 无 |
| long_data | 数据token全部long，CLS仍short | 无 |
| snapshot_data | 数据token全部snapshot，CLS仍short | 无 |
| equal_data | 三种数据token各1/3，CLS仍short | 无 |
| real | 真实已到达25点目标 | 有 |
| reverse | 同一目标时间逆序 | 有 |
| hold | 将原点最近值重复到25点 | 有 |

long_data与以往“包括CLS的全网络d2重算”不是同一实验，不混称结果。
固定阈值0.7258946895599365，严格lead>30ms计及时检出；完整180D+180S计分。
前20炮8D12S全部计入，不能只报后340炮。另报lead>3000ms数量。

操作性门槛：real的FPR≤0.20、TP不少于cold、J严格高于cold。
机制支持门槛：real的J严格超过三种静态视图、reverse、hold；并列不算
证明真实反馈的独立作用。若仅目标损失下降而无报警净收益，判为失败；
若静态视图或假反馈同样好，不能把差值归因于有用的神经适应。
这只是开发集诊断，不是独立确认或物理机制发现。
