## 1. 比较是怎样做的

同一 J-TEXT 源、前20炮输入映射、360 炮固定炮序（180D/180S）、冻结炮内
第一层生成器与同一个阈值（0.7258946895599365）。前20炮的 8D/12S 历史标签
在该块封存后才开放。后续每20炮预测完成且封存，按**无标签**的报警分歧、
是否在可更新前已报警以及阈值邻近度选一炮；末块不查询，额外只读取16个标签
（4D/12S）。未查询的目标结局不进入生产回放，由单独评分器在回放结束后读取。

炮间修正是第一层内部的128维增益/偏移向量，而不是报警规则修改。共享同一
持久记忆给 inter 与 both；intra 与 both 使用同一炮内动作。模型向量按过去
炮已到达的状态和短/长变化检索，在实际模型前向拟合，每次20步、有界。
提议保护包括查询炮、先前 4D/4S 冷启动守卫与最近两次查询的整条曲线。
当时的混合对照在推理时把相似度权重替换成均匀权重，提议仍用局部核。第三种从头回放
允许安全标签继续作守卫，但不从安全查询生成新的修正。

## 3. 为什么这些策略不够好

**安全修正过度迁移。** 局部全反馈相对炮内救回2、丢失8个严格及时，减少
2个误报、不新增。虽然核有紧支撑，首次生效后的320炮中有318炮曲线发生
可测变化（最大概率差 (>10^{-6})）；局部并不等于临破裂时刻附近。进一步
固定原来的记忆写入路径、核分母与生效秩，按训练结局将向量置零：

| 固定路径上的干预 | 合用及时 / 误报 | 30–3000 ms 及时 |
| --- | ---: | ---: |
| 原路径全部修正 | 114 / 31 | 99 |
| 只留安全来源 | 112 / 31 | 98 |
| 只留破裂来源 | 122 / 34 | 106 |

全部修正导致丢失的8个及时炮，只保留安全来源时全部仍丢失，只保留破裂
来源时全部保住。原路径消除的2个误报也都能由安全来源单独消除。说明在
这个固定实验中，同一组安全修正确实一边减少误报，一边抑制真正的前兆。
拆分是后验机制诊断，不能当作训练另一个策略的成绩。

**从头复跑后，破裂记忆仍缺少阶段辨别。** 只拟合破裂的组合，相对炮内新增
2个严格及时、增加1个误报，(J) 增约 .00556。但 70861 从18 ms 到45 ms
是真救回；73541 的新首报提前 5.333 s；89549 从59 ms 被推到3.024 s；
85123 新增误报。70861 的救回与 89549 被推早相互抵消，30–3000 ms 没有净增。
三种炮间策略之间的差别不是因为拿到了更多标签；源网络、参数插入位置和阈值也固定。

**下一步的线索是轨迹阶段，而非放大步长。** 对这4个配对变动病例，重新由
原信号构造键，并逐值重现先前已写入的两个历史原型。把同一历史破裂炮的
(leadge500) ms 键作为“较早阶段”参照（不标成安全）。在 70861 的45 ms
端点，最近的临破裂训练键距离为 .954 个带宽，较早键为 1.013；在 73541
的5.333 s 端点是 1.112 对 .997；89549 推早端点与实际激活的85023原型
为 1.655 对 1.597，新增误报对两个原型也更接近较早参照。**只看这几个
被挑出的变动不能保证泛化**，但给出明确的下一项检验：先前已经揭示的
同炮较早轨迹，能否在不读本炮剩余时间的情况下抑制这种误匹配。

## 5. 补齐同标签、同揭示时点的直接迁移

沿用旧固定360、原0.72589469阈值、前20和相同16次查询（4破裂、12安全）。每20炮先封存预测，再按原无标签策略承诺同一个查询；最早下一炮才能用该结局。前20仍作准备和守卫。基模、第一层炮内动作、整炮保护和查询集合不变。在原局部全反馈臂的同8次拟合机会，用相同新教学端点、每次20步 Adam 维护一个共享128维第一层增益／偏移向量。与旧方案逐炮新增局部原型不同，此处每次联合重放截至该时点已揭示的教学样本，按炮等重，并对仅炮间和联合两种上下文等重；标签和优化步数配平，历史样本累计计算量不同。半径.60，合用时仍按原规则缩小炮间分量使总范数不超过2.0。没有使用未查询炮真值拟合，也没有在这些结局上选阈值。

| 固定360，同一阈值 | >30 ms 及时／误报 | 30–3000 ms 及时 | 同一未查询后段及时／误报 |
|---|---:|---:|---:|
| 静态 | 116／29 | 100 | 108／19 |
| 仅炮内 | 120／33 | 105 | 110／21 |
| 直接迁移，有保护 | 116／29 | 100 | 108／19 |
| 直接迁移＋炮内，有保护 | 120／33 | 105 | 110／21 |
| 局部记忆全反馈＋炮内 | 114／31 | 99 | 105／20 |
| 均匀核全反馈＋炮内 | 114／29 | 100 | 105／19 |
| 局部只拟合破裂＋炮内 | 122／34 | 105 | 112／21 |
| 阶段参照匹配＋炮内 | 121／33 | 106 | 111／21 |

**直接迁移8次提议全被拒绝。** 八次均降低其历史教学损失，且向量抵达.60半径，但每次在仅炮间臂会让冷端已知安全炮70323产生新误报；第16块另使历史安全炮67900在联合臂新增误报。实际回放因此逐点复用各自父曲线。旧局部全反馈能采纳7次，主档却比炮内少6个及时；只拟合破裂在经验20%误报内净增2个严格及时，30–3000 ms没有净增；阶段参照匹配净增1个，两者均没有在后180炮改善该区间。直接迁移未被采纳不构成局部经验在同标签下稳定获益的证明。

**封存候选的保护影子。** 每次只在原揭示边界后启用当时已经拟合好的向量，下一提议替换它；不因影子结果重训或读取新标签。绕过保护时，直接迁移为121／33（30–3000 ms 104），联合122／44（区间103）。联合相对仅炮内救4、失2，新增11个安全误报且无移除，实际FPR24.44%，超过20%。直接影子单臂满足20%并相对静态多5个严格及时，需如实保留；这是固定已拒绝提议的反事实，原保护下没有实际写入，也不等同于一条从头重训且合法采纳的路径。

原阈值下，上表正式臂均未达到.15；单独炮间的局部全反馈110／25、均匀核107／23满足.15，及时数低于静态。本项没有另立阈值，.10没有合格臂。严格 >15／20／25／30 ms，炮内与正式直接联合均为133／128／125／120；155个已报警破裂炮的均值850.84 ms、中位130 ms。阶段匹配联合为133／129／126／121，155炮均值851.04 ms、中位130 ms。没有以平均值代替炮级及时／误报。

复现：本机 CUDA 回放11.59秒退出0，独立CPU读360原HDF5复算4,320条首报，核对36次可见结局、每块先封存再揭示、8次教学端点、完整保护和160步预算。保护影子CUDA约25.95秒退出0，另复算1,440条首报。初跑在传参错误处退出，未产生成绩；使用修正后的独立目录。
