- Verification Status: complete source replay, independent HDF5 recount and CPU witnesses
- Version Label: output_trust_v1 / continuous_capacity_v2

**本版不进入 EAST。** 把临时参数改动在三个已到达时刻的风险变化
限制在 .10 logit 内，并分别预测误报和首报损害后，J-TEXT VAL160
三个种子均为 73 个及时报警、6 个误报，没有新救回，也没有减少
误报。安全约束阻止部分退化，但不能替代纠错能力。

## 1. 全炮训练与盲封存

沿用冻结源模型、固定阈值、原两段 32 点成熟时钟。18 个正反方向
用真实诊断误差梯度产生，参数范数上限 .35；有约束版在
`m−16,m−8,m` 三个已到达时刻用原网络真实前向选择正反共同
半径，不裁剪任何未来输出。所有绝对峰、相对形状及保护损害只
用已经结束的源训练炮标注。两类伤害头各自拟合；最佳动作若被
伤害头否决，选择不写入，不改选第二名。

TRAIN1353 共 12,570 个可用块，涵盖 1,165 个安全炮、177 个
有规范正窗的破裂炮、144 个原及时首报可保护的炮。所有动作的
后续块先实测封存，再按完整炮做五折选择与首报复算。无约束版
的已到达变化最大 6.1107 logit；有约束版最大 .0999994。以
动作–种子–窗口为单位，约 1.85% 原可用动作被缩至零；全部
270 个有支持正窗仍至少有一个可用动作。然而对 6 个原迟报炮，
无约束原轴每种子均有 6 炮存在某个越阈动作，受约束原轴为 0。
**可更新的窗口多，不代表有真正能救回漏／迟报的更新。**

TRAIN 五折全炮计分中，冻结为 182 及时／117 误报；无约束联合
三个种子均为 182／114，所有有约束臂仍为 182／117。按事前
几何覆盖门槛允许执行固定 VAL 盲回放，没有用 TRAIN 得分挑
种子、阈值或调整约束。

不能当作成功。

## 3. 同一限幅下的方向容量

仅用已结束的六个源迟报炮、9 个有支持块。比较原方向逐个缩步、
只用到达风险导数投影原方向、在诊断方向张成空间组合、以及加
入未来风险导数的增广空间。后两项为离线诊断，使用真实未来
正窗选择优化目标；每个候选都在原网络直接复核双符号历史变化、
参数范数和实际整块风险。没有把未来导数引入可运行策略。

| 方向条件 | 原6迟报炮中实际可越阈数（各种子相同） |
| --- | ---: |
| 原方向，不限输出 | 6 |
| 原方向，同约束缩步 | 0 |
| 只用已到达信息投影原方向，再同约束缩步 | 0 |
| 离线优化，混合原诊断方向 | 1（1057866） |
| 离线优化，额外允许未来风险导数 | 2（另有1056284） |

这不是全局最优或实际及时率：150 个有限优化尝试中求解器
63 个声明成功，97 个优化终点通过原模型的数值可行性检验；
仅保留真实可行的候选。第一轮和加无未来对照的第二轮的容量结果
逐值一致。把 9 个越阈状态接回原始完整炮独立复跑，三种子均
重现；原诊断组合中 1057866 提前 18.47 ms，增广才到的
1056284 提前 10.37 ms，接近源及时判定边界。
结论分两层：单方向缩步并不是可达性的上限；同时，
仅有当前诊断方向和三点投影，还没给出**如何因果选对组合**
的证据。不能直接上线离线优化出来的参数。
