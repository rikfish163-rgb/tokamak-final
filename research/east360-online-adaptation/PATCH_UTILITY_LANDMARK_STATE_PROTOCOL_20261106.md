# 炮内更新需要的风险状态是否可识别：125 ms 辅助靶

- Origin Skill: experiment-agent
- Origin Mode: run, frozen before any state-head fit
- Origin Date: 2026-11-06
- Verification Status: previous exact payoff and support verified; state predictions not yet scored
- Version Label: patch_utility_landmark_state_v1

先检验“这段时间值得争取及时首报吗”，不让候选动作如何越线
影响状态头训练。原生受保护的正效用场景只有 7 个原炮，直接
再拟合一次硬效用不增加监督。扩大的是**辅助靶**的时间和可用
的训练时刻，不改变 J-TEXT 源训练窗、不修改源模型或报警规则。

- 对相同 release 和八帧延迟，比较两种离线辅助靶：后续真实
  记录的至多 24 帧中是否有 `10 < lead <= H_i`，与是否有
  `10 < lead <= 125 ms`。125 ms 是项目现行 EAST 正窗，
  不是扫测试结果选的值；两靶独立，若某炮 H_i >125 并不覆盖
  原窗。无真实后续的块不评分。完全和部分块的真实长度、
  HDF5 结局、破裂时钟、候选未来分数只作教学或评分，绝不输入状态头。
- 主拟合使用三视图的所有有真实后续块，**包括**静态已报警块；
  额外拟合限制至仍可写入的块作训练支持对照。两种拟合在
  完全相同的五个留出折上打分，仍为三拟合折、一未使用预留折、
  一留出折。按辅助标签、物理炮、视图、块等权，不把分数称为
  自然流的概率。固定 ridge logistic L2 .03，不搜超参数或弃权阈值。
- 四种信息条件：风险／时钟、三家族的无序统计、真实时序反馈、
  倒序反馈。四臂共享 m 的 10 个静态历史特征及 m+1..m+8 的
  八个静态分数。附加 27 维来自既有封存的 Mirnov、SXR、XUV
  三组预测误差、带符号变化、有效样本数（每组三个子段）。
  无序臂只对每类/每组的三个子段排序，保留其多重集合；
  倒序臂来自已有的同观测值时间反转后**重新算反馈**。
  本轮不再读取或重跑波形。
- 固定两项留出比较：1）仍能写入的块，在相同评价标签（先原窗、
  再 125 ms）上的逐炮平衡 AUROC／AP；2）真正有可救迟报的块，
  对照真的存在新增误报动作的安全块。第 2 项用事后硬效用来
  构造**核验子集**；只取每炮/视图的同一基准块集合，评分按
  炮与视图等权，逐炮列出可救块分数。由于只有 5 个正原炮，
  同时列五次剔一重算的描述性范围，不作显著性或独立外推声明。
- 若 125 ms 与有序反馈的改善未同时见于可写入域与关键正负
  对照，不能让此状态头决定写入。即使方向正确，也须下一轮
  在同一时钟预测候选首过线而非均值，并用原阈值验证实际
  整炮首报、先纯炮内后联合；本诊断不产生在线增益、EAST
  推理或监督预算变化。不能把两个条件均值的乘积当作无偏效用。
  具体晋级仅针对全支持拟合：125 ms 真实臂在共同的 125 ms
  可写域 AUROC 和 AP、以及关键正负 AUROC，均须优于全支持
  的另外三个 125 ms 信息臂与原窗真实臂，且关键 AUROC 的优势
  不依赖任何单个可救炮；未过则保留诊断。
