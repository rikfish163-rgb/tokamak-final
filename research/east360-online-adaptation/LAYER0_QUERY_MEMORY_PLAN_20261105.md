# 局部炮间记忆：冻结炮内策略上的四臂消融

**问题。** 第一层的本炮方向在固定误报上限内增加了及时预警，但相对静态 (J)
持平。已知的跨炮错误能否以局部神经参数写入的形式减少误报，又不吃掉炮内收益？

| 实验臂 | 第一层内的临时动作 | 第一层内的跨炮记忆 |
| --- | --- | --- |
| static | 无 | 无 |
| intra | 已冻结动作 | 无 |
| inter | 无 | 有 |
| both | 已冻结动作 | 与 inter 完全相同 |

保持原源模型、固定 360 炮序、前20炮映射、HDF5 口径、阈值和首越规则不变。
必须复现 static 与 intra 的完整曲线及越阈结果。前20炮全用静态预测，
封存后才开放这20个共同历史标签。此后每个20炮块全封存后，按不依赖真值的
固定顺序选一炮：优先没有不可修改的首步前报警、静态/炮内是否报警不同、两者
的整炮峰值离固定阈值近；再以峰值差大、炮序早打破平局。最后一块不查询，
因为它的反馈不会影响流内的任何预测。新增 16 个可见标签，不读取其余后缀
结局直至独立评分。预测、查询承诺、HDF5 读取、写入均有单调进程时钟及哈希。

每个允许查询的错误炮，选安全轨迹的分段峰和已有首报，或破裂前 (30<leadle125)
ms 的教学窗口；仅用它与之前可见的结局。以当前隐状态、短/长状态差（不含
风险值或时钟）作键，使用前20炮已有标准化尺度及跨炮近邻距离的75%分位数确定
带宽。匹配一个已知错误炮的多个窗口时，取其最大紧支撑核权重，跨炮加权平均，
权重和不足1时按实际权重衰减。每炮候选是第一层的一个128维增益/偏移向量，
用真实固定风险网络前向拟合，对 inter 与 both 的等权风险损失做反传，固定
Adam 20步，L2 半径 .60（原合成动作上限2.0的30%）。与冻结临时动作合成时
只缩减记忆增量至总范数2.0，不旋转或重新归一化炮内动作。

写入前对刚结束的查询炮重放**完整曲线**。不能破坏原来正确的安全判断、及时
或30–3000 ms 报警；错误臂的实际整段风险余量不能变差，至少一个要修复首报
或概率峰净改善 .02。再用前20中按顺序最先可用的4个破裂、4个安全全轨迹，
加最近两次已揭示的查询炮做同样的既有正确性保护。只保护这些已知历史，不能
解读成对未知炮的安全保证。若拒绝写入，原因和拟合回执仍保留。无参数扫描。

**评估。** 以整炮配对统计严格 (lead>30) ms、FPR、J，分开 (30<leadle3000)
与 (lead>3000)；查看新增/丢失的及时报警、误报、首次可用反馈之后的各阶段、
同一未查询集合上的结果。组合方法须在 FPR≤.20 下对静态和炮内具有净增益，
并证明保有可辨的炮内边际贡献；只改风险曲线不算成功。此轮四臂不含
等预算直接迁移；需要另作同一标签清单和标签时间边界的对照，不能用其占位
或事后数据替代。固定流已参与开发，无独立未来验证声明。
