# 炮内首报的两个问题：动作会不会越线，越线是否有益

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run, with independent artifact recounts
- Origin Date: 2026-11-06
- Verification Status: deterministic sealed-bank, split and metric checks complete; no prospective policy validated
- Version Label: shadow-response / dense-effect / pivotal-support / landmark-state v1

**决定：不晋级当前选择器，也不把新状态头接入报警。** 八帧影子风险
能帮助预测内部动作随后怎样改变分数，预测平均变化却不能判断
是否该动。原训练正窗还遗漏了五个可救迟报中的三个有效首报；
扩大辅助靶后有了更多监督，但在真正的救报与误报对照上，有序
诊断反馈仍输给只看原风险和时钟。源模型、固定阈值、训练标签和
EAST 实流均未改动。

### 1. 影子响应有数值信息，没有证明能选对首报

在相同三个 J-TEXT TRAIN1353 封存视图、相同动作和八帧保护
下，动作选择器按物理炮五折留出；各折三折拟合、保留一折给
可能的校准、另一折评分。不读当前结局决定采用；倒序只改变
候选响应相对静态风险真实时钟的对齐。真序、倒序和仅幅度三臂
均没有把可救迟报动作排第一；不看影子仅在双缺视图的 1055239
排对。下面的名次是各视图内最好的有益动作名次，不是在线
救回，未执行选择策略的整炮回放。

| 影子信息 | 有益迟报排首的独立原炮 | 最好名次：原生／缺 MNM／双缺 |
|---|---:|---:|
| 不看 | 1 | 4 / 10 / 1 |
| 仅幅度 | 0 | 4 / 10 / 6 |
| 真序 | 0 | 4 / 10 / 6 |
| 倒序 | 0 | 4 / 10 / 6 |

同一动作的另一个目标更容易：预测随后三个八帧段内，
「候选减静态的 logit」相对最后已达偏移的平均变化。留出
1,308 个有完整支持的原炮，先对同块动作等权，再对块、
视图和原炮等权。拟合目标不使用破裂标签；加载器仍核对了
原 TRAIN HDF5 的元数据及已有 bank。

| 后续效应预测 | 按炮等权 MAE（logit） |
|---|---:|
| 保持最后偏移 | 0.029323 |
| 线性外推已达斜率 | 0.062839 |
| 学习但不看影子 | 0.029260 |
| 仅幅度 | 0.024622 |
| 真序 | 0.021406 |
| 倒序 | 0.021454 |

真序相对保持的误差少约 27%，相对倒序只少约 0.23%，
且双缺视图反而略差。对倒序有 802 个原炮较好、506 个较差。
所以“有影子响应可帮助估计动作效应”有数据支持；“顺序
明显增加可用信息”及“可以辨别首报收益”都没有相同强度
的证据。这里没有新的 TPR/FPR。

### 2. 点级正窗与操作上能救回的首报并不重合

用 [独立首报实现](verify_patch_utility_selection_20261106.py) 对照
[精确效用分解](PATCH_UTILITY_PIVOTAL_SUPPORT_PROTOCOL_20261106.md)。
决定时刻已无静态首报时，若未来局部首个越阈在破裂炮是及时的、
且动作有效期过后静态不再有及时报警，局部越阈值 +1；若本炮
安全且窗后也不会报警，局部越阈值 −1；其余为 0。动作首个
越阈所取的值减静态首个越阈的值，恰好等于原一次写入的炮级
硬效用。HDF5 结局和后缀只用于离线靶，不能作为策略输入。
386,104 个受保护非零动作全部与旧首报计分一致。

在八帧后仍有完整后续 24 帧的原生视图里，118 个原炮含
原训练及时正窗；限制“此前尚无首报”后剩 21 个，进一步
要求能写入后剩 20 个。此时只有 7 个独立破裂炮的局部
越线可能改变炮级结果，只有 6 个是原先未及时；三视图去重
分别 15、10 个。相反，三视图有 1,080 个安全原炮的局部
越线可能改变误报结果。这些是状态靶支持，不表示有实际
动作能翻转所有这些炮。

按原保护计入不完整后缀时，实际动作库只能救回五个原迟报：

| 原炮 | 有效首报提前量 | 落在原正窗 | 后续完整 |
|---|---:|---|---|
| 1052388 | 35.36 ms | 否，块内另有正窗点 | 是 |
| 1053042 | 34.56 ms | 否，整块都没有正窗 | 是 |
| 1053940 | 107.56 ms | 否，整块都没有正窗 | 是 |
| 1055239 | 19.87 ms | 是 | 否 |
| 1056284 | 10.37 ms | 是 | 是 |

五个原炮在本资料中的源训练窗均为 25 ms。最后一例仅略超
10 ms 截止，不外推为充足提前量。三个越窗首报仍按原 J-TEXT
指标算及时；它们说明不能把原点级正窗当作所有合理首报的
代理。表为事后动作容量，不是实际选中。

### 3. 扩大辅助靶后，可见风险增加；有序反馈仍未过关键对照

[事前协议](PATCH_UTILITY_LANDMARK_STATE_PROTOCOL_20261106.md)
只把未来局部有无可预警正点的**离线辅助靶**从
`10 < lead <= H_i` 换成另一固定版本 `10 < lead <= 125 ms`。
125 ms 来自项目的 EAST 监督窗口，不调整原 J-TEXT 的模型
标签、报警阈值或及时线。与按事件发生时间建模的
[DeepHit 原论文](https://ojs.aaai.org/index.php/AAAI/article/download/11842/11701)
仅共享“把事件时间单列为目标”的动机，不是复现其模型或结论。

含部分后续的所有可写块中，三视图带正例的物理炮由
23／37／32 增至 108／119／106。四种信息臂同样只看到时刻
`m+8` 已到达的数据；状态靶不随候选身份变化。分数在
同一五折留出测，不称为自然流概率。关键子集是事后确定的
5 个真实可救迟报对 67 个有新增误报动作的安全原炮；
这些病例只用来核验，绝不决定输入或拟合权重。

| 拟合靶和信息（全支持） | 可写块统一 125 ms 靶 AUROC / AP | 关键正负对照 AUROC |
|---|---:|---:|
| 原窗，真实诊断序 | 0.819 / 0.806 | 0.802 |
| 125 ms，仅静态风险和时钟 | 0.826 / 0.816 | **0.869** |
| 125 ms，无序诊断统计 | 0.832 / 0.808 | 0.849 |
| 125 ms，真实诊断序 | **0.835 / 0.816** | 0.852 |
| 125 ms，倒序诊断 | 0.832 / 0.810 | 0.845 |

可写块的 AP 未舍入时，真序 .816479、风险时钟 .816193；
不能把这个很小的差异扩大为有用收益。关键子集相对风险时钟
下降 .01741。五次剔除一个可救原炮后该差异仍均为负。
按同一留出折才比较的探索复核中，真序在有正例的三个折中
一折更好、两折更差。只在可写块拟合的真序臂在关键子集
AUROC 为 .829，也未改善。正例只有五个；不报显著性或
外推，不把总体分数变好当作炮内增益。
