## 主要结论

**新增8点差分势没有产生完整EAST流的炮内增益。** 原360炮上，七臂均为116个严格及时检出、29个误报，没有任何救回、损害、新增或消除误报。对这四个已计算的实际动作，即使事后逐时刻选最好动作，及时检出上限和误报下限仍为116／29，因此不再训练选择器来调度同一组动作。

这个有限动作集合的结论，不是对所有低秩参数、Transformer或无监督适应的理论上界。整体科研目标尚未达到，不进入炮间及联合的成功归因。

## 4. 为什么局部变化没有变成预警收益

以下只分析已封存曲线与评分结局，不拿这些错误标签重新拟合：

| 固定shape实际作用 | 观测值 |
|---|---:|
| 后340中风险曲线最大改动>10⁻⁶的炮 | 340/340 |
| 后340中风险曲线最大改动>5×10⁻⁶的炮 | 337/340 |
| 后340中实际临时参数非零的炮 | 340/340 |
| 全流最大单点概率改动 | 0.0102367401 |
| 后340每炮最大概率改动的中位数 | 0.0004572272 |
| 首报采样点改变的炮 | 3；移动范围−1…+1点 |
| 后340未及时检出的破裂炮 | 63 |
| 这些炮及时区间峰值距门槛的差距中位数 | 0.3990365267 |
| 这些炮峰值改动的最大有利值 | 0.0008931756 |
| 后340误报炮峰值高于门槛的中位数 | 0.1584172845 |
| 误报炮峰值改动范围 | −0.0003723502…+0.0001924038 |

最接近可救的65944，原及时峰值仍低于门槛0.001401901，而fixed_shape反向降低峰值0.000045598。74087的峰值有利增加0.000893176，但原差距0.062603891。这两个案例分别说明方向不合适与实际作用不足；不是仅靠修改某个统一倍率就已证明可解决的问题。

因此“没有执行梯度更新”不符合观测。更准确的结论是：**当前反馈损失产生的实际内部改动，没有把这些错误轨迹推到正确决策一侧。** 源域学到的通道权重也未改善该问题。

进一步把四个实际臂static／level／fixed_shape／learned_shape逐时刻拼成事后有限菜单：破裂炮取最大曲线，安全炮取最小曲线，仍只有116个可及时检出，至少29个误报。该反证排除了“再给这四个动作加一个完美开关就能救回”的期待；它只约束这四条已计算曲线，不约束其他参数方向、半径或模型。

- 数学内核＋源模型集成33项通过2.31s；新增时钟＋内核＋集成32项通过2.77s。两组有重叠，不相加为覆盖率。实现通过不等于方法通过。

## 6. 后续决策

停止继续扫描这套固定子空间下的差分间隔、权重和开关。需要检验模型允许调整的内部方向是否适合风险纠错，而不仅是让同一小范围梯度更复杂。当前第一FFN的4维输入基底由源权重SVD选定，尚不能把其最大奇异方向等同于破裂相关的可塑方向。

[MT-net（ICML 2018原文）](https://proceedings.mlr.press/v80/lee18a/lee18a.pdf)在第3节区分了跨任务学习的激活几何与任务内更新参数；它支持把“在哪些内部方向适应”作为单独设计变量。其少样本监督协议不等于本项目的无标签炮内协议，也不证明这项改变能成功。后续必须单独比较源SVD、同范数随机方向和源任务训练出的可塑方向，保持零状态等于合格基模，再以真实／错配反馈和完整流检验，而不是预先声称已有增益。
