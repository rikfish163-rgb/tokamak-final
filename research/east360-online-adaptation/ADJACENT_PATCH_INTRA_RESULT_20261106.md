# 炮内低秩变化写入：有真实轨迹纠错空间，预测误差还不会选对方向

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run and independent paired re-evaluation
- Origin Date: 2026-11-06
- Version Label: adjacent_patch_intra / observability / ridge v1
- Verification Status: completed TRAIN diagnostic; no new EAST efficacy evidence

**决定：不晋级这两个无标签更新规则。** 相邻时间片的变化写入
可以产生超出等锚点分数偏移的真实时序效果；但这种效果有时
也会新增误报。现有 H25 自监督误差及其逐点岭解，在真实首报
上未能把两种情况区分开。

## 1. 相同容量和幅度的固定因果回放

按[事前方案](ADJACENT_PATCH_INTRA_PROTOCOL_20261106.md)固定父模型、
时钟和阈值。只有相邻片都实际观测到的同位置诊断才用于写入；
变化和水平臂使用同一个 8×8 临时矩阵，未改风险头、CLS 或
原始可用性。三类诊断的已到达变化误差分九项求梯度；以真序、
反序及等锚点分数作对照。四个真实写入臂匹配实际 token 编辑
量，再用相同网格对正负两步做原模型历史风险限幅。

J-TEXT TRAIN 的 260 个预选诊断炮（177 破裂、83 匹配安全）、
75,369 个采样点和 1,942 个释放位置完整回放，封存后才重读
HDF5 结局和时刻。它不是代表性测试集，特别是匹配安全炮的
误报计数不能外推总体 FPR。

| 固定方法 | 整炮及时 | 误报 | 144 个保护窗内不再越阈 |
|---|---:|---:|---:|
| 冻结 | 171 | 57 | 0 |
| 真实变化写入 | 171 | 58 | 18 |
| 反序变化写入 | 171 | 58 | 15 |
| 真实水平写入 | 171 | 58 | 11 |
| 反序水平写入 | 171 | 58 | 11 |
| 变化的等锚点分数偏移 | 171 | 58 | 0 |
| 水平的等锚点分数偏移 | 171 | 57 | 0 |

全部 497 个角色窗有共同梯度支持且有实际写入。270 个危险窗
（177 炮）上，变化写入相对冻结平均风险峰为 −.00513 logit；
相对真实水平 +.00085 [−.00441, +.00623]，相对反序 −.00085
[−.00505, +.00343]，相对等锚点分数 −.00608 [−.01148, −.00105]。
区间为同一固定开发样本上的炮级重抽样描述，不作独立总体检验。
变化与等分数的局部曲线最大差中位 .0344 logit，说明形状确有
改变；“形状改变”不等于改善。“保护窗内不再越阈”也不等同于
整炮失去及时报警。

## 2. 有限能力：离线确有不能由等分数复制的方向

同一六个原迟报炮、九个正窗，匹配求解次数与参数预算。每个
状态既复核真实后续块，也复核等锚点偏移；优化时可看到未来，
所以不能用于部署。在 300 次有限求解里，每臂 50 次，不是
严格上界。

| 候选空间 | 正窗内越阈且整炮变及时的炮 | 等锚点分数对照 |
|---|---|---|
| 变化真序九梯度 | 1056284 | 无 |
| 变化反序九梯度 | 1056284 | 无 |
| 水平真序／反序九梯度 | 1056284 | 无 |
| 完整 64 维水平空间 | 1056284 | 无 |
| 完整 64 维变化空间 | **1052388、1056284** | 无 |

原来的仿射层有限比较可救回 1057866；本次不是与异构层按
完全等效预算比较，不能把新旧炮数直接加总。1052388 的完整
变化见证在 m=159 写入之后，使实际首报提前量由 7.36 ms
变为 35.36 ms，并且在规范 10–25 ms 区间里也有越阈点；
等锚点分数的首报仍是 7.36 ms。1056284 的首报从 9.37 到
10.37 ms，贴近判定边界，不能夸大为实机裕量。
完整变化空间的新增方向属于离线能力；真序九梯度没有胜过
反序及水平，预设晋级门未过。

## 3. 原预测头并非看不见方向，九项汇总损失压缩掉了很多

[逐坐标雅可比试验](ADJACENT_PATCH_OBSERVABILITY_PROTOCOL_20261106.md)
固定 40 炮／45 窗，在相同到达信息上去掉三个已到达风险导数
方向。12 个普通危险窗中，九项汇总对未来风险方向的范数覆盖
均值为 .464；逐点最强同秩九维为 .500（差的描述区间跨零）；
保留相对奇异值 ≥.01 的逐点空间为 .914，平均约 52 维。
后者的优势不能与增加维数分开解释，但证明原预测头并非
完全对这类风险变化不敏感。

1052388 完整变化见证投影到真序九项空间时，只保留向量范数
的 **38.5%**；投影到稳定逐点空间时保留 **87.2%**。实际重放
中九项投影仍只报 7.36 ms，空间外分量与逐点投影均在同一限幅
下仍报 35.36 ms。这两个投影的首越都在 25 ms 规范训练窗之前，
且后来未在规范正窗内再越阈，不能把它们算作新增规范窗跨越。
未投影的完整见证才同时满足两项。逐点真实雅可比在同一原波形
上的独立 float64 中心差分，最大误差 2.06e−10。

## 4. 直接拟合逐点反馈仍没选对

按[预设岭解](ADJACENT_PATCH_RIDGE_PROTOCOL_20261106.md)在同一
40 个预选 TRAIN 炮完整回放。逐点解只看已经到达的预测残差，
不看当前炮结局；真实／反序、变化／水平、逐点／九项共八个
内部写入臂在每个锚点匹配实际编辑 RMS 和双符号风险限幅。
冻结 **22 及时、9 误报**；八臂都是 **22 及时、10 误报**，
新增是同一个 1053386，首报都是零基索引 120。逐点真实变化
的等分数对照为 **22、9**。这证明实际形状变化确实能产生不同
的整炮判定，也证明对这组数据，真实观测与普通反序在误报上
没有表现出可靠的选择性。未通过门槛。

## 5. 下一轮具体改变什么

这不是继续增加学习率、把九项改成更多项、或只给风险头加修正。
现在有必要检验**炮内观测能否预测一次动作的首报收益**：用已
结束的 TRAIN 炮生成实际内部写入与不写入的首报差，离线训练
从到达前缀到受限内部动作的映射，同时保留不写入这一选择。
必须含危险、原首报和同风险余量的安全窗口，不用六炮做唯一
教师。按炮留出，比较真实波形、同容量反序、仅风险／时钟、
等锚点分数和冻结；用整炮首报而非预报损失作为晋级证据。
原 J-TEXT VAL 整炮门过后才进 EAST；先独立炮内，最终仍固定
阈值，报告严格提前超过 30 ms 与排除超过 3 s 的及时量，并
满足 FPR ≤20%。
