# 炮内首报效用：有真实纠错动作，但尚不能从已到达信号可靠选中

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run and independent recount
- Origin Date: 2026-11-06
- Verification Status: complete; disjoint fits, whole-shot scores, raw forward and exact finite capacity independently checked
- Version Label: patch_utility_selection_train_v1; sparse follow-up is exploratory

**决定：两个选择器都不晋级。** 在 1,353 个锁定 J-TEXT 训练炮上，
有界低秩内部写入的真实反事实，确实可以救回迟报或消除误报。
但硬首报监督的机会高度集中；整炮留出时，真实波形选择器没有救回
任何迟报。重加权并限制每炮只写一次后，真实视图在留出集仍新增误报，
同幅度／同动作的对照不支持可用的时序特异收益。结果不是 EAST 在线
成绩，未读取新的源验证／测试或 EAST 波形与结局，未修改报警阈值。

## 1. 固定策略、波形和首报口径

源模型固定；它已在这些 TRAIN 炮上训练过。这里只把**动作选择器**
分为三折拟合、一折独立校准、一折评分，五次轮转，各折的炮号完整互斥。
每个已到达释放点只用当前及过去信号，构造六个轴的正负方向，加不写入。
候选改变 Transformer 的内部数据 token，不直接调风险头。三处历史
前向变化限制在 .10 logit，未来写入最多 32 个采样点，每块不继承
上一块的临时参数。真实前向的全部候选轨迹先生成并封存，
再按原始 HDF5 IsDisrupt／DownTime 重算每炮首报。

共 188 个破裂炮、1,165 个安全炮、12,570 个释放块、476,194 个点。
阈值全程不变，及时为首次有效报警提前 **严格大于 10 ms**。
J-TEXT 规范训练正窗仍为 max(25 ms, AdvancedTime)，只影响训练教师的
软效用分区，不替代首报判定。逐炮和候选的细则见
[主协议](PATCH_UTILITY_SELECTION_PROTOCOL_20261106.md)。

## 2. 动作容量与实际选择

| 量 | 有效数量 |
|---|---:|
| 可用非零动作 | 150,840 |
| 单次写入有益／有害 | 30 / 92 |
| 至少存在一个单写入有益／有害动作的独立炮 | 10 / 28 |
| 6 个原迟报中，单写入或允许每块独立多写能救回 | 2 / 2 |
| 117 个原误报中，单写入／允许每块独立多写能消除 | 8 / 11 |

这是有限动作菜单的**事后能力**，不是可部署成绩。4 个不可救的迟报
在整个及时区间内，最优实际 logit 峰值仍离阈值 0.469–1.419。
117 个原误报中，7 个在首个可写点之前已经发生；另 99 个即使把
每块都选成最有利的实际候选也还会越阈。只有 11 个能消除，
其中 3 个必须在同一炮内写入多块。这些数限制的是本动作位置、
候选集、时钟和限幅，不是所有炮内模型的理论极限。

两个事后可救回迟报为 1052388（7.36 → 35.36 ms）和 1056284
（9.37 → 10.37 ms）。后一例贴近判定线，不外推为充足提前量。
它们在原风险曲线上的及时区间峰值距离阈值分别为 .711、.782
logit，均远大于 .10 历史锚点允许的偏移；同锚点恒偏移不能救回。
原模型 embedding hook 复跑还确认了安全炮 1054241 的单写入纠错、
1054159 必须多写才能消除的误报、以及 1052344 因写入新产生的误报。

| 选择器 | 开放：及时／误报 | 保守：及时／误报 | 开放／保守写入块 |
|---|---:|---:|---:|
| 冻结 | 182 / 117 | 182 / 117 | 0 / 0 |
| 风险与时钟 | 182 / 132 | 182 / 117 | 12,391 / 0 |
| 真实诊断反馈 | 182 / 129 | 182 / 117 | 12,231 / 0 |
| 倒序诊断反馈 | 182 / 132 | 182 / 117 | 12,285 / 0 |
| 真实选择的同锚点恒偏移 | 182 / 117 | 182 / 117 | 12,231 / 0 |

真实开放臂移除 1 个误报、增加 13 个，净加 12；等分数也移除
同一炮，并新增另 1 个。三个正式视图的全部 15 个校准折均没有
同时满足保护并取得收益的有限门槛，最终都选不写入。
所以不能用真实波形臂相对倒序少 3 个误报，声称它改善了静态模型。

## 3. 追因：稀有标签加权和一次写入都未解决

按[后续协议](PATCH_UTILITY_SPARSE_PROTOCOL_20261106.md)在同一数据
上另做探索，比较硬三分类等权拟合与旧岭分数，并施加同一个
按时间首次超过门槛才接受、每炮最多一次的写入策略。已封存
的首报不撤回。校准仍不能新增误报或损失原及时炮；表中写入数是
非零动作，不是查询数。类别加权是处理稀疏监督的诊断设计，不把
重加权得分当作自然流的概率；相关背景见
[Menon 等的长尾分类研究](https://openreview.net/pdf?id=37nvvqkCo5)。

| 同一单写入策略 | 开放：及时／误报 | 保守：及时／误报 | 开放／保守写入炮 |
|---|---:|---:|---:|
| 岭：风险／时钟 | 182 / 119 | 182 / 117 | 1,308 / 0 |
| 岭：真实 | 182 / 119 | 182 / 117 | 1,308 / 0 |
| 岭：倒序 | 182 / 119 | 182 / 117 | 1,308 / 0 |
| 岭：真实选择的恒偏移 | 182 / 117 | 182 / 117 | 1,308 / 0 |
| 硬标签：风险／时钟 | 182 / 117 | 182 / 117 | 1,308 / 0 |
| 硬标签：真实 | 182 / 117 | 182 / 118 | 1,308 / 145 |
| 硬标签：倒序 | 182 / 117 | 182 / 117 | 1,308 / 157 |
| 硬标签：真实选择的恒偏移 | 182 / 117 | 182 / 117 | 1,308 / 145 |

真实硬标签策略只在一个折选择有限门槛；其留出炮仍新增 1055961
误报，没有消除误报或救回迟报。五个训练折组的有益硬标签仅来自
2、7、9、8、4 个独立炮。即使事后给出最有利的**写入时刻**，
风险／时钟、真实、倒序的硬标签模型也只在 1／2／3 个炮的某块
把有益动作排首位，且均为安全炮。旧岭三视图分别为 1／1／1。
因此，在真实硬标签模型的现有排序和单次写入合同下，**任何
标量弃权门槛**都不能救回原迟报或移除 3 个误报；问题不只是
这次门槛网格太粗。由同一批开发炮产生，这些是描述性配对计数，
不是独立外推或显著性检验。

## 4. 核验与后续

- 上轮 CUDA 动作库 session60276 正常结束，106.54 s；14 个 tape
  分片记录零结局读取。三处原始波形截断比对中，封存因果候选的
  最大绝对数值差 1.91e−6，动作可用性一致。
- 本轮 CPU 主实验 session2845 19.81 s，稀有事件探索 session83773
  31.52 s，均退出 0。两次准备错误分别为错误的协议常量路径与
  在 CPU 验证调用 CUDA 初始化；均在拟合或证据写入前终止，
  修正后实际重跑，既有结果未覆盖。
- 原网络 CPU session88879 重跑 5 个原始炮的 14 段动作，实际
  未来曲线最大差 9.54e−6 logit，所有越阈位一致；历史保护点
  最大偏移 .0669。独立有限包络 session31647 在全部原失败炮复核
  同样的 2 个可救迟报及 11 个可消除误报。
- 主实验独立复核 session55375 8.60 s，核对 1,409 个输入哈希、
  163,410 个硬标签（含不写入）、8 臂 × 1,353 炮首报、75,420
  个留出动作及 120 条校准规则，逐值一致；封存 float32 效用对
  重算 float64 最大差 1.76e−9。软标签仅对原加载器，不重拟合
  记录权重。探索独立复核 session37518 8.39 s，重算 150,840
  次留出因果决策及 21,648 个整炮首报，得分最大差为 0。
- 本轮相关回归共 157 项测试和 14 个子测试通过，Ruff 通过。
  scikit-learn 当前 L-BFGS 接口产生一条 SciPy 弃用警告，不影响
  本次拟合收敛或复算。

不把更多时间点当作更多有益炮，也不再对这版选择器扫门槛。
下一步先做[**与目标装置观测条件一致的源域反事实**](PATCH_UTILITY_TARGET_VIEWS_PROTOCOL_20261106.md)：按已确认的
缺诊断合同，保留同一 TRAIN 炮的 native／缺 MNM／再缺 CIII
视图，先量测相同安全约束下能否获得更多独立的有益动作，特别
是等分数不能复现的迟报救回。三个视图始终按同一炮分折。
若仅增加原模型错误、没有扩大可纠错范围，就应改变内部动作
作用位置或表示目标，而不是继续拟合现有稀疏标签。
这里不假定缺诊断能模拟全部装置漂移，也不使用 EAST 未来标签。
后续仍须先过固定源 VAL 的整炮对照，再在 EAST 上证明炮内独立
收益，并验证炮内与炮间联合、同标签预算和固定误报约束。
缺诊断容量阶段已独立完成，见[续接结果](PATCH_UTILITY_TARGET_VIEWS_RESULT_20261106.md)；
尚未拟合新的跨视图选择器。
