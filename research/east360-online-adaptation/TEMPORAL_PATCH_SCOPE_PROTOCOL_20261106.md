# 炮内临时写入的时序范围：TRAIN 离线容量对照

问题：此前同一低秩状态作用于窗口内的所有数据 token。只改最近时序块，或者随当时已到达的观测移出近窗而撤出，能否让及时报警依赖新的局部演化，而不改变安全伙伴的首报？

- 固定前次已核验的 48 个危险—安全释放配对：J-TEXT TRAIN 三种原始视图 23 对（11 个原炮），两种已封存的辐射压力视图 25 对。复用同一原始分数、时钟、配对和冻结基模；不读新 VAL、TEST 或 EAST 数据。
- 只在输入 token 上改已有的相邻块变化量载体。对照为全窗口、最近四个 8 点块、最近四块按其与释放时最近 32 点的重合比例缩放。释放索引为 \(r=m+8\)，历史反事实锚点 \(t\le r\) 以自身当时已到达的最近四块计算；实际只改 \(r+1\) 至 \(m+32\) 的预测，保护锚点不写回。权重乘在 token 的改变量上，不修改观测或原 token。
- 三臂分别用相同危险目标点与原联合保护求解，在各目标点的共同可达范数上应用同一尺度网格。危险—安全双方使用同一个 64 维状态。对两个局部臂，各增加一臂：方向不重求，把同一状态按每个端点的局部／全局写入能量平方根比缩放后全局施加，匹配该端点的 token 改变量 Frobenius 范数。
- 两炮历史锚点对正、反两符号检查最大偏移不超过 0.09998 logit。安全伙伴整炮不得报警；危险炮在固定阈值下的首报须提前严格大于 10 ms、且在原监督窗内。每臂保留同一释放锚点分数差的恒定标量对照。候选计数不当作独立炮，严格原炮还排除在任一臂存在合格标量救回的炮。
- 只有局部臂至少支持三个原始物理炮，且至少一个不被本轮或存档的全窗口、相应等能量对照救回，才继续检验无标签信号能否选择该方向；否则不再扫局部块数。方向求解使用事后结局和释放后梯度，这里只测容量，不是已实现的因果策略、EAST 增益或总体误报率。
