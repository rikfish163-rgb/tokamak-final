## 六条曲线，五个不同条件

| 名称 | 唯一新增变化 |
|---|---|
| cold | 冻结冷启动基线，无新增变换 |
| n1_gain | n=1 amplitude乘以源/目标中位数比；零点不变 |
| CIII_gain | 有效CIII乘以源/目标中位数比；占位点仍不可用 |
| dx_shift | dx_a加上“源中位数−目标中位数”；保留炮内差值 |
| dy_shift | dy_a同样做平移 |
| identical | 和cold完全相同的实现零变化检查，不算独立实验 |

源和目标中位数均来自父运行保存的signal-only等炮统计。目标身份必须等于当前前20炮。每个增益要求有限且为正；没有可估计数据时直接报错，不偷偷退回identity。CIII的目标统计实际仅有1炮提供有效观测，这个条件只用于展示覆盖不足下的变换响应，不能因为有一个数值便认定标定可靠。

四个干预不叠加，不扫描倍率或偏移。它们不是正确物理单位的假设，而是具体可否证的数值操作。位置平移可能错误地改变真实平衡位置，增益可能消除真实幅值差异，因此失败也要完整报告。MNM屏蔽和CIII占位合同不变，不同时修改其他输入。
