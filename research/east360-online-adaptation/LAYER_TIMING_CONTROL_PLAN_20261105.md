# 单层炮内适应是否真的需要本炮历史？

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run
- Origin Date: 2026-11-05
- Verification Status: pre-execution plan
- Version Label: layer_timing_control_v1

同一个前20炮 moving-peak 已拟合规则，单独保留各内部位置，分别做三种逐动作
同幅对照。保留原静态、第一层、第二层全曲线作为复现基准。每个临时参数向量
均只应用于对应层。对照保留真实动作在该时刻的范数，所以只检验**方向**的特异性，
不声称对照拿掉了本炮的全部信息。

1. 滞后方向：当前状态不变，用四次更新之前已到达的炮内历史生成方向。
2. 首次方向：当前炮到达第一次更新点后锁住方向，不再根据后续信号改变方向。
3. 前炮方向：取上一炮已结束的方向序列，在相同相对采样点使用（前炮更短则
   停在最后一笔），不读上一炮的结局构造动作。第21炮的前炮方向在第20炮封存、
   结局揭示后，用固定映射重算第20炮，仅作对照，不回写其报警。

仍为 360 炮，前20不在线更新，无新增拟合、无新增标签、无阈值或报警器调整。
每炮全轨迹封存才读取结局。此对照在看到部件消融后提出，属开发验证；
若本炮方向不胜全部同幅对照，不能把首报改善归因于本炮持续微调。
报告严格 >30 ms、30–3000 ms 与 FPR/J 的逐炮配对；控制强度以相同站点范数核对。
执行 `layer_timing_control_20261105.py --output <new-directory>`，rl_env CUDA，
硬超时 360 s，记录每25炮进度，期望 360×9 条有独立复核的曲线。
