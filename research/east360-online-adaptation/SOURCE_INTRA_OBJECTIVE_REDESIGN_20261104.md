## 1. 结论和关键风险

**只建议检验一种：用真实 CIII 为同窗额外隐藏视图提供表示监督，更新当前炮的小型临时补偿状态。** 它不需要新预测头，但能否在真实 no-MNM 掩码下产生正确风险更新完全未知。尤其要防止：学生为了补回人为隐藏的 CIII 而写入一个方向，该方向应用到真实视图时又把已存在的 CIII 贡献加了一遍。

现有静态基线供定位，不是新方法收益：J-TEXT TEST220 的 native 100 TP/13 FP、no-MNM 92/15、no-MNM/CIII 97/29；EAST 纯源 145/94，前 20 原始输入、其后固定 map 为 116/29。`forecast_only` 主视图 0.07297 仍差于保持 0.05626，风险 utility 头为 0.53431；这些不同范围的数值不能互相换算为报警收益。[当前状态](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/CURRENT_SOURCE_UPDATE_STATE_20261104.md)；[utility 结果](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/SOURCE_UPDATE_UTILITY_RESULT_20261104.md)。

主进程新增的[静态阈值诊断](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/probe_outputs/static_threshold_diagnostic_20261104_v1/summary.json)显示：在整 360 炮结局事后参与选阈值、FPR≤0.2 且 EAST 提前量严格 >30 ms 的条件下，既有静态曲线最高及时 TP 分别为 unmapped **110**、map-after20 **119**、retrospective-map-all **126**。这支持对这几条固定曲线“单靠调一个门槛不足”的判断，不是神经更新或其他模型的上限；阈值使用全部结局，且 retrospective-map-all 对首 20 炮不是部署路径，均不可用于在线选择或改写主线门槛。本审查核读了摘要和计分代码，没有独立复跑。

相近工作不能忽略：历史内部表示补全在**另一 cold 父模型与另一掩码、位置、更新规则**下，普通、带任务约束、倒序及不更新均为 125/32，适应组各 11,114 次更新仍未改变炮级结果；不能把这当成本候选已失败，也不能把“表示补全”说成项目内全新思路。[原实验](/media/hetaisheng/044A81D94A81C83E/Fuison/docs/research/source_event_rebuild_20261023/内部表示补全_炮内预警配对实验_20261028.md)。

## 2. 唯一候选：真实掩码 teacher、额外隐藏 CIII 的 student

### 放置与目标

令 `M` 为当前已到达窗口的真实可用性，`M⁻` 只把**真实观测到的 CIII** 隐藏；其余信号和可用性不变。EAST 的 MNM 在 `M` 和 `M⁻` 中均保持真实缺失。`e_j(M)` 是第 `j` 个 8 点 patch 在源模型 embedding 后、Transformer 前的 64 维向量；`r_φ` 是已训练并冻结的 persistent TokenRepair。则

```text
T_j = stopgrad[e_j(M)  + r_φ(e_j(M),  M )]       # 真实掩码，δ=0
S_j =          e_j(M⁻) + r_φ,δ(e_j(M⁻), M⁻)     # 只对 δ 求梯度
L   = sum_{j∈P_train} ||S_j - T_j||² / (64 |P_train|) + 0.01 ||δ||²
```

`T` 必须是**真实掩码下已补偿的 `embedding_after`**，不是未补偿的 no-MNM native embedding；后者不提供保留静态 MNM 补偿的监督，可能把它抵消。teacher 完全 detach，不使用 teacher risk、风险伪标签、风险一致性/蒸馏锚或后验结局。`M⁻` 只是辅助分支，实际预警的输入值和真实 mask 不改变，也不把缺失 MNM 伪装成观测。

最小临时参数取 `δ∈R^16`：在冻结补偿器的 `Linear(66,16)` 与 `SiLU` 之间，加到其 16 维 preactivation；`LayerNorm(66)`、两层权重及偏置均冻结。它通过原 `Linear(16,64)` 改变受支持 patch 的补偿，不使用源模型原有 128 维 `fast` 作第二套更新。真实预警前向仍经同一个冻结编码器与 risk head：`embedding → TokenRepair(φ,δ) → 原 fast-origin token 变换 → Transformer → 原 risk_head`。详见 [TokenRepair](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/mask_repair_20261104/core.py) 和 [Simple23](/media/hetaisheng/044A81D94A81C83E/Fuison-intra-trajectory-20261028/experiments/risk_aligned_online/simple23.py)。

为限定修改而非承诺安全：`δ` 初值为 0，归一化 SGD 一步长度 **0.025**、L2 半径 **0.25**、无动量；`||g||<1e-8` 跳步，否则 `δ_next=Π_{||·||₂≤0.25}(δ−0.025 g/||g||₂)`。令 `u_δ=W₂·SiLU(W₁·LN([e,avail])+b₁+δ)+b₂`，`u₀` 为同输入、`δ=0` 的冻结输出，`r₀=clip_RMS(u₀,0.25)`；暂定 `r_φ,δ=clip_RMS(r₀+clip_RMS(u_δ−u₀,0.025),0.25)`。只在原实现的 eligible token 上应用，`clip_RMS` 沿用原实现对零范数/精度的安全处理。这样每 token 相对 persistent 补偿的附加改变量在最终投影前 RMS≤0.025，总补偿仍受 RMS≤0.25 限制。

`δ=0` 必须与原静态前向逐值相等，同时 `u_δ` 必须保留对 `δ` 的计算图：**不能因 `δ=0` 直接返回与 δ 无关的静态输出**，否则零初始化会永久无梯度。只有冻结的 `u₀/r₀` detach；夹紧饱和导致的实际改变量与梯度另行记录。这些是待预先固定的工程起点，不是物理量，也不能在看结果后扫描。无输入均值/方差在线归一化，不以风险高低控制更新。

### 因果时序与可观测支持

- 与现有 `simple_online.py` 的 26 点块边界对齐：零基 `t=25+26k`，至少已有 128 个采样点才允许第一次更新，即最早 `t=129`；采样点数不自动等于毫秒。先提交并锁定到 `t` 的所有预测，再仅用 `[t-127,t]` 的已到达值求梯度，更新只影响 `t+1` 起的输出。炮结束后封存完整曲线，才揭示 HDF5 结局和评分；不可重写任何已提交预测。
- 将 16 个 patch 固定分为前 12 个训练、后 4 个同窗留出。训练只用真实 CIII 在该 patch 中至少有 4 个观测点、且额外隐藏前后有效时间点集合不变的 patch；至少 4 个合格训练 patch 和 1 个合格留出 patch 才更新。留出值不进入梯度、调度或接收决策，仅用于事后评估。所有门槛只依据截至 `t` 已到达的 mask，不依据风险、后续长度或结局。
- `g=∂L/∂δ` 只来自当前窗口的已观测 CIII 与其他已到达信号。teacher 和 student 的 e/修复都在 embedding 位置取得；学生不能被整体 `no_grad` 包住。源模型及 persistent φ 无梯度、无优化器状态修改。每炮重新置零；若连续 52 个已到达采样点没有合格更新机会，清零过期 `δ`。真实 CIII 不可用时不能凭空更新；统计有支持窗口与炮的覆盖率。
- 先 20 炮仍使用原始输入，第 21 炮起使用已固定 map；新方法与自身 no-update 父模型完全共享它们，不能载入旧 `cold.pt`。静态补偿器应用与否由预先固定的配对臂决定，不能借用 116/29 代替新静态父模型的实际结果。

## 3. 为什么它可能无效，怎样直接证伪

令 `J₋=∂S/∂δ`，真实预警视图在同一点的敏感度为 `J_M`。未触发投影时，局部有 `g_SSL = 2 Σ_j J₋,jᵀ(S_j−T_j)/(64|P_train|) + 0.02δ`，真实视图的一阶改变量沿 `−J_M g_SSL`。**`J₋` 与 `J_M` 不必相同；降低额外隐藏视图误差不等于纠正真实视图。** 甚至 embedding 的线性部分直接包含被隐藏 CIII 的值和 mask 列贡献：复制这项就可能降低 L，应用于真实 mask 却重复计入 CIII。记录两种 Jacobian 的实际作用、补偿变化和真实视图风险变化，不能只报告 L 降低。

更根本地，静态 φ 的训练目标只是对源域同窗完整 embedding 的 MSE；当前 EAST teacher 自己仍不知道真实 MNM，也没有 HDF5 风险标签。相同已到达前缀可以对应不同未来结局，单靠这个无标签损失不可能保证风险梯度方向正确。固定风险头的雅可比只说明**分数如何移动**，不说明该上移还是下移。即使源域完整 embedding 教师的拟合误差下降，也必须用冻结后、未来窗口、事后揭示的真实标签检验；源 teacher 本身也不是结局真值。

因而分三级检查：

1. **静态前置**：先读主进程的静态评估。完整观测与原基模应精确等价；在锁定源 VAL 的 no-MNM 和 no-MNM/CIII 两视图，分别检查按炮风险损失、逐组和固定阈值的 TP/FP，并对照未补偿及已拟合的常量补偿。建议预定的晋级保护为：两视图各自相对未补偿，在安全和源及时正例组的逐炮平均 margin-BCE 均不得恶化超过 `1e-5`，固定阈值 TP 不下降、FP 不上升；组样本不足时标为不充分。如果仅 embedding 改善而上述保护失败，不以其作为已验证的有效静态 teacher 晋级；若未胜过常量补偿，也不称已证实条件性修复。TEST220 及已有 EAST20 已用于开发，不称独立测试。
2. **局部机制**：冻结 φ，先做源 VAL 的**离线单步反事实诊断**，每个起点从 `δ=0` 开始，不形成 J-TEXT 在线分支。源数据以实际可用 mask 人为去 MNM 构造 `M`，再去 CIII 构造 `M⁻`；只在 MNM/CIII 真有观测的支持上，另以未人为删通道的 frozen native embedding 作**仅离线可见的参考**，看真实 no-MNM 视图更新后是否更接近它，原本缺失的不能当完整真值。比较训练 12 patch 与留出 4 patch 的一致性变化。然后在 `q=t+26` 的 `M` 视图上先封存各臂预测，再按合同揭示 HDF5，算固定阈值 margin 的 BCE 变化：`BCEWithLogits(z−logit(τ), y)`；这是决策边界附近的代理损失，不是校准概率。安全炮与 J-TEXT 原标签且提前量 >10 ms 的及时正例分开、先炮内平均再跨炮平均；无效/不足 q 单列。未来 125 ms 若另行报辅助组，不能替换源原标签。
3. **真实部署口径**：只有局部检查通过，再在 EAST 做持状态逐炮回放，先预定的开发前 20 炮仅作诊断，不称独立；最终才考虑完整锁定 360 炮。输出每炮 first-alarm、提前量、救回/新增漏报、消除/新增误报、极早报警、覆盖、更新次数、状态范数/饱和率和延迟。持续危险片段事后按 HDF5 及时间分层，检查真实报警是否被持续压低；不允许用任何在线风险锚、变阈值或改历史预测掩盖该现象。

另做只读的方向审计：预测已封存、标签揭示后，在未来 `q` 的**更新前同一状态**计算 `g_risk=∂BCE/∂δ`，逐炮、逐组报告 `cos(g_SSL,g_risk)`、实际一步风险损失变化及真实视图的 `∂z/∂δ`。正常梯度下降的一阶有利方向要求内积为正；零范数单列，不编造余弦。**该梯度只用于事后诊断，绝不进入线上更新或训练。** 危险持续时的补偿范数受限、原始绝对信号仍在，并不保证危险不会被抹平；报警恶化本身就是拒绝证据。

## 4. 同预算对照与拒绝规则

对每个同炮同端点，使用相同真实风险输入、炮起点、更新日程、损失支持、学习率、半径和回传次数，各臂独立持有并在炮末丢弃 `δ`。局部单步诊断各臂从相同 `δ=0` 开始；完整流各臂历史更新后状态可以不同，不强行同步。以下替换**只发生在辅助 teacher/目标**，不改真实预测输入：

| 臂 | 辅助目标的差异 |
|---|---|
| real | 上述真实 CIII teacher。 |
| hold | 将当前窗口真实可用位置的 CIII 值替换为该窗口最早的已观测 CIII 值；保留真实 mask。 |
| reverse | 仅在同一已到达窗口的 CIII 可用位置反序其值，mask 不动。 |
| random | 固定 seed，在相同可用位置随机打乱 CIII 时间次序，mask 不动；不从其他炮或未来取值。 |
| spatial shuffle | 设 `T⁻` 为冻结 φ 在 `M⁻` 的 embedding，目标改为 `T⁻ + P(T−T⁻)`，`P` 为预定 seed 的 64 维特征置换；保留差值范数。它是**表示坐标**错配，不声称物理通道可交换。 |
| no-update | 按 real 完成相同 teacher/student 前向、反向和裁剪计算，但丢弃提议，`δ` 保持零。 |

每个有效端点所有臂均计算一次真实 teacher、一次隐藏 teacher、一次该臂控制 teacher 和一次学生，并回传一次；real/no-update 也重复计算其控制 teacher，spatial 臂做同样次数的 teacher 前向后再做置换。记录前向/反向调用数、实耗时、有效步数、零梯度和实际状态增量，避免把“算得更多/更新更大”当效果。hold/reverse/random 不能重写真实输入；无支持时所有臂均跳步。real 的留出误差相对 **real 原始 teacher** 统计；各臂自有伪目标训练误差仅供诊断。另记录 `J_M` 与 `J₋` 作用的范数、方向以及 real 相对 persistent φ 的真实掩码补偿变化，检查 CIII 重复计入和 MNM 补偿被抵消。

建议在任何新结果出来前固定以下门槛；`ε=1e-5` 是风险代理损失的数值区分门槛，不代表实际报警效应量或统计显著性：

- **支持不足**：源 VAL 每个安全/及时正例组各少于 10 个有支持的独立炮，标记“不充分”，停止晋级；不能用相关窗口数冒充炮数。EAST 另按炮和时间报告 CIII 可用率及跳步率；覆盖不足时不得把少数可更新炮推广到全流。
- **拒绝局部候选**：任一组真实反馈相对 no-update 的逐炮平均未来 margin-BCE 不下降，或真实反馈未以至少 `ε` 优于 hold、reverse、random 和 spatial shuffle 中**每一臂**；或留出 patch 不改善、真实 no-MNM 相对源完整参考恶化。真实组均值与各控制均按同一支持炮配对；同时报告以炮为单位的配对 bootstrap 区间及全部伤害，不把有符号均值写成显著性。
- **拒绝完整流晋级**：相对于同一静态 φ 父模型，真实臂 TP 下降、FP 上升，或固定阈值 `J=TPR−FPR` 未严格超过 no-update 及每个伪反馈臂；有改善也须列出所有反向翻转。早于第一次更新的报警不可能被后续更新撤销。若真实臂只有代理损失或 embedding 改善而未达到这些条件，结论仍是未证明炮内收益。

## 5. 主进程实现前的最小核对

1. 在 CPU 合成输入上同时验证 `δ=0` 与 persistent 静态路径 bitwise 同值、未饱和且构造非零差值时 `∂L/∂δ` 有限且非零；teacher 与 φ/源模型无梯度。验证 MNM 两侧均缺失、只隐藏真实 CIII、padding/有效点与输出 mask 无误。检查夹紧、零梯度、无支持和异常时 hook 清理。
2. 截断或任意修改 `t` 之后的信号/结局，不得改变截至 `t` 的预测、支持、teacher、梯度与状态；跨炮初始 `δ=0`，无动量或残留。验证反向只更新临时变量、真实分支的风险确实对 `δ` 有可测响应，同时检验已提交预测不变。
3. 依次完成静态评估、离线单步机制、开发 EAST20，再决定是否固定完整流；每一步先固定参数和全部控制，保留失败产物，不以门槛扫描、换炮、补缺值或选择有利时间点过关。
