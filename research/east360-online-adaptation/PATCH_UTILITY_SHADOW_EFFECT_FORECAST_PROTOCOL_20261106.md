# 影子响应是否能预测动作效应：密集目标与首报效用分开

## Material Passport

- Origin Skill: experiment-agent
- Origin Mode: run; locked before the dense forecast run
- Origin Date: 2026-11-06
- Verification Status: no dense target results at protocol freeze
- Version Label: patch_utility_shadow_effect_forecast_v1

这是八帧影子选择的独立机制诊断，不依赖稀少的正效用标签来
学习响应方向。问题是从 t=m+8 已到达的候选轨迹，是否能
预测同一个候选会在后 24 点怎样改变**内部更新产生的风险**，
而不是能否知道破裂或该写哪一个动作。

- 同三个封存视图和已验证的八帧保护。只纳入后 24 点都
  有实际记录的可写非零动作来统一目标长度；无未来时不作
  估算，不改主策略样本。这个完整性条件是离线评分所需，
  不作为运行时输入。对每动作定义 `Δ(s)=z_a(s)-z_0(s)`，
  目标为之后三个相邻 8 帧内 `Δ(s)-Δ(t)` 的均值。
  拟合不读取 HDF5 破裂真值或硬首报效用；首报只可用于分层描述。
- 两个确定性基线：保持最后已达偏移（预测后续相对变化零）；
  用已到达八点的首末斜率乘以后三区间距 t 的平均步数
  4.5、12.5、20.5。四个学习臂使用与首报选择完全一致的
  不看影子、幅度、真实、倒序特征。每臂固定 L2 .03，
  加权中心化标准化，三个输出分别回归；每折用与原方案
  一样的三拟合折，剩余校准折不参与本诊断。
- 先对每一块的可写动作等权，再对该炮该视图的块等权，
  再对该炮有支持的视图等权，最后对独立炮等权；拟合和
  评分都不把多视图当独立炮。报告三段 MAE、整体 MAE，
  各视图以及合并物理炮的配对差。只有真实同时优于保持、
  斜率、幅度和倒序，才说这批源域观察给未来效应预测提供
  了时序增量；即使成立，也不能当实际首报提升。

不读取新的 VAL／TEST／EAST，不改变任何报警器、不回放
新选择策略，也不替代主实验的排名及整炮安全门。
